# L3/U: вводные тексты сайта и Android — результат

Продолжение [аудита одного экрана](genesis-welcome-intro-audit-2026-10-22.md). Исправлены вводные zh/tr/uk в существующих общих каталогах, без перестройки интерфейса, новых библиотек и изменений входа. Пользователь отдельно разрешил промежуточный деплой сайта после текущих проверок; новые сборки/публикация Android приостановлены. Все debug APK для этого среза собраны до этого указания; последующие проверки используют готовые APK. Физические телефоны и SSH не использовались.

## Содержимое

Китайский заголовок больше не означает сбор средств и сохраняет GENESIS; турецкий и украинский заголовки правильно называют календарь и менеджер проектов. Три вводных абзаца ясно объясняют планирование и синхронизацию; украинские «рекурсійні практики» заменены регулярными практиками. Для нативного двухстрочного названия добавлены цельные переводы с корректным порядком слов/падежом. Общие короткие фрагменты переводчика не менялись. В web сохранены прежние полные `WELCOME_TITLES`; изменился общий вводный заголовок, а не h1 или юридические тексты.

Сохранены существующие блоки, отступы, ассеты, официальная кнопка Google и выбор языка. Тексты переносятся естественно; высота и геометрия действий не уменьшаются ради длинной строки. Эти девять сообщений не являются полной носительской вычиткой четырнадцати языков; другие неточные формулировки в каталогах остаются частью L3.

## Приёмка

- Web: реальный `WelcomeScreen` и штатный `useDocumentLanguage`, все восемь CSS-файлов приложения. Chromium: zh/tr/uk ×light/dark ×360/390/768/1440px — **24 before +24 after профиля, 48 PNG**. Точный заголовок, неизменный h1, переносы строк, отсутствие горизонтального переполнения и официальное изображение Google проверены. Frozen install/lint/496 tests/build:beget PASS; lint содержит только две прежние img warnings. Production и OAuth этим прогоном не проверялись.
- Android: API28/API35 ×zh/tr/uk ×light/dark ×360/390/768/1440dp, font1,3. **48 профилей в каждой фазе; 16 instrumentation-запусков, 288 PNG** (header/title/body). Все запуски PASS; после исправления проверены фактические текст, строки TextLayout, горизонтальные границы, размещение над областью действий и высота Google-кнопки≥48dp. Ширина/fontScale и display restore подтверждены; на API35 ожидался RenderThread commit, на API28 — animation fallback. Содержимое PNG дополнительно проверено по градиенту экрана и system-error guard.
- Один test APK/compiled harness применён к обеим фазам/SDK. App APK одинаков на обоих SDK в каждой фазе; после изменения его четыре каталога побайтно совпали с исходниками. **Все 553 упакованных изображения совпали побайтно**. Сборки debug app/test и native lint PASS; новых release/R8 и JVM suite для изменения копирайта не запускали.

## Сбои harness и границы

Vite dev transport не загрузил большие каталоги за 60сек. Вместо него использована локальная production bundle того же компонента/переводчика/CSS с исходными public fonts/flags/Google asset; первые dev-результаты не принимаются. Первый favicon404 этой fixture не является ошибкой сайта. Web проверялся на изолированной странице без разрешённых account actions.

На API35 `run-as` не смог прочитать synthetic captures из external storage. Первый UI-профиль при этом PASS; диагностический `Permission denied` сохранён. Уже готовые кадры/JSON выгружены штатным `adb pull`, затем остальные профили продолжены теми же APK; первый UI-запуск повторно не выполнялся. После обеих фаз настройки каждого эмулятора восстановлены.

Не проверены fresh Google OAuth, signed MainActivity, физические устройства/жесты/TalkBack, новый release/R8, новые браузеры WebKit/Firefox и полная носительская вычитка всех14 каталогов. Остаток:11/32 функциональных ID приняты,21 частичный; отдельно14 K/U/L. Android-код и новая native fixture остаются в локальной acceptance-ветке; промежуточный web-релиз переносит только web/API и общие каталоги на свежий master.
