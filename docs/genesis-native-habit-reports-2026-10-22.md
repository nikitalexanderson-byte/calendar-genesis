# F1–F3: продолжение нативных отчётов

Аудит существующего HabitCompletionCalendar: числитель считает все completed snapshots, знаменатель только текущее active-состояние; это исключает историю архивированных привычек и может дублировать один день. Нет отдельных знаменателей объёма и закрытых целей, сопоставления равных прошедших частей недели, исходных записей выбранного дня и годового представления новых типов.

Первый экран — блок календаря выполнения в существующем разделе привычек. Сохраняются галерея, изображения, награды, качество и личная история. Вместо параллельной модели используется нативный перевод уже подготовленных web analyzeHabitDay/analyzeHabitRange/buildHabitGoalComparison: current snapshots по устойчивой дате, причинная доступность, правило на дату, отдельные закрытые цели/объём/открытый период. Периоды берутся из действующего GenesisCalendar с зоной, версией и январским/мартовским началом года. Год не обрезается до370 дней.

Интерфейс сохраняет STANDART и общие48dp icon actions. Навигация по календарю и периоду отделяется от содержимого; выбранный день показывает фактические записи, единицы, источники, пропуск/отдых/паузу/неизвестную доступность и переход в существующую историю. «Сегодня» не меняет дату при просмотре отчёта.

Проверки до приёмки: parity с web fixtures, равные части периода/нулевая база, открытые гибкие цели,13 лунных месяцев, мартовский год, DST/зоны, двойные snapshots, объём выше100% при доле целей не выше100%, отсутствие записи/осознанный пропуск, наградная неизменность чтения. Затем настоящие UI/storage сценарии и обе схемы/4 ширины/14 языков/font130 на API28/API35. Отчёт пока фиксирует аудит и направление, не завершённую приёмку.
