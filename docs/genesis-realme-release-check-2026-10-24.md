Проверены открытие, доступность содержимого и возврат без сохранения. Создание/удаление пользовательских данных и фактический импорт не выполнялись. ## Границы приёмки

Установленная2.9.7 не содержит новые source-only Android fixes из PR #276: закрытие четырёх полнооконных редакторов снаружи, Saver подразделов и изменение шкалы приоритета. При смене системного шрифта в2.9.7 воспроизводится прежний сброс «Год»→«Месяц»; это не является проверкой исправленного Saver. Новая web-панель переписки также не заявляется частью установленного Android UI.

Число обычных активных привычек в библиотеке и состав Today со старыми завершёнными практиками остаются отдельным вопросом совместимости, описанным в предыдущем отчёте; пользовательские записи ради проверки не менялись. Полная матрица всех13окон × обе темы × все шрифты/ориентации не проходилась. Аппаратный TalkBack, длительный Doze, все ошибки вложений/ключей и новая регистрация не проверялись.

Новая web-панель до публикации проверена на синтетическом localhost-стенде в Chromium: обе темы ×360/390/768/1440, отправка с настоящим шифрованием/расшифровкой, поиск/страницы, unread/draft, error recovery, DE/JA и малая высота. Попытка доступа realme к этому стенду через USB отклонена автоматической проверкой (`blocked by policy`, без пояснения). Запрошено отдельное разрешение; этот маршрут не считается пройденным. Проверки native приложения выполнены независимо от него.

## CI и подготовка публикации

Для продуктового кода PR #276 выполнены frozen install, lint, scoped TypeScript,666/666 web tests, `build:beget`, изолированный messaging PHP suite. После параллельной публикации #277 ветка без конфликтов перенесена на `38065184`; повторены web-проверки, messaging suite и167 проверок Physis security (SQLite, HTTP, межпроцессный CAS). Backend acceptance в GitHub сначала не стартовал с сообщением об оплате/лимите: репозиторий оказался Private. По действующему указанию пользователя возвращён Public; повтор того же workflow прошёл успешно. Предыдущая production-публикация подтверждена через deploy-meta и health. После параллельного релиза видимость ещё раз оказалась Private и вновь возвращена в Public перед нашим выпуском.

Скриншоты/XML и receipts сохранены локально в `output/realme-deploy/`, предыдущие web-матрицы — в `output/playwright/panel/` и `output/samsung-email/`. Они не включены в Git. SSH в этом дополнительном прогоне не использовался. Итоговый SHA и состояние публикации следует сверять с GitHub Actions, `/deploy-meta.json` и `/api/health`; этот документ фиксирует проверки до запуска workflow и не выдаёт его будущий результат за успешный.
