## Выявленные ошибки и ограничения проверки

1. Общий Android instrumentation-прогон на API 35: 123 проверки, 24 падения. После исправления ожиданий светлой темы ночью повторный прогон на API 36: 123 проверки, 13 падений. Из них две проверки ожидают ещё не опубликованный APK 2.4.7; одна требует включённого TalkBack; часть тестов напоминаний и аккаунта зависит от разрешений, сети и состояния других тестов. Один тест главного экрана использовал старый путь к иконке внутри новой кликабельной плашки; он исправлен и затем прошёл отдельно. Остальные сбои оставлены открытыми в отчёте, полный набор пока не зелёный.
2. Не проведена проверка авторизованных веб-экранов с настоящим Google-аккаунтом и живой синхронизации после удаления привычки. Исправление восстановления удалённой привычки имеет автоматический тест, но поведение на production-аккаунте требует отдельной проверки без изменения пользовательских данных.
3. Публичные браузерные снимки не подтверждают вид авторизованных карточек в каждой теме. Тёмные карточки проверены на локальных визуальных образцах с теми же стилями. Права администратора, показ рекламы по сегментам и её закрытие через минуту не проверены в production.
4. Play Protect и системное предупреждение об установке APK не могут быть сняты сборкой сайта. Регистрация разработчика и APK в Android Developer Console требует действий владельца аккаунта Google; шаги описаны в `docs/ANDROID-PLAY-MARKET.md`.
5. Подключение Яндекса оставлено выключенным для следующего выпуска. Подготовлен только план в `docs/yandex-next-release.md`.
6. Дополнительная команда `tsc --noEmit` выдаёт 178 ошибок типов во всём репозитории, включая старые остаточные рабочие деревья. Обязательные для публикации lint, тесты и сборка проходят; общая проверка типов требует отдельной очистки и исправлений.
7. Автоматический аудит переводов проверяет покрытие и письменность, но не может доказать смысловую точность каждого предложения. Исправлены обнаруженные ошибки в карточках дней на английском, турецком, польском, немецком, украинском, японском, китайском и других языках; полный редакторский просмотр всех экранов носителями языка не проводился.
8. Дополнительная проверка сохранности ассетов подтвердила все 558 исходных файлов без удаления или изменения. Её историческая проверка числа встроенных SVG завершилась с ошибкой: она сравнивает текущий код с более старым commit и отмечает как прежнее изменение `TheokyklosView.tsx`, так и добавленные сейчас SVG. Ни один файл изображения в этом выпуске не удалён.
