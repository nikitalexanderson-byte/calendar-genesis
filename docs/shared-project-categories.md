# Категории проектов общих пространств

Категории пространства объединяют только проекты и подпроекты. У проекта одна категория или «Без категории»; у подпроекта выбор независимый. Теги остаются множественными. Задачи и списки задач нельзя непосредственно включить в категорию пространства. Хаос-бокс также не является проектом для категорий.

Миграция `040_shared_project_categories.sql` добавляет таблицу и nullable-ссылку в `shared_projects`. Существующие проекты, задачи, теги и исторические категории задач не переписываются. Старые клиенты, не передающие `categoryId`, сохраняют выбранную категорию проекта. Исторические совместимые API категорий задач сохраняются; новый интерфейс использует `/shared/spaces/{id}/project-categories`.

Перед CI-деплоем существующий `deploy.yml` делает согласованную runtime-копию SQLite и `config.php`. Миграцию применяет приложение транзакционно при первом обращении к БД. Проверки в `server/tests/shared-ui.php` покрывают права, чужие пространства, категории подпроектов, старые клиенты, конфликт ревизий и сохранность проектов, задач и тегов при удалении категории.

Откат кода выполняется через `git revert`: прежний код игнорирует добавленные поля, схема и данные категорий остаются в БД. Откат БД автоматически не требуется и не выполняется. Если понадобится восстановить БД, сначала остановить изменяющие запросы, проверить runtime-копию и отдельно согласовать восстановление.
