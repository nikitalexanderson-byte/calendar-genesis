# Календарь, выполненные задачи и личные проекты · 19 октября 2026

Пользователь попросил ограничить высоту общих календарных ячеек квадратом, уменьшить плашки задач и раскрывать выполненные задачи порциями по пять. Дополнительно разделены раскрытие личного проекта и открытие его окна.

## Изменения

- Ячейки календаря проекта квадратные; содержимое больше не увеличивает высоту строк. День показан в круге. Три компактных превью сохраняют открытие задачи, многоточие — полный день. При наведении или фокусе плашка раскрывается вверх поверх номера дня, сохраняя исходную область наведения. После ухода номер снова виден. Для сакрального и лунного календаря сохранена дополнительная григорианская дата. Изменения стилей ограничены календарём общих проектов.
- В календаре и Ганте выполненные задачи сначала показываются по пять. Вложенный спойлер открывает следующие пять; дальнейшая кнопка добавляет ещё пять. Размер страницы API не меняет размер видимой порции. Неуспешная загрузка не увеличивает видимый предел. Сворачивание возвращает фокус на заголовок, смена проекта сбрасывает раскрытие.
- В личных проектах плашка и стрелка раскрывают задачи. Одиночный клик по названию на компьютере раскрывает проект; двойной открывает окно проекта. На мобильной ширине название открывает окно одним нажатием. Для клавиатуры стрелка управляет раскрытием, Enter/пробел на названии открывают окно. Кнопки самостоятельные, вложенных кнопок нет.

## Проверки

- `pnpm install --frozen-lockfile` выполнен.
- `pnpm lint`: ошибок нет, два существующих предупреждения об `img` в майндмепах. После восстановления используемого импорта отдельно повторён lint изменённых модулей.
- `pnpm test`: аудит всех переводов и 352 теста прошли.
- `pnpm build:beget`: успешная сборка с обоими включёнными флагами майндмепов, проверкой публичных документов и offline precache.
- Дополнительный `tsc --noEmit` выявляет существующие ошибки вне изменённых модулей: таймер/защита привычек, типы Стойхейона, совместимый Yandex-диалог и Cloudflare-типы. В изменённых модулях ошибок TypeScript после проверки нет.
- Браузерные проверки выполняются на изолированных синтетических данных, без изменений production-БД. Светлая и тёмная схемы, ширины 360, 390, 768 и 1440 px. Снимки до/после: `output/playwright/square-cells-*`, `completed-batches-*`, `personal-project-expand-*`.

- Календарь: восемь сочетаний темы/ширины, геометрия квадратов с допуском 1 px, прямое открытие задачи и полного дня. Отдельно проверены все три устойчивые области наведения и возвращение номера дня. Сакральный/лунный/григорианский виды дополнительно сняты на 390/1440 px; дополнительная дата сохранена.
- Выполненные: 16 сочетаний календаря/Ганта, темы и ширины; последовательность 5→10→15→20→24→5, правильный счётчик и возврат фокуса. Пустой список не создаёт секцию, пять задач обходятся без вложенного спойлера, шестая показывается отдельной порцией. На 131 задаче проверены уникальность строк, отказ сетевой страницы при 100 видимых задачах, повторная загрузка до 105 и открытие последней задачи.
- Личные проекты: восемь сочетаний темы/ширины; стрелка и свободная область плашки раскрывают задачи без окна, название на мобильной ширине открывает окно одним нажатием, на десктопе — двойным. Enter на названии открывает окно, отдельное редактирование сохраняется.
- Сохранено 62 снимка: 24 до, 32 после для основных поверхностей, ещё 6 для календарных режимов. Внешнего переполнения страницы на проверенных ширинах нет; широкая календарная сетка прокручивается внутри своей области.
