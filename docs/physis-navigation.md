# Фюзис: верхняя панель, страницы и модальные настройки

Актуальная структура и расчёты от 25 октября: [Фюзис: дневник, программы и расчёты](physis-workflows-2026-10-25.md). Ниже сохранена история предыдущего этапа.

24 октября 2026. Узкий этап оформления по поручению пользователя; существующие формы, записи, вход и API сохраняются.

Аудит исходного экрана: название, глобальный обзор, текстовая кнопка настроек и подразделы всех трёх направлений имели один уровень. Новый порядок: верхний блок в стиле Теокиклоса → три основные страницы → подразделы выбранной страницы → содержимое. Верхний блок использует существующие theokyklos-hero, seal, шрифт и палитру; силуэт Фюзиса сохранён. overflow:clip защищает текст от внутреннего горизонтального сдвига при фокусе на шестерёнке.

Основные страницы — Тренировки, Питание, БАДы и лекарства. Каждая сохраняет выбранный подраздел при возврате; остальные подразделы не показываются в её меню. Блоки прежнего обзора распределены по своим направлениям; показатели остаются в обзоре тренировок. Кнопки основных страниц используют общие shared-projects-switch стили календаря/Оракула. Доступные подписи и выбранная страница сохранены.

Настройки доступны только в модальном окне по общей IconActionButton с gear. Используются общие DialogCloseButton и useDialogAccessibility: focus trap, Escape, закрытие снаружи и возврат фокуса. Вход из личного кабинета тоже открывает модальное окно. Содержимое настроек остаётся смонтированным при закрытии, чтобы сохранить черновик. Обычной страницы настроек нет.

При проверке найден конфликт: общий tooltip перехватывал Escape в capture phase после клавиатурного фокуса на иконке, не давая диалогу закрыться. Tooltip теперь закрывает подсказку и передаёт Escape активному модальному окну. Это относится и к существующим диалогам.

## Дополнение: боковая панель

Следующее поручение пользователя добавлено в тот же выпуск. Выбор секунд заменён checkbox. Панель сразу скрывается при включении режима, раскрывается при наведении на левый край и скрывается при уходе мыши, в том числе после клика по пункту меню. Клавиатурный фокус удерживает меню доступным; Escape из меню возвращает фокус на край. Перетаскивание ширины сохраняется.

Для совместимости существующее поле sidebarAutoCollapseSeconds остаётся в API: 0 выключает режим, прежние положительные значения означают включённый режим без таймера. UI записывает прежнее допустимое положительное значение; SQL/API migration и ручные изменения production DB не нужны. Невидимая полоса не перемещается за уходящей панелью; её область плавно сужается до края, чтобы наведение не обрывалось во время открытия. На мобильных ширинах режим не меняет нижнюю навигацию.

В году личные pending/completed индикаторы объединены в одной верхней правой группе; компактная геометрия сохранена.

Локальная проверка выполняется на синтетической личной записи и перехвате shared API, без создания production-задач. Обе схемы × три календаря × месяц/год × 360/390/768/1440.
