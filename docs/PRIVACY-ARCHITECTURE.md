# Приватная архитектура GENESIS

## Где находятся данные

| Данные | Устройство | Google Calendar | Сервер GENESIS |
|---|---:|---:|---:|
| Названия и описания задач | Да | Да | Нет |
| Даты, напоминания, повторения, статусы | Да | Да | Нет |
| Связи задач и теги | Да | В закрытых свойствах события | Нет |
| Проекты, подпроекты и категории | Да | В событиях задач как ссылки | Только AES-GCM ciphertext |
| Gmail, имя, аватар | Кэш профиля | Google Account | Да, для аккаунта |
| OAuth refresh token | Нет | Выдаётся Google | Да, Sodium secretbox |
| Пароль Google | Нет | Нет | Нет — вход выполняется на стороне Google OAuth |
| Статистика | Локально вычисляется | Нет | Только числовые агрегаты |

## Поток синхронизации

1. Пользователь входит через Google OAuth 2.0 с PKCE.
2. GENESIS создаёт отдельный календарь `GENESIS` с ограниченным scope `calendar.app.created`.
3. Задача сразу сохраняется локально и отправляется как событие Google Calendar.
4. ID проекта, теги, зависимости и статус находятся в `extendedProperties.private` события.
5. Структура проектов сериализуется в JSON, шифруется Web Crypto AES-GCM и только затем передаётся серверу.
6. На другом устройстве после входа приложение получает зашифрованный контейнер, расшифровывает его в клиенте и читает задачи из Google Calendar.
7. Без сети используется локальная копия и очередь изменений.

Сервер технически проксирует события между приложением и Google API, но не записывает их содержание в SQLite, логи или административную статистику.
