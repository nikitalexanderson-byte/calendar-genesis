# Приватная архитектура GENESIS

## Где находятся данные

| Данные | Устройство | Google Calendar | Google Tasks | Сервер GENESIS |
|---|---:|---:|---:|---:|
| Названия и описания календарных задач | Да | Да | Нет | Нет |
| Названия списков и данные Google Tasks | Да | Нет | Да | Нет — только транзитная обработка |
| Даты, напоминания, повторения, статусы | Да | Да | Для нативных Google Tasks | Нет |
| Связи задач и теги | Да | В закрытых свойствах события | Нет | Нет |
| Проекты, подпроекты и категории | Да | В событиях задач как ссылки | Нет | Только AES-GCM ciphertext |
| Email, имя, аватар | Кэш профиля | Google Account | Google Account | Да, для аккаунта |
| OAuth refresh token | Нет | Выдаётся Google | Выдаётся Google | Да, Sodium secretbox |
| Пароль Google | Нет | Нет | Нет | Нет — вход выполняется на стороне Google OAuth |
| Статистика | Локально вычисляется | Нет | Нет | Только числовые агрегаты |

## Поток синхронизации

1. Пользователь входит через Google OAuth 2.0 с одноразовым `state` и PKCE; на этом этапе запрашиваются только `openid`, `email` и `profile`.
2. Пользователь отдельно нажимает кнопку подключения синхронизации и видит запрос разрешений Calendar и Tasks.
3. GENESIS создаёт отдельный календарь `GENESIS` с ограниченным scope `calendar.app.created`.
4. Календарная задача сразу сохраняется локально и отправляется как событие Google Calendar.
5. Списки и задачи Google Tasks читаются и изменяются через официальный API только после отдельного согласия.
6. ID проекта, теги, зависимости и статус находятся в `extendedProperties.private` события.
7. Структура проектов сериализуется в JSON, шифруется Web Crypto AES-GCM и только затем передаётся серверу.
8. На другом устройстве после входа приложение получает зашифрованный контейнер, расшифровывает его в клиенте и читает задачи из Google Calendar и Google Tasks.
9. Без сети используется локальная копия и очередь изменений.

Сервер технически проксирует события и задачи между приложением и Google API, но не записывает их содержание в SQLite или административную статистику. OAuth-токены зашифрованы Sodium secretbox; пользователь может отозвать их отдельно в личном кабинете либо вместе с удалением аккаунта.
