# Задачи внутри ячеек общего календаря: аудит

Пользователь просит показывать от1 до3 задач в ячейке, открывать карточку по задаче и полный день по многоточию. В `SharedProjects` названия сейчас выводятся только при count≤3, берутся из первой100-строчной страницы и находятся внутри одной общей кнопки даты. Поэтому большая загрузка скрывает названия, а отдельное открытие задачи отсутствует. На узких ячейках существующий CSS также скрывает превью.

Сайт уже имеет `CalendarCellTasks`, bounded `/shared/calendar/previews` с3 ссылками на каждый день и существующее окно дня с полной пагинацией. Переиспользовать эти части: добавить к прежнему preview endpoint необязательный серверный фильтр проекта/приоритета/полей, сохранив current ACL,42-дневную границу, open-only и прежний контракт без фильтра. Подключить тот же hook со scope текущего проекта и всех ширин, отдельные настоящие кнопки даты и задачи без вложенных кнопок. Перед открытием preview загрузить актуальные задачу и контекст; поздний ответ прежнего проекта/периода не должен открыть чужую карточку.

День продолжает открываться существующим окном и показывает все страницы. Отображение сакральных/лунных/обычных дат и календарь ввода не меняются. На узком экране обеспечить читаемые ячейки с локальной горизонтальной прокруткой сетки, без переполнения страницы; обычные подписи дней и последовательность календаря сохраняются. Завершённые/без срока, переносы задач и данные сохраняются.

До правки снять текущий экран. Приёмка:1/2/3/5/131 задач, задача за первой страницей, отдельный проект/priority/custom filters и ACL, открытие каждой preview-карточки/дня/следующей страницы, поздний ответ и навигация,14 языков, три календаря/сохранённый контекст и обе схемы ×360/390/768/1440. SQL-миграций не требуется; выпуск только через прежний deploy.yml.
