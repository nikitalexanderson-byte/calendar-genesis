# GENESIS 3.1.2 / 119 — подготовка изменений

База: свежий `origin/master`, `7f2271ed`; отдельная ветка `codex/v3.1.2-today-shared-and-calendar`. Незакоммиченные изменения исходной рабочей папки сохранены. Функциональная приёмка завершена; публикация выполняется штатным deploy.yml.

## Аудит и выбранные изменения

На «Сегодня» использовался только личный список задач; общие задачи читались для выбранного дня календаря. Добавлен отдельный запрос общих задач по фактической сегодняшней дате, включая выполненные записи, с прежней пагинацией и обработкой ошибок. При наличии общих задач появляются подписи «Личные» и «Общие». Личные задачи остаются доступны при ошибке общего списка. Web-запрос дополнительно разделён по владельцу аккаунта.

Android-перенос между досками удерживается общим viewport, независимо от lazy recycling. После долгого нажатия движение резервируется в Initial pass, а callback переноса/завершения вызывается после Final pass: дочерние узлы успевают обработать событие до изменения дерева. Владение жестом снимается до callback завершения. Карточкам добавлены устойчивые ключи, статус читается безопасно, координаты preview проверяются на конечность. Точный стек пользовательского вылета не получен; нативная приёмка и ограничения ниже.

У карточки дня жёсткая граница создавалась отдельной прямоугольной заливкой поверх изображения. Убрана дополнительная заливка; рисунок плавно переходит в поверхность темы. Видимая область изображения увеличена. В светлой теме «Сегодня» использует светлые подложки и более яркую исходную иллюстрацию во всех трёх календарях. Ассеты сохранены.

Остальные изменения Android:

- Создание переписки перенесено в общую шапку, в тот же зелёный/золотой стиль. В списке переписок новая кнопка и два общих переключателя образуют три иконки.
- Кнопка проверки обновления внизу drawer оформлена как соседняя кнопка обновления аккаунта: без заливки и обводки.
- Панель открытой личной или общей карты: вид → добавить → отменить → название и описание → история → экспорт. Экспорт непосредственно открывает меню JSON/PDF. Один ряд сохраняет цели 48dp, при недостатке места допускает горизонтальную прокрутку.
- Центрирование карты и поиск используют общую нижнюю панель и одинаковые кнопки 56dp на одной высоте.
- «Сегодня» перенесено в правый верхний угол описания месяца у всех трёх календарей. Название периода центрируется между одинаковыми стрелками. Из годового вида кнопка и её callbacks удалены полностью.

Web повторяет разделение задач, обработку иллюстраций и положение перехода к сегодняшнему месяцу. Годовой вид этого перехода не содержит.

## Дополнение: трекеры «Сегодня» и разрешение выпуска

Пользователь явно поручил добавить трекинг состояния, сна и воздержания в этот же выпуск, перепроверить переводы, выполнить деплой сайта и публикацию Google Play. Это разрешение заменяет прежний запрет Android-сборок для 3.1.2/119. Используется прежний Alpha, package и подпись; тестировщики и Production-трек не меняются. После выпуска GENESIS_DEPLOY_ANDROID возвращается в false.

Android «Сегодня» показывает настроение, планы/записи сна и активные трекеры воздержания по их сохранённому расписанию, независимо от выбранного календарного дня. Настроение редактируется только для фактического сегодня; формы сна и воздержания используют ту же дату. Доступны создание плана сна и ежедневного трекера воздержания. Обычные привычки соблюдают прежний переключатель модуля; наблюдения хранятся независимо. Общий флаг видимости блока сохраняется.

Добавлены кодеки, импорт облачного документа и трёхстороннее слияние addictionTrackers/addictionEntries. Старый локальный документ без этих коллекций сохраняет их отсутствие; сохранение сна/настроения не интерпретирует это как удаление записей с сайта. Изменения сохраняются транзакционно с проверкой версии записи и существующим encrypted outbox. XP и Лавры не начисляются. Миграция БД не требуется.

Новые подписи и release notes подготовлены для всех 14 языков. `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` (763/763) и `pnpm build:beget` повторно прошли с production-флагами GENESIS_MINDMAPS/NEXT_PUBLIC_GENESIS_MINDMAPS=true. Максимальный JS — 349968 bytes, лимит 350000 сохранён. Android testDebugUnitTest: 876, failures/errors 0, skipped 8; lintRelease прошёл. На Windows используется существующий file.encoding=COMPAT из gradle.properties: UTF-8 в worker argfiles искажает кириллический путь и приводит к ClassNotFoundException.
