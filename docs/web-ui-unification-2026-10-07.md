# GENESIS Universal UI: задачи, проекты и навигация

Пользователь явно разрешил улучшать обе темы, начиная со Standart. Это уточнение имеет приоритет над прежним ограничением AGENTS.md на визуальные изменения только Experimental.

Аудит обнаружил разные шапки проектов/задач, нестилизованные вкладки задач, слишком мелкие подписи бокового меню, дублирование основной навигации на планшетах и маленькие кнопки действий. Принято общее оформление существующего интерфейса: палитра, изображения и функции сохраняются; шапка раздела, переключатели, поиск и кнопки получают единые размеры и состояния.

Реализация начата с раздела задач. WorkspaceHeader затем применён к личным и общим проектам. Общий слой universal-ui.css подключён после существующих тем в обеих точках входа. Светлые и тёмные варианты Standart/Experimental используют одну структуру и собственные цвета активных элементов.

- На экранах до 1199 px показывается нижняя навигация: Сегодня, Задачи, Проекты, Месяц, Ещё. Второстепенные разделы доступны в нативном popover; скрытые пользователем пункты остаются скрытыми. На десктопе используется боковое меню с читаемыми подписями.
- Веб-настройки «Только иконки» удалены. Старые локальные значения переводятся в text; при недоступном localStorage подписи также видны. Настройки Android не изменены.
- Шапки, переключатели личного/общего доступа, фильтры, поиск, основные/второстепенные кнопки и формы списков унифицированы. Действия задач имеют область касания не менее 44×44 px. Поиск и фильтры имеют доступные имена и состояния выбора.

Проверки: pnpm install --frozen-lockfile, pnpm lint, pnpm test (105/105), pnpm build:beget; аудит переводов 14 языков; Impeccable detect не обнаружил проблем. Проверены 48 сочетаний: задачи, личные и общие проекты × четыре темы × 360, 390, 768, 1440 px. Нет горизонтального переполнения и двойной основной навигации. В последней проверке кнопки действий задач и мобильной навигации не меньше 44×44 px.

Дополнительно проверены личные/общие списки и настройки на 390 px; открытие и Escape для «Ещё». Синтетический локальный аккаунт исключает изменение production-данных. Исходные и итоговые PNG и измерения находятся в output/playwright/site-unification этой рабочей копии (не включены в Git). Сохранены и скриншоты production до изменений.

При проверке нижних карточек дополнительно исправлены реальные классы действий проектов и кнопок создания: размер 44 px, перенос действий под название до 1200 px, читаемые названия/описания и метаданные задач. Устранён конфликт планшетной сетки: одна колонка теперь имеет соответствующие области inbox/tree, поэтому дерево не сжимается в нулевую колонку под хаос-боксом. Категории задач используют контрастную подпись во всех темах, сохраняя пользовательский цвет в боковой метке. Эти состояния дополнительно проверены на четырёх ширинах во всех темах.

Непроверенные состояния: физические телефоны/планшеты и Safari, каждый язык в браузере, все комбинации пользовательского скрытия пунктов меню, реальные совместные записи/приглашения, живая Google-синхронизация, офлайн-переходы и все календарные/каталожные экраны. Их функции не переписывались; общие календарные проверки входят в текущие тесты. Production проверяется после CI-деплоя по SHA и health, затем визуально.

SSH не использовался. Миграций и ручных изменений базы данных нет. Code rollback — git revert с повторным деплоем через существующий workflow.
