# GENESIS Android и сайт 2.3.11

## Изменения

- Админ-панель показывает по каждому аккаунту число запросов на скачивание Android APK из авторизованного сайта, первый и последний запрос и версию запрошенного файла.
- Нативное приложение сообщает серверу свою версию и случайный идентификатор установки. Панель показывает последнюю сообщённую версию, число известных установок, время последней связи и результат последней синхронизации с сервером и сервисами Google.
- Ссылка на APK проходит через серверный адрес учёта и перенаправляет на подписанный файл 2.3.11. Анонимные и прямые загрузки нельзя достоверно отнести к конкретному пользователю; сведения о старых загрузках и версиях появятся только после нового запроса или связи клиента с сервером. Отчёт версии не подтверждает, что приложение всё ещё установлено.
- Содержание задач и заметок в телеметрию не попадает. Данные об установке и загрузках удаляются вместе с аккаунтом; политика конфиденциальности обновлена.

## Проверки

- `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test`, `pnpm build:beget`.
- SQLite-миграция, запись загрузки и версии, выборка админ-панели проверены локально; PHP smoke проверяется существующим CI перед деплоем.
- Android debug, androidTest, JVM-тесты и lint; обновление поверх 2.3.10 и проверка HTTPS-транспорта на Samsung Galaxy A56.
- Админ-панель проверена в браузере с тестовыми данными в обеих темах на ширинах 360, 390, 768 и 1440 px. Снимки до/после сохранены в локальном каталоге `output/playwright`. Вход в реальный production-аккаунт для визуальной проверки не использовался.
- Полная матрица уведомлений, телефонов API 26–36 и четырёх планшетных профилей уже прошла на 2.3.10; новая версия меняет только заголовки HTTPS-запросов Android-клиента.

## Выпуск и откат

- Версия APK `2.3.11`, код `44`; публикация только через текущий GitHub Actions workflow после merge в `master`.
- Миграция `015_android_activity.sql` создаёт две новые таблицы с `ON DELETE CASCADE` и не меняет существующие данные. Перед CI-деплоем workflow сохраняет серверную SQLite-копию. При ошибке кода выполняется `git revert` выпуска; откат базы вручную без отдельного плана не проводится.
