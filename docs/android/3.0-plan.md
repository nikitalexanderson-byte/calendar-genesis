## Дизайн-решение

Operate: пользователь сразу видит содержимое, а меню открывает по необходимости. Одна строка 56dp: меню, контекст, актуальные действия. Основные разделы и их подстраницы в прокручиваемой Material drawer; текущий пункт выделен, Back/нажатие вне/выбор закрывают меню. Статус локальной копии и версия внизу drawer. Никакой постоянной нижней навигации. Без общего свайпера разделов: горизонтальные жесты принадлежат календарю и карте. Сохранённые настройки подписей меню применяются в drawer.

Светлые web-токены: paper #eee9dc, surface #fffdf8, ink #132426, muted #526263, teal #255b59, gold #8c672b. Тёмные: paper #0b1511, surface #12241c, ink #f0eee7, muted #afbeb2, gold #e4c78c, teal #acc7af. Источник: app/experimental-theme.css (только чтение). Контролы и обычные карточки 10dp, сенсорные цели от 48dp. Авторские изображения сохраняются; крупные материалы дня раскрываются по запросу.

## Исследованные подходы

- Google Calendar: выбор вида из меню, возвращение к сегодня, переход по дате: https://support.google.com/calendar/answer/6110849?co=GENIE.Platform%3DAndroid&hl=en
- TickTick: создание из календарного контекста, редко используемые параметры в overflow: https://help.ticktick.com/articles/7063851189372190720
- TickTick: статистика привычки по запросу, отдельные настройки отображения: https://help.ticktick.com/articles/7055792921664028672
- Todoist: документация мобильной навигации исследуется; решения принимаются по подтверждённым источникам и реальному коду GENESIS.

## Неизменяемые границы

Не менять web, backend, production-БД, шифрование, package стабильного приложения и идентификаторы данных. Не удалять ассеты. Фюзис отсутствует в новой Android-навигации. Установка не равна сборке; debug-подпись не равна совместимому release. Локальных signing env пока нет; штатные signing secrets есть в Actions. CI и стабильный публичный канал не изменять ради выдачи beta.

Итоговые результаты, точный APK и ограничения: [3.0-acceptance.md](3.0-acceptance.md). Отдельный ручной artifact-only workflow зарегистрирован PR #305; `deploy.yml` не менялся. Независимый подтверждающий UX review выполнен, оставшихся P0/P1 по исходным пунктам не найдено.
