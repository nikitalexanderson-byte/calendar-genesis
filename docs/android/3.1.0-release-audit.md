# Приёмка GENESIS 3.1.0 / 117 — 29 октября 2026

Пользователь разрешил сайт, обновление смартфона и прежний Google Play Closed testing Alpha. Во время проверки Realme заменён пользователем на Samsung SM-A566E. Production-трек, страны, тестировщики, package и подпись сохраняются. Публикация выполняется существующим deploy.yml после merge; этот отчёт подготовлен до неё.

## Изменения

- Android: компактный календарь, переход на выбранные месяц и солнечную дату, единые высоты календарных блоков, исправления перетаскивания и оптимистическое перемещение задач/сроков с последующим сохранением на сервере.
- Диалоги, прозрачность фона, иконки, сон и настроение, нейтральные emoji и выбор оттенка, порядок информации Оракула приведены к согласованному поведению.
- Сравнение привычек показывает отдельные подписанные периоды, «выполнено … из … целей», долю выполнения и изменение числа выполненных целей. Объясняет исключение сегодняшнего дня и неизвестной истории пауз. Пустой период не выдаётся за результат 0/0. Даты сохраняют выбранный календарь. Тексты добавлены на 14 языках.
- Таймер раскрывается внутри своей привычки. Сворачивание сохраняет работающую сессию; другая привычка не запускает второй таймер того же устройства.
- Три звуковые схемы, 18 коротких оригинальных сигналов, независимые переключатели отклика, проверка уведомления без изменения прогресса, работающие испытания. Настройки меню соответствуют фактическим разделам и календарям.
- Дневник: удаление заметок, локальное хранение, выключение/явное включение синхронизации, удаление активных серверных копий с сохранением локальных заметок. Постоянные отметки удаления препятствуют воскрешению старыми клиентами. Потерянный ответ сервера не создаёт повторную копию. В юридических документах описаны действия и ротация резервных копий.
- Сообщения используют единый Google-аккаунт: контакты по email, личные, групповые и проектные чаты, блокировки, приглашения и устройства. Обычные чаты защищены при передаче и шифруются сервером. Секретные чаты привязаны к двум устройствам и используют ECDH/HKDF/AES-GCM; ключи создаются автоматически. Неизвестный результат отправки повторяется дословно; подтверждённый конфликт позволяет вернуть текст в защищённый черновик.
- Вход через связанный Google-аккаунт сохраняет права канонического владельца, включая admin и Фюзис на сайте. Фюзис не добавляется в Android. Отвязка аккаунта отзывает доступ.
- Афродистика: 120 дословных русских текстов из DOCX, 13 переводов, отдельная иллюстрация для каждого совета, три смысловых направления. 64 совета помечены 18+, 56 доступны без взрослой тематики. Категория выключена по умолчанию. Отказ/отсутствие подтверждения исключает взрослые материалы на сервере, в том числе из старых снимков. Весь каталог: 672 опубликованных совета, 0 черновиков, 672 разных изображения, 14 языков.

## Границы проверки и риски

- Секретные чаты — собственный протокол GENESIS, не MTProto/Signal. Double Ratchet и прямая секретность после компрометации долговременного ключа не заявляются; независимого криптографического аудита нет. Очистка локального хранилища лишает доступа к секретной истории. Подробности: 3.1.0-messenger.md.
- Не проверены все сочетания данных во всех диалогах, Safari/Firefox, TalkBack, масштаб шрифта 200%, все режимы энергосбережения производителей и физическое прослушивание/вибрация на Samsung. Инструментальные тесты синтетические, не заменяют многодневную проверку двумя реальными пользователями на разных устройствах.
- Переводы прошли структурную проверку, проверку письменностей и выборочную смысловую вычитку; отдельная профессиональная лингвистическая экспертиза всех авторских текстов не проводилась. Русский оригинал сверяется по SHA-256 и не изменён.
- Миграции 087/088 добавляют таблицы и защитные триггеры. Штатный CI сохраняет runtime SQLite перед применением. Код откатывается через git revert; автоматического отката БД нет. Триггеры намеренно не позволяют старому коду заново загрузить удалённые записи или обойти запрет синхронизации дневника.
- IARC-анкета обновлена с указанием текстовых упоминаний взрослой тематики и пользовательского общения. Рассчитанный Google/IARC рейтинг по регионам отличается от внутреннего ограничения 18+ на часть советов. Готовый черновик и Changes in review не считаются доступностью версии 117 тестировщикам.
- Подпись, публичные SHA-256, запуск подписанных вариантов, сохранение установки Samsung и production health проверяются на фактическом выпуске и фиксируются в ignored release-result.json. SSH на этапе подготовки не использовался; production-БД вручную не изменялась.
