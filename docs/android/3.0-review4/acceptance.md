# Android 3.0 beta.4 — правки владельца 26 октября

Пробная версия 3.0.0-beta.4 /106. Только Android и его документация. Сайт, API, production, стабильный канал и GENESIS_DEPLOY_ANDROID=false не изменяются. SSH не используется.

Требования: [22 пункта](requirements.json). Исходные снимки владельца содержат личные записи и остаются вне Git. Синтетические снимки предыдущей версии: [beta.3](../3.0-review3/screenshots.md).

Состояние: локальная приёмка и проверка подписанного артефакта выполняются. Результаты и конкретные границы проверки будут записаны после завершения; промежуточные прогоны не считаются финальной поставкой.

История команды использует существующий ограниченный ответ сервера и раскрывает его по 5 записей; API сайта не менялся. Перенос списка сохраняет записи и Google-идентичность. Задачи, ранее отдельно вынесенные из списка, сохраняют своё независимое размещение.

Модель использует неизменённый genesis-sacred-calendar-v8.svg из сайта, упакованный офлайн. Встроенный WebView не получает JS-интерфейс к приложению, доступ к файлам/контенту и внешние сетевые ресурсы отключены; наружу передаются только проверенные номер месяца и дня.
