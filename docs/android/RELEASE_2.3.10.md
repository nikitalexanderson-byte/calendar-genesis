# GENESIS Android 2.3.10

## Изменения

- Кнопка «Подробнее» в сакральном годе получила контрастные цвета для тёмной темы, мягкую анимацию и больше не содержит стрелку.
- При меню только с иконками связующие линии скрыты; активный пункт и подменю объединяет слабое переливающееся свечение.
- В анимации Стойхейона участвуют все 24 буквы греческого алфавита.
- Заголовок года прокручивается вместе с содержимым григорианского, сакрального и лунного календарей. Справочные кнопки показывают полные названия и отдельные акцентные цвета.
- Григорианский год можно показывать с января или с марта. Та же настройка синхронизируется с профилем сайта; по умолчанию остаётся январь. Даты задач и повторов не меняются.
- В григорианском годе доступны четыре мягких постоянных сезонных фона или 20 дополнительных фонов для пяти региональных палитр. В Южном полушарии название сезона, цвет блока и иллюстрация соответствуют местному времени года.
- В общих настройках можно брать регион устройства, определить регион по IP или выбрать его вручную из списка. Запрос к сервису IP-определения выполняется только после выбора этого способа или ручного обновления; при отсутствии результата используется регион устройства.
- У подраздела «Списки задач» собственный заголовок и анимированная иконка списка. Кнопка «Создать» сразу открывает редактор задачи или списка в зависимости от выбранного подраздела.
- На планшетных экранах от 600 dp шапка компактная: статус аккаунта остаётся в строке с названием и версией, в том числе при боковом меню.

## Проверки

- `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` (71 тест), `pnpm build:beget`.
- Android: компиляция debug и androidTest, JVM-тесты, `lintDebug` и проверки сценариев на Samsung Galaxy A56 / Android 16.
- Ручной выбор Австралии и порядок сезонов мартовского года покрыты UI-тестами; выбор климатической палитры покрыт JVM-тестами.
- Снимки годового календаря и настроек сохраняются в каталоге отчётов Android-тестов.
- Локальная публичная оболочка сайта просмотрена в браузере на ширинах 360, 390, 768 и 1440 px в Standart и с применёнными стилями Experimental; горизонтального переполнения нет. Личный кабинет в браузере без тестового аккаунта визуально не проверен; логика настроек покрыта сборкой, тестами и проверкой API.

## Выпуск и откат

- Версия APK: `2.3.10`, код версии: `43`.
- Миграция `014_gregorian_year_start.sql` добавляет необязательный для старых клиентов столбец с исходным значением `january`. Совместимый откат кода: revert выпуска в `master`; откат БД не выполняется автоматически.
- APK собирается и подписывается существующим GitHub Actions workflow. Публикация — только через merge в `master`.
