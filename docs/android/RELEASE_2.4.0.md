# GENESIS Android и сайт 2.4.0

## Изменения

- Сайт и Android получили польский, сербский, украинский, упрощённый китайский, турецкий и японский языки. Экран входа показывает только SVG-флаги с доступными названиями языков. При первом входе без сохранённого выбора используется язык региона устройства; неизвестный регион даёт английский.
- Переведены шаблоны уведомлений о привычках, целях, достижениях и системные каналы. Полные каталоги интерфейса доступны офлайн в APK. Автоматические переводы требуют редакторской проверки носителями языков.
- В настройках Android владельцу аккаунта с серверным `isAdmin` доступна админ-панель в модальном окне с кнопками закрытия сверху и снизу. Сервер проверяет права на каждом запросе.
- Заголовок календарного года движется вместе со страницей и находится отдельно от карточки года. Фоновые сезонные иллюстрации стали на 40% заметнее.
- Для восхода и заката сайт и Android используют координаты и IANA-часовой пояс выбранного города; переход на летнее/зимнее время рассчитывается для даты. При автоматическом определении региона по сети время помечено `≈`; при ошибке сети остаётся приблизительный расчёт по поясу. Город можно выбрать в настройках вручную. Для Сакраменто 30 сентября 2026 года расчёт даёт около 07:01 и 18:49.
- Версия подписанного APK `2.4.0`, `versionCode 46`. Прямая загрузка APK не может программно отключить предупреждения Chrome или Play Protect.

## Проверки

- Обязательные проверки: `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test`, `pnpm build:beget`.
- Android: debug APK, test APK, JVM-тесты, lint и эмуляторная матрица API 26–36 для телефонов, API 35 для четырёх планшетных профилей. Отчёты находятся в `android/build/reports/emulator-matrix-2.4.0`.
- Браузер: экран входа 360, 390, 768 и 1440 px, локальные скриншоты в `output/playwright/release-2.4.0`. Авторизованные страницы обеих тем требуют действующей сессии и отдельно отмечаются как проверенные или непроверенные в итоговом отчёте.
- Реальный Samsung проверяется отдельно от эмуляторов; Samsung One UI и устройство тестировщика S23 эмулятором не воспроизводятся.

## Выпуск и откат

- Публикация сайта и подписанного APK проходит через существующий GitHub Actions workflow после merge в `master`. Проверить `/deploy-meta.json`, `/api/health`, SHA-256 скачанного APK и обновление установленной версии без очистки данных.
- Миграции БД не требуются. Для отката кода выполнить `git revert` в `master`; базу данных автоматически не откатывать.
