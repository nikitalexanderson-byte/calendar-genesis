## Объявление об обновлении

PR315 добавляет локализованную update-карточку в существующий /ads/today для Android, сообщившего более старую версию, чем опубликована в android-update.json. API дополнительно проверяет наличие APK. Минимально поддерживаемая версия и доступность синхронизации не повышаются. При равной/новой/невалидной версии карточка не выдаётся. Объявление автоматически начнёт предлагать3.0.6 после её публикации.

Старые APK сохраняют скомпилированную кнопку закрытия; сервер не может её удалить. Для повторного входа update-карточка не использует часовую паузу. В3.0.6 специальный kind и targetVersionCode исключают скрытие по рекламной частоте и кнопку закрытия; после обновления карточка фильтруется и сервером, и клиентом. Play-сборка ведёт из такой карточки в Google Play. Обычная реклама сохраняет прежние ограничения показа и закрытия.
