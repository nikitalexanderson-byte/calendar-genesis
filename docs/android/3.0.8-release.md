Все локальные UI-проверки используют изолированный debug package и синтетические данные. Не выполняются uninstall, очистка данных, понижение версии или автоматическое восстановление БД.

Не заявляется полный ручной перебор всех языков, объёмов данных, ролей, уведомлений при погашенном экране и OEM-ограничений. Эмуляторные результаты и результаты на телефоне перечисляются отдельно в итоговом отчёте. Прямой SSH для этого выпуска не требуется.
