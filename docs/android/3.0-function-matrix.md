# GENESIS 3.0 — матрица функций и исходная проверочная база

Исходный срез: 26 октября 2026, свежий `origin/master` `f69bc7b7` (до изменений 3.0). Инвентаризация исходников, маршрутов, вызовов записи и тестов дополнена нативными реализациями 3.0. Наличие экрана или тестового файла само по себе не является PASS; выполненные проверки привязаны к точным APK в [3.0-acceptance.md](3.0-acceptance.md).

Обозначения: **CODE** — реализован пользовательский сценарий и путь изменения/чтения данных; **GAP** — конкретный web-сценарий не найден в native; **PARTIAL** — есть поднабор; **EXCLUDED** — исключён заданием. Столбец проверок связывает сценарий с тестами; упоминание теста без явного результата не означает его выполнение. **NOT_RUN** сохраняется у неиспытанных реальных сетевых операций. Пути web даны от корня, native UI — от `android/app/src/main/java/ru/genesis/calendar/ui/` (U), native auth/data — от соседних `auth/` (A) и `data/` (D). Тесты `.kt` указаны точными уникальными именами; UI обычно в `android/app/src/androidTest/java/ru/genesis/calendar/`, pure/unit — `android/app/src/test/java/ru/genesis/calendar/`.

## Критические связи навигации и прав

- Исходный master: `GenesisApp.kt:358` и `MenuSwipeNavigation.kt` перечисляют Сегодня, Проекты, Календарь, Привычки, Сакральное, Настройки. «Задачи» остаётся внутренним совместимым состоянием, но уже не отдельным основным пунктом. Новый drawer должен сохранять доступ к спискам и задачам через личные дела.
- `GenesisApp.kt` применяет account `uiVisibility.hiddenMenuItems`, `hiddenSubmenus`, `sacredFeaturesEnabled`, выбранные видимые календари. Скрытые пункты не должны вновь появиться через боковую панель, deep link, свайп или голос.
- Общие дела: `sharedProjectsEligible && sharedProjectsEnabled`; тестовый workspace их выключает. Принятие приглашения и включение общих дел остаются реальными сценариями.
- `SharedProjectsScreen.kt:370–379`: write owner/manager/member; comments включают commenter; invite owner/manager; редактирование task дополнительно использует `sharedTaskCanEdit`, archived/pending/revision guards. `canOrganizeTasks` отличается от обычного edit. При переносе UI сохранять эти вычисления и серверную проверку.
- Контекстные инструменты общих проектов — не отдельные основные пункты: `SharedProjectsScreen.kt:1207–1255` содержит сохранённые виды, экспорт, шаблоны, bulk, автоматизации, поля, импорт, отчёты, доступ к проектам, planning/workflow, настройки, участников и архив. Нельзя потерять их, убрав верхние большие блоки.
- Admin остаётся только при `isAdmin`; guest/viewer/commenter не должны получать кнопки мутаций из-за нового визуального компонента.
- Не превращать обнаруженный GAP в неактивную кнопку или ссылку на десктопный web. Если GAP не устранён, отчёт должен явно отделить его от реализованного редизайна.
