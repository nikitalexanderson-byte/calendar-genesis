# GENESIS 3.0.5 — уточнения интерфейса 28 октября

База: `origin/master` `25fe0c7dae0a75558ccd98f47df1a86468059db9`, опубликованная 3.0.4/111. Рабочая ветка: `codex/android-305-month-space-menus`. Основной OneDrive checkout с изменениями Фюзиса не изменялся. Это подготовка следующей версии: номер Android-релиза и production не изменены.

## Аудит и направление

Присланные снимки показали повторяющиеся действия, смешение сущностей доски и списка задач, потерю структуры в обсуждении и перегруженные календарь/Гант. Первой изменена григорианская плашка месяца, затем последовательно указанные экраны. Сохранены STANDART, две схемы, существующие изображения и Universal UI. Мягкие смысловые цвета по образцу «Пути героя» применены к указанным блокам без смены общей темы.
