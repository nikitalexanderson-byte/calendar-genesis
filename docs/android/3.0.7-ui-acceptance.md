# Genesis Tasker 3.0.7/114 — изменения и приёмка

28 октября 2026. База: `d5b35a016bb6e557214566366f76bd864e017dcd`. Подготовлены исходники web/API и Android; публикация 3.0.7, APK/AAB и установка на телефон в эту проверку не входят. `GENESIS_DEPLOY_ANDROID=false` сохраняется. Основной OneDrive checkout с изменениями Фюзиса не затронут.

## Изменения

- Сакральную привычку можно вернуть к исходному названию, описанию, значку и цвету. ID, расписание, состояние, цели, история и награды сохраняются. Дополнительные практики чтений не заменяют стандартные слоты и не сбрасываются этой командой.
- Пространство общих дел содержит проекты. Задачи и списки создаются внутри проекта; задачи без доски находятся в хаос-боксе этого проекта. Старый блок «Ранее сохранённые задачи» удалён из web и Android. Подготовлена миграция 086 и серверные ограничения, включая старые клиенты, переносы, импорт и повторения. [План миграции и восстановления](../shared-project-inboxes-086.md).
- В Android увеличены промежутки между семью кнопками общего раздела с сохранением одного адаптивного ряда. У создания задачи отдельная иконка file-plus-2. В поиске сняты обводки действий фильтрации/сортировки; также сняты обводки у меню личного проекта, таймера привычки и стрелок периода истории.
- Общий заголовок диалогов Android и отдельные заголовки редакторов используют крестик без обводки справа, с локализованным именем и целью касания 48dp. У редактора мысли устранён второй верхний крестик. Отдельно учтены custom Dialog, окна загрузки, выбор региона/даты/эмодзи, редакторы сна, полноэкранные планирование/спринт/workflow и нативный TimePickerDialog. Обязательное обновление остаётся недоступным для закрытия, как и прежде; системная авторизация Google управляется ОС.
- Четыре шаблона майндмепа — «Пустая», «Идея», «Проект», «Решение» — размещены равными кнопками в одном ряду.
- На «Сегодня» убран лишний дополнительный промежуток между задачами и привычками; переключатель светлой/тёмной темы в форме разделённого квадрата добавлен только в шапку «Сегодня».
- Для выбранного дня календаря задачи и привычки разделены на самостоятельные блоки. Общий счётчик открывает окно «Общие задачи дня»: все страницы задач даты, завершённые и незавершённые, загрузка, ошибка/повтор, пустое состояние, открытие задачи с существующей проверкой доступа.
- Годовые карточки всех трёх календарей используют общую вычисляемую высоту и скруглённые оригинальные изображения. В григорианских карточках добавлены короткая этимология и строка сезонной природы по выбранному региону, каждая без переноса; номер месяца остаётся вне изображения. Природные заметки описывают сезон, не прогноз погоды.
- Редактор дневника ограничен содержимым и доступной высотой, сохраняет прокрутку при клавиатуре и равные кнопки действий.
- Подписи внутри оригинального SVG солнечного круга локализованы для всех 14 языков, включая дуговые надписи, даты и доступные имена. Ассет не заменён; Android использует тот же модуль локально, без сетевой загрузки или JavaScript bridge.
- Каталог «Возвращение к мере» загружается в выбранном языке. Сохранённые автоматически созданные названия и абзацы отображаются в текущем языке; собственный текст пользователя и сохранённые снимки не переписываются. Исправлены также машинные подмены собственных названий месяцев (например, TRYGE больше не превращается в глагол «попробовать»), подписи управления кругом и формат даты по языку. В CJK сохраняются канонические латинские имена собственные согласно проверкам терминологии проекта. Предлагаемое имя нового плана сна локализовано при создании и в Android, и на сайте.

## Подтверждённые проверки

- `pnpm install --frozen-lockfile`; lint без ошибок, два прежних предупреждения Next img; TypeScript без ошибок с исключением ignored QA-стенда.
- Полный `pnpm test`: 743 успешных теста, включая четыре случая локализации солнечного круга и подписей интерфейса. Проверки восстановления практик и отображения сохранённых рекомендаций включают все 196 сочетаний языков и сохранение собственного текста.
- `pnpm build:beget` успешно. 116 обязательных entry-ассетов, 402 визуальных ассета, наибольший JS chunk — 349999 байт при неизменённом лимите 350000. Новые словари вынесены в небольшие общие ресурсы и отдельный locale-refinements chunk, а не в переполненные locale chunks.
- Android `:app:compileDebugKotlin :app:testDebugUnitTest` успешно: 855 случаев в 149 suites, 0 ошибок, 8 ранее предусмотренных opt-in HTTP-проверок пропущены. После последнего изменения геометрии дневника повторная компиляция Kotlin успешна; актуальные словари повторно упакованы в generated assets. APK/AAB не собирались.
- Изолированная миграция 086: исходные шифротексты, ID, комментарии, зависимости, категории, дополнительные поля и их значения, завершённость, списки, повторения, права recovery-проекта, журнал, FK, резервная копия и запрет записи задач в корень — успешно.
- PHP: series, bulk, shared-ui, data exchange, task details (включая 10000 задач и 50 проектов), calendar previews, mindmap conversion, mutation receipts — успешно. Основные проверки shared-projects/collaboration/approvals выполнены; полный security HTTP/race harness на Windows не подтверждён из-за отдельных subprocess/config и кодировки кириллического пути. Это ограничение стенда, полную Linux CI-проверку оно не заменяет.
- Реальный Chrome на локальном изолированном стенде, настоящие компоненты/CSS и синтетический PHP API: 48 снимков до/после для habits/shared/solar, светлая/тёмная схема × 360/390/768/1440px. Выхода документа за ширину viewport нет. Копии исходных компонентов взяты из базы; зависимости и синтетическая БД общие, поэтому это сравнение интерфейса, а не старой модели данных.
- В браузере подтверждены отмена/подтверждение возврата привычки, создание задачи в хаос-боксе, перенос на доску и обратно, завершение/возврат в работу без потери расположения. Для солнечного круга дополнительно проверены выбор месяца и локализованные дуги EN/DE/JA/SR/UK.
- После исправления оставшихся английских подписей солнечного круга сохранены ещё 16 снимков DE/JA на всех четырёх ширинах в обеих темах; подписи и отсутствие внешнего переполнения подтверждены заново.
- SVG исключён из повторного DOM-перевода: иначе общий наблюдатель переводил отдельные буквы уже локализованной дуги. На японском в браузере отдельно подтверждена неизменность полного набора глифов имени AREIOS.
- Impeccable detector: одно advisory о прежнем fallback-цвете `#2d6c68` в SharedProjects; новых блокирующих замечаний нет.

Локальные доказательства остаются в ignored `output/android-307/` и `output/playwright/genesis307-*.png`. Пользовательские исходные снимки сохранены в `output/android-307/before/`. В Git не добавляются локальные БД, cookies, конфигурация и журналы с личными данными.

## Непроверенные состояния

Физический Realme, новый APK на эмуляторе, Android runtime/IME и системный TimePickerDialog после этой правки, TalkBack, увеличенный системный шрифт, все жесты и визуальная геометрия годовых карточек на устройстве, живой многопользовательский доступ и production-синхронизация не проверены. Проверка текста всех языков не является ручной лингвистической приёмкой каждой страницы. Web-матрица покрывает три изменённых раздела, не всё приложение. Production-БД не менялась; SSH не использовался.

Перед будущим выпуском нужны штатная Linux CI-проверка, runtime-приёмка Android после отдельного разрешения сборки, подтверждённый server-only backup и обычные проверки `/deploy-meta.json`/`/api/health` после согласованного деплоя.
