# GENESIS Android и сайт 2.3.12

## Изменения

- В настройках аккаунта сайта тема Experimental получила выбор светлой и тёмной цветовой схемы. Выбор сохраняется в аккаунте; тема Standart по умолчанию визуально не изменена.
- Сайт и Android поддерживают греческий, немецкий, французский, испанский, итальянский и португальский языки наряду с русским и английским. Выбор сохраняется в профиле. Переводы используют общие каталоги интерфейса; Android включает их в APK для работы без сети.
- Экран входа Android располагает выбор языка отдельным рядом, чтобы кнопки не перекрывали логотип на телефоне.
- Уведомления Android получают локализованные названия каналов. Текст некоторых уведомлений, системных и справочных сообщений при отсутствии перевода остаётся на английском; машинные переводы требуют дальнейшей редакторской проверки носителями языков.

## Проверки

- `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test`, `pnpm build:beget`.
- Android debug, androidTest, JVM-тесты и lint; установка и переключение шести языков в эмуляторе Android API 35. Полная матрица устройств и авторизованные сценарии синхронизации в этом выпуске не повторялись.
- Настройки аккаунта и темы проверены в браузере на ширинах 360, 390, 768 и 1440 px; скриншоты до/после находятся в локальном `output/playwright`. У реального production-аккаунта визуальная проверка не проводилась.

## Выпуск и откат

- Версия APK `2.3.12`, код `45`; публикация через действующий GitHub Actions workflow после merge в `master`.
- Миграции базы данных не требуются. При ошибке кода выполнить `git revert` выпуска в `master`; откат базы данных не нужен.
