- Нативный Android-клиент использует одну тёплую тему Standart для рабочих разделов. Экран входа отдельно перенял с веб-страницы тёмно-зелёный фон `#07171b`, светлый текст, золотой акцент и заголовок с засечками; мобильная компоновка вертикальная, кнопка Google-входа закреплена над системной навигацией, у RU/EN видны флажки. - Вход подтверждает серверную сессию, загружает и расшифровывает пространство автоматически, импортирует структуру проектов, привычки/трекеры и задачи Google в отдельный зашифрованный account scope. Без подтверждённого bootstrap рабочие разделы закрыты. Изменения workspace уходят зашифрованным CAS/merge-запросом, изменения задач — через существующие серверные маршруты Google Tasks; неотправленные локальные записи остаются в outbox. Ранее созданные изолированные debug-записи не публикуются в аккаунт.
- Интерфейс аккаунта показывает до пяти дополнительных Google-аккаунтов и правила маршрутизации без необходимости входить в пять аккаунтов для теста. Язык RU/EN доступен на входе и в настройках. В календаре григорианский выбор открывает григорианский день с изображением дня недели, сохраняя сакральные и лунные сведения. Экран привычек, проекты и «Сегодня» используют расширенный контент одной темы.
- `assembleDebug`, `testDebugUnitTest`, `lintDebug` PASS после обновления экрана входа (lint: 0 ошибок, 42 предупреждения); ранее на устройстве прошёл изолированный `NativeUiTest` 6/6 и календарные тесты. Дополнительно на realme прошли 5/5 изолированных instrumented-тестов импорта, workspace CAS и Google task outbox на базе в памяти. Веб-проверки `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` (66/66), `pnpm build:beget` PASS. Никаких синтетических задач или привычек в реальный аккаунт не добавляли.

Ссылка на сайте подготовлена, но ещё **не опубликована**: release package `ru.genesis.calendar` требует отдельного OAuth Android-клиента для release SHA-1; на телефоне этот package сейчас занят старым TWA с другой подписью. Полный instrumented suite содержит зависимые от длительного alarm/device-state сценарии; их нельзя считать зелёными по результату остальных классов. SSH не использовался.
