## Что изменилось

- Одна шапка 56dp и основная навигация в Material drawer. Меню группирует разделы, выделяет выбранный маршрут и закрывается по Back, нажатию вне или выбору. Закрытый drawer не перехватывает жесты календаря и карты. Состояние разделов сохраняется при возврате.
- Светлая и тёмная STANDART-палитры взяты из существующего оформления сайта. Обычные формы имеют радиус 10dp. Inter обслуживает чтение и элементы управления, Source Serif 4 — крупные заголовки; полная кириллица встроена для offline. 72 официальные иконки Lucide с лицензиями и воспроизводимым manifest.
- «Сегодня» использует фактическую сегодняшнюю дату. Сохранились авторские изображения, но дополнительные материалы раскрываются; задачи расположены перед ритмами и чтением. Просмотр других дней остаётся в календаре.
- Плашка календаря, навигация периода и содержимое разделены. «Сегодня» находится рядом с периодом. В проектах, задачах, привычках и майндмепах частые действия видны, редкие собраны в контекстное меню.
- У редактора задачи постоянные «Сохранить»/«Отмена», обработка ошибки, защита несохранённого текста и повторной записи. Контекст личного/общего проекта сохраняется.
- Нативные дополнения соответствия: дневник, общие майндмепы, архив/корзина/серии/согласование/файлы общих задач, приватные E2EE-сообщения, условно доступный серверный помощник с review плана и администрирование по роли. Фюзис исключён из навигации.

Обоснования и фактически прочитанные источники: [3.0-design-decisions.md](3.0-design-decisions.md). Матрица 46 функций: [3.0-function-matrix.md](3.0-function-matrix.md). CODE в матрице означает реализацию, а не production PASS.

## Непроверенные состояния и риски beta

- Новый Google OAuth/восстановление сессии, двухустройственная синхронизация, повторные входы/выходы реального аккаунта; пользователь не разлогинивался ради теста.
- Реальные production роли, приглашения, revoke, сквозные операции файлов SAF/скачивание на другом устройстве, общие серии по серверному расписанию, согласование и permanent purge. Автотесты протоколов не заменяют эти roundtrip.
- Реальные сообщения между двумя аккаунтами и устройствами, истечение ключей/сессии, фоновые уведомления и process kill. WebCrypto Unicode backup/message/file interop проверен на Android, но не весь live transport.
- Live Gemini/GigaChat, отправка audio provider, реальные Google Tasks разрешения и длительные сетевые отказы. Server assistant появляется по реальному `/assistant/status`; локальный помощник сохранён.
- Production Admin, image SAF roundtrip. У API объявлений нет atomic CAS: клиент проверяет fingerprint перед записью, но не может устранить гонку сервера. Неопределённый POST автоматически не повторяется.
- Новые базовые строки и release notes покрыты 14 языками; часть новых Messaging labels для 12 дополнительных языков использует английский fallback. Полная foreign UI-приёмка не заявлена.
- Матрица была на API35; физический телефон API36 проверен отдельным ограниченным release smoke (см. ниже). API26 runtime, foldable, все сочетания access settings, самый большой production аккаунт и полный TalkBack не испытаны.

## Проверка владельцем на телефоне

1. Открыть меню, перейти в месяц и обратно в «Сегодня»: сегодняшняя дата должна остаться фактической.
2. Создать задачу в нужном личном проекте, изменить текст с открытой клавиатурой, проверить предупреждение при выходе и сохранение.
3. Переключить проект/раздел и вернуться: проверить проект, поиск и выбранную дату. Завершить задачу и перезапустить приложение.
4. Отметить привычку и открыть историю. Посмотреть те же экраны в тёмной теме и с увеличенным системным шрифтом.
5. На тестовых данных проверить общий проект, майндмеп, вложение и сообщение второму аккаунту; отдельно подтвердить синхронизацию на другом устройстве.

## Журнал завершения

**Собрано / установлено / запущено / основные экраны проверены на телефоне.** Подписанный APK из указанной Downloads-папки обновил realme RMX5000 (Android16/API36) с 2.9.7/102 до 3.0.0-beta.1/103 командой `adb install -r` с явно выбранным устройством. Сертификат установленного прежнего release независимо сверялся перед обновлением. Uninstall/clear/sign-out не выполнялись.

На телефоне после окна изменений 3.0 проверены реальные нативные «Сегодня», drawer, григорианский месяц с навигацией периода/днями и Настройки → Аккаунт GENESIS. Сохранённый профиль и состояние входа отображаются, повторная авторизация не потребовалась. Это подтверждает доступность локального профиля после обновления; новый Google OAuth, продление токенов и сквозная cloud synchronization этим не доказаны. Пользовательские записи вручную не создавались, не редактировались и не удалялись; полная сверка каждой записи не выполнялась.

Подписанный release также прошёл отдельный emulator smoke: обновление прежнего release, запуск, отображение экрана входа, живой процесс, без новой AndroidRuntime fatal error. В crash-buffer телефона были только исторические записи 15/17 октября, новые при текущем запуске не обнаружены. Частные XML/снимки/логи телефона сохранены только вне Git; публичный протокол — [3.0-device-smoke.md](3.0-device-smoke.md).
