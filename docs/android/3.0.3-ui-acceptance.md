## Исправления приёмки

Новый тест дневника уточнён: кнопка отмены выбирается внутри окна палитры, а не среди одинаковых надписей двух окон. Равенство кнопок проверяется по собственным размерам узлов, независимо от обрезания прокручиваемой области при открытой клавиатуре. Замер поиска майндмепов выполняется после стабилизации системной клавиатуры и сохранения снимка. Эти уточнения не меняют продуктовый интерфейс и не снимают проверку равных размеров.

Первый запуск матрицы оборвался вместе с процессом эмулятора; AVD перезапущен без wipe. Прерванный запуск не считается успешным. Исходный крупношрифтовой запуск с двумя ошибками замеров сохранён отдельно от подтверждающего прохода.

Один запуск механического детектора web-части дал только шесть advisory: пять существующих литералов цветов и один служебный размер шрифта. Ошибок не найдено; это не заменяет визуальную проверку. Цвета дневника по требованию пользователя имеют собственную палитру.

## Артефакты и публикация

Исходные фотографии: ignored `output/android-refinements-before/`. Нативные снимки после изменений: ignored `output/android-303/native/`; логи каждого сочетания: `output/android-303-matrix/`. На снимках только синтетические данные; фотографии пользователя не добавляются в Git.

Версия источников — 3.0.3/110. Существующий deploy.yml сохраняет прошлые неизменяемые APK/AAB, включая 3.0.2. Перед установкой требуется сравнение production SHA с master, health, public manifest, SHA-256 скачанного APK, package/version и прежнего release-сертификата; после `adb install -r` — package/version, firstInstallTime, dataDir и побайтовое совпадение установленного APK с публичным. Результат этих этапов сохраняется в `output/android-303/release-result.json`, после выполнения CI. Секреты в отчёт не включаются.
