# GENESIS 3.0: решения и проверка UX

## Уточнение стандарта 27 октября: исходники 3.0.1

`WorkspaceScreenHeader` передаёт название, контекст, Back и действия в единую шапку; standalone fallback сохраняется. Минимальная высота шапки72dp, целевые области48dp. Бургер без контрастной рамки; обновление аккаунта — прозрачное действие рядом с версией внизу drawer. Открытое меню закрывается свайпом влево.

`AffairsLayout` сохраняет радиус10dp обычных блоков/контролов, gutter16dp, gap8dp, sectionGap16dp и target48dp. Настройки сохраняют отдельно согласованный пользователем образец страницы привычек. Новые карточки привычек используют внутренний отступ12dp; хаос-бокс16dp. Inter и Source Serif4, существующие изображения, светлая и тёмная схемы сохраняются.

Привычки: «Сегодня / Все привычки», дневная сводка по repository goals независимо от игровых виджетов, оставшиеся/выполненные/раскрываемые незапланированные. Бинарное выполнение, качество, количество, длительность, интервалы и периодическая цель остаются в карточке своего типа. Count-only цель сохраняет одно выполнение вместе с заметкой явной кнопкой. История/статистика, подборка, развитие и данные имеют отдельные области. История из карточки открывает просмотр выбранной привычки, не запускает корректировку и сбрасывает дату другой привычки. Сохраняются фильтр, позиции областей и saveable-состояния карточек; выход из изменённой формы защищён подтверждением.

Общие дела: inline хаос-бокс пространства и проектного списка использует общие `chaosBoxColor/Border`, задачи и списки без собственного поиска и досок. Скрытие и положение сверху/снизу сохраняются отдельно для аккаунта и владельца области. Поиск, сортировка и фильтры проекта собраны в нижнем `WorkspaceSearchDock`. Это описание спискового режима; внедрение хаос-бокса во все представления проекта не заявлено.

Сегодня: изображение соответствует выбранному календарю; у лунного режима — существующая иллюстрация месяца. Наружное чёрное затемнение16%, внутренняя поверхность48%, inset8dp и тонкая золотистая рамка. Текст остаётся полностью открытым; суммарное затемнение под ним около56,3%. `TodaySolarTimes` объединяет восход/закат, `FlowRow` позволяет перенос при увеличении шрифта. Часы и навигация даты внутрь блока не добавляются. При выключенных сакральных возможностях сохраняется прежний упрощённый вариант.

Эти пункты описывают исходники. Два сценария `HabitWorkspaceReview6Test` подготовлены, но не запускались; новых Android-снимков нет из-за запрета сборок. Независимый reviewer проверил конкретные исправления статически. Старые результаты не объявляются приёмкой восстановленной композиции. Веб `DESIGN.md` и `.impeccable/design.json` сохранены.

Исходное исследование — 26 октября 2026; стандарт интерфейса уточнён 27 октября в продолжении. Backend не меняется. Отдельная узкая веб-правка скачивания описана в `3.0-review6/acceptance.md`.

| Проблема | Принцип | Решение GENESIS | Доказательство/план проверки |
|---|---|---|---|
| Основное меню, подменю и служебный footer постоянно занимают высоту | Содержимое главное; navigation отдельно от actions | Общая шапка min72dp, действия48dp; прокручиваемая ModalNavigationDrawer, статус и refresh внизу меню | Исторические снимки shell; новые композиции требуют отдельной runtime-проверки |
| Оформление первого блока дня расходится с последними решениями пользователя | Полный контекст дня и сохранение изображения | Полный текст всегда открыт; внутренняя рамка, яркие края изображения, общий восход/закат. Дата Today всегда фактическая | Исходники 27октября; новые Android-снимки пока отсутствуют |
| Общий свайпер перехватывает горизонтальные жесты календаря и карты | Предсказуемое платформенное поведение | Drawer по кнопке, отключённый root pager; жест карты не открывает drawer | Back/outside/select, pan/zoom, calendar period tests |
| Возврат сбрасывает состояние | User control; отсутствие повторного ввода | SaveableStateHolder по маршруту, сохранённые subsection и история drawer-переходов | Проект/фильтр/дата → другой раздел → назад, пересоздание Activity |
| Несколько почти одинаковых шрифтов и авторских UI-глифов | Consistency/recognition | Inter для чтения и контролов, Source Serif 4 для заголовков; фиксированная шкала; официальные Lucide | Полная кириллица в TTF, offline, source/license manifest; увеличенный шрифт |
| Несогласованные светлая/тёмная поверхности | Общая визуальная система | Material roles из фактического STANDART CSS, обычные формы/контролы 10dp | Контраст токенов и снимки обеих тем; авторские календарные цвета отдельно |

| Инструменты майндмепа отнимают полотно | Direct manipulation, контекстные действия | Компактный toolbar; поиск/экспорт/редкие команды в overflow; карта/структура | Панорама/масштаб/центр/редактор узла и клавиатура |
| Постоянная статистика привычек вытесняет выполнение | Frequent tasks first | Краткий дневной прогресс; подробности раскрываются | Отметка привычки и сохранённая история/ранги |

## Проверка сценариев

Снимки: узкий телефон 360dp и обычный 412dp; дополнительно 390, 768, 1440 в нативном тестовом viewport. Браузер не используется как подмена нативной проверки. Светлая/тёмная схемы, fontScale 1.3, длинный русский заголовок, IME, портрет/альбом. После первого согласованного просмотра исправления пакетом и подтверждающий проход.

Сценарии: выбрать день; создать личную задачу; создать в общем проекте с видимым контекстом; изменить и вернуться; сменить проект; найти/изменить узел; отметить привычку; отличить локальное сохранение/ожидание/ошибку/подтверждённую синхронизацию. Фактические результаты заносятся в 3.0-acceptance.md, непроверенные не становятся PASS.

Сравнение числа шагов и площади допустимо только при одинаковом устройстве, данных, теме и масштабе. Без выдуманных процентов удобства или участников.
