# Проекты и оформление: этап без Google-входа

Срез 24.09.2026, ветка `codex/android-native-bootstrap` поверх `origin/master` 30257ff. Изменения в Android и тесте ожидаемой версии; сайт/темы web не редактировались. Это рабочий этап, не приёмка полной синхронизации.

## Аудит до реализации

Web source of truth: `app/cloud-sync.ts` (`GenesisProject`, `GenesisCategory`, `TaskListProjectLink`, `GenesisTask`, `EncryptedWorkspaceStructure`) и `app/GenesisCalendar.tsx` (`DEFAULT_CATEGORIES`, дерево, Хаос-бокс, действия с проектами). Сервер `server/public/api/index.php` требует PHP session для `/workspace`, CSRF для записи; password login возвращает 410. Проекты/категории/привязки списков находятся внутри единого зашифрованного workspace-документа, задачи в отдельных серверных записях. Новые `projectId/categoryId/project` должны быть связаны с задачей; перенос одной лишь карточки проекта без задач недостаточен.

Перед этапом Android хранил задачи отдельно, без project/category ownership и без экрана «Проекты». Локальные разделы привычек и трекеров уже есть, но это не полный web workspace. Горизонтальная строка из шести вкладок на компактном Android не соответствует 3–5 пунктам Material navigation; новый раздел делает вопрос ещё заметнее. Этот системный недостаток оставлен для отдельной навигационной итерации, потому что новые AGENTS.md разрешают начать дизайн с одного экрана.

План первого экрана: native Compose «Проекты» с деревом, категориями, Хаос-боксом и списком задач выбранного проекта. Для Experimental — существующие web токены `--gx-color-panel`, `--gx-color-on-dark`, `--gx-color-accent-soft`, карточные радиусы и оригинальный `month-frieze-v2.png`. Standart продолжает пользоваться прежней Material-схемой; существующие изображения и авторские выборы даты/времени не тронуты. Экран использует touch-кнопки/чипы и LazyColumn, не HTML/WebView.

## Реализовано в исходниках

- `WorkspaceStructure.kt`: точные имена полей web `projects`, `categories`, `taskListLinks`; категории по умолчанию с исходными id/color/position; parent/category/status/tags/position; проверка отсутствующих ссылок, дублей и циклов. Зашифрованный `DocumentRecord(scope,"structure")`, local revision и outbox с состоянием `local`.
- `LocalTask`: сохранены совместимые `projectId`, `categoryId`, `project`; старые локальные записи читаются как Хаос-бокс. Сохранение задачи проверяет существование проекта и актуальную категорию; соответствующая метка проекта заполняется из структуры.
- Один новый экран `ProjectsScreen.kt`: создание/редактирование проектов и категорий, вложенность, выбор статуса, список связанных задач и переход к редактору задачи. Редактор задачи получил выбор проекта. Удаление проекта/категории и перенос Google списков остаются вне этого этапа. Визуальное развитие выполнено только для Experimental.
- `mergeIntoDecryptedWorkspace` — **чистая подготовка** фрагмента структуры: заменяет три поля в расшифрованном документе и сохраняет habits/mood/syncMetadata/будущие поля. Этот helper ничего не отправляет; перед серверной записью ещё нужны session, ключ, трехстороннее слияние, CAS/retry и полный task wire adapter. Локальный outbox не является синхронизацией.

## Проверки и границы

- Unit: exact roundtrip web-формы, исходные категории, порядок дерева, rejection cycle/orphan/duplicates, сохранение чужих разделов облачного документа, миграция старой локальной задачи. **54 unit tests PASS** в общей Android suite (0 failures); Gradle-команда — `STATUS.md`.
- Android instrumented тесты созданы для зашифрованной Room-записи структуры и назначенной задачи, stale revision, открытия native project editor. APK тестов собран, запуск на realme ожидает подключения устройства; наличие APK тестов не равно PASS на телефоне.
- Браузер был открыт на `https://genesiscalendar.ru`, но без Google-входа видна только страница входа. Forced CSS preview Experimental подтвердил `#245d59` и фон `#f3efe6`; это не тест Projects workspace. Скриншоты входа на 360/390/768/1440 px обеих тем — лишь справка по палитре. До/после Android Projects и визуальная проверка на телефоне пока NOT_RUN, если устройство не появится в adb.
- Не проверены: реальный web↔Android обмен, заполненный аккаунт/несколько аккаунтов, конфликт структуры и задач, удаление с сохранением связей, Google task-list links, tablet/rotation/TalkBack/крупный шрифт, браузерный Projects workspace обеих тем из-за отсутствия session.

Следующее независимое действие: завершить server-neutral импорт/экспорт полного workspace и task wire с сохранением неизвестных полей, затем изолированный CAS/merge harness. Включать live sync только после проверки реальной авторизованной сессии и ключа.
