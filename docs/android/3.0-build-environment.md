## Почему отдельный ручной workflow

Актуальный production deploy `40252785298` / `f69bc7b` — success. `GENESIS_DEPLOY_TARGET=hostinger`, `GENESIS_DEPLOY_ANDROID=false` подтверждены read-only.

`deploy.yml` запускается только push в master, объединяет build/deploy и при включении Android пишет стабильный APK и `android-update.json`. У него нет режима «подписать APK выбранной ветки и сохранить только artifact». Ни он, ни repository variables, ни стабильный update pointer не меняются ради пробной версии.

`.github/workflows/android-trial.yml` выполняется только вручную: выбранный ref → проверка trial-флага/версии → unit/lint/release build с существующей подписью → проверка certificate SHA-256, applicationId, beta-версии, возрастающего versionCode, non-debuggable и zipalign → GitHub Actions artifact APK + SHA-256 + публичные metadata/source/certificate. Нет сайта, SSH, Play upload, release publication или изменения update pointer. Артефакт хранится 14 дней; private signing file удаляется после Gradle.

GitHub должен сначала зарегистрировать файл workflow в default branch. Затем ручной запуск может выбрать рабочую ветку:

```powershell
gh workflow run android-trial.yml --repo nikitalexanderson-byte/calendar-genesis --ref codex/android-3-redesign
```

Добавление workflow только в новую ветку не гарантирует доступность `workflow_dispatch`. Регистрацию и запуск координирует основной агент после review/commit; в рамках исследования CI не запускался.

## Обновление и возврат

Перед `adb -s <нужный serial> install -r <apk>` сверить package, release certificate и versionCode с установленным приложением. Не удалять и не очищать приложение. Пробный release сохраняет package/подпись, но локальное сохранение данных и фактическую установку подтверждают отдельно, после проверки финального APK.

Понижение версии старым APK не считается проверенным rollback. Безопасный путь возврата — новая совместимая сборка с прежней подписью и большим versionCode, восстанавливающая стабильный интерфейс. Database rollback автоматически не выполняется. SSH не использовался.
