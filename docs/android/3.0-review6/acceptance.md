## Реализация

Восстановлены незакоммиченные правки майндмепов, общих дел и привычек. Приоритетная композиция привычек описана в [решениях](habits-decisions.md). Исправлены два обнаруженных при независимом ревью дефекта: явное сохранение count-only выполнения вместе с заметкой и контекстная история выбранной привычки. При смене привычки сбрасывается прежняя дата корректировки. Общий дневной блок получил рамку и солнечную группу во всех календарях, у Луны используется существующее изображение её месяца. Калькуляторы, repository callbacks, правила наград, права и формат данных не изменены.
