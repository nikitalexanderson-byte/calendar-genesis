# GENESIS Android 3.0.1 / 108: проверка перед публикацией

27 октября 2026. Пользователь явно разрешил штатную сборку, публикацию на genesiscalendar.com и обновление подключённого смартфона поверх установленного приложения. Этот checkpoint заменяет прежнее ограничение «без Android-сборки» в [исходном отчёте](acceptance.md) и [аудите восстановления](recovery-audit.md). Исторические сведения там сохранены как результаты отдельного этапа.

## Выпускаемые изменения

Общая навигация и шапка, самостоятельные блоки календаря, фактическая дата экрана «Сегодня», сохранённые изображения трёх календарей, структура привычек, контекстная история, count-only выполнение с заметкой, inline хаос-боксы общих дел, нижние инструменты поиска, жесты и палитра майндмепов. Полные требования и сверка: [большой промпт](request-global.md), [уточнения](request-refinement.md), [матрица восстановления](recovery-audit.md).

В круге GENESIS Enter/Space теперь останавливает всплытие события: выбор вложенного дня или пяты больше не заменяется выбором родительского месяца. Обводка остаётся только на геометрии сектора; цвет и контуры букв не меняются.

Скачивание с мобильного сайта использует `/api/android/download`; номер версии читается из опубликованного manifest. Панель через portal сохраняет размеры основной шапки. Новая UI-библиотека, миграции БД и ручные production-правки не добавлялись.

## Публикация и установка

Путь выпуска сохранён: commit/push → PR → master → существующий `deploy.yml`. Он собирает подписанные native APK и Play AAB, проверяет запуск обоих release APK в API35 до публикации, выполняет штатный backup server-only состояния и проверяет публичные hashes/redirect. Старые неизменяемые URL 2.9.0–2.9.7 сохраняются. Репозиторий остаётся Public, цель — Hostinger.

Перед установкой проверяются опубликованный manifest 3.0.1/108, SHA-256 APK и прежний release certificate `1e161d36f574b0560d808c7ee95e1abe98165b3385336d0276fb381dfd901cb8`. Установленная версия телефона — 3.0.0-beta.4/106 с этим же сертификатом. Разрешена только установка `adb install -r`, без uninstall и очистки данных. Идентификатор телефона и его приватные экраны не публикуются.

Это checkpoint до merge: успешные production deploy и установка не утверждаются этим документом. Их фактический результат сообщается после проверки `/deploy-meta.json`, `/api/health`, публичного APK и установленной версии.

## Ограничения

Не подтверждены свежий Google OAuth/обновление токена, двухустройственная синхронизация, все живые роли и отзыв доступа, полный набор привычек/таймеров, полный TalkBack/SAF, все иностранные локали, downgrade. Эта матрица не содержит нового снимка лунного hero экрана «Сегодня» (есть лунные месяц/год и unit-проверка выбора картинки). Установка поверх сохраняет Android data directory, но не является сверкой каждой пользовательской записи. Старый домен не переводится в объявление о переезде.

Прямой SSH не использовался. Штатный CI использует существующий SSH/rsync только в разрешённых корнях проекта.
