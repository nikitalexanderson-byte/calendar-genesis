# Нативная проверка 3.0.1/108

Синтетическое debug-пространство `internal-validation-v1`, API35, AVD Genesis_API35 с host GPU. Содержимое физического телефона и его идентификатор не сохранены.

`before/`: 6 исторических кадров предыдущего этапа из сохранённого worktree `android-3-redesign`, ширина390dp / font100, обе темы. Это предыдущий интерфейс и дата его тестового запуска, а не новая проверка 3.0.1.

`after/`: свежие PNG и JSON с runId `release-301-matrix`, `release-confirm`, `host-gpu-confirm` или `release-301-frame-fix`. Основной shell: 360/390/768dp portrait и1440dp landscape, font100, обе темы. Функциональные сценарии привычек, карты, общих дел и круга дополнительно проверяются на360dp/font130 в обеих темах. PNG основного shell получены из Compose root; отдельные Dialog/WebView/IME — Android screencap с metadata рядом. Исходный таймаут тёмного круга сохранён в matrix-логе; последующие frame-fix логи относятся к исправленному исходнику.

Имена старых review4/review5 сценариев отражают происхождение тестов; фактическая версия3.0.1/108, runId и параметры находятся в metadata и логах. Снимки карты/общих дел на360dp с runId release-301-matrix относятся к font130, хотя имя файла этих старых тестов ещё не содержит fontScale.

JSON основного shell перечисляет пройденные assertions и связанные кадры. `notTested` в этих JSON относится к конкретному emulator-сценарию. Установка на физический телефон и production проверяются отдельно после деплоя. В тестовом хранилище могут присутствовать синтетические записи прежних запусков; их заголовки не заменяют фактическую дату задачи.

Индекс: [screenshot-index.json](screenshot-index.json). Полные границы проверки: [release-checkpoint.md](../release-checkpoint.md).
