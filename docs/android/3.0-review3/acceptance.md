# GENESIS Android 3.0 beta.3 — изменения по скриншотам владельца

26 октября 2026. Продолжение `codex/android-3-redesign`, draft PR306. Только Android; сайт/backend, стабильный APK и update pointer не меняются. Предыдущие [beta.2 и её физическая проверка](../3.0-review2/acceptance.md) остаются историей.

## Реализованные изменения

- Общая шапка всех рабочих вкладок: текущий календарь → синхронизация. По нажатию календарь циклически переключается среди доступных; календарь ввода/повторов не изменяется.
- Голосовое управление временно исключено по прямому запросу владельца: нет микрофона, SpeechRecognizer, inline voice bar, записи серверной команды, разрешения RECORD_AUDIO или запроса speech service. Неактивные parser types сохранены; текстовый серверный помощник доступен через настройки аккаунта при прежних условиях.
- Карточка «Сегодня»: существующая картинка дня заполняет фон всей карточки; информация лежит на тёмной читаемой подложке. Название календаря — обычный текст. «Подробнее о дне» раскрывает описание; повторной сакральной кнопки нет.
- Пята, стихия и пифагорейский смысл показываются без дополнительного нажатия последним блоком «Сегодня», после совета дня (и имеющегося рекламного блока), если сакральный календарь и блок разрешены настройками видимости.
- В меню один «Календарь». Переключение месяца/года находится вверху раздела; обе старые плашки выбора календаря удалены по новому прямому указанию владельца. Это заменяет прежнее правило AGENTS об обязательной плашке. Информация месяца видна сразу; кнопки книжки нет.
- «Развитие» содержит привычки и сон/настроение. Стойхейон и Теокиклос доступны через один «Оракул» с внутренним переключателем.
- Подписи drawer всегда видны, включая аккаунты с прежним выбором icons. Переключатель «Подписи меню» удалён; сохранённая настройка не удаляется и не меняет независимые настройки других подменю.
- Исходный логотип в drawer круглый, с мягкой тенью 3dp и светлым/тёмным ободком. Сверка со стилем web-header-logo выполнена только чтением CSS сайта.

## Проверки и поставка

Целевая пробная версия — **3.0.0-beta.3 /105**. Результаты сборки, native UI-проверок, подписанного artifact и установки записываются ниже по факту завершения. Новая установка ещё не подтверждена. Стабильный CI-деплой остаётся выключенным: `GENESIS_DEPLOY_ANDROID=false`.

Пользовательские записи, сессия и настройки физического телефона не используются как тестовые fixtures. Новые снимки и native сценарии используют отдельный debug package и синтетическое локальное пространство.

Новый OAuth, реальная двухустройственная синхронизация, live AI-провайдеры, полный TalkBack и все иностранные локализации этим проходом не подтверждаются. Полная матрица: [3.0-function-matrix.md](../3.0-function-matrix.md), F40/F41 обновлены согласно явному исключению голосового управления. SSH не используется.
