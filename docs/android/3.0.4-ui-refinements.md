# GENESIS 3.0.4 — исправления по снимкам 27 октября

База — master `2c66f1c660100fa7a0458f826d8b40dd1f129190`, опубликованный выпуск 3.0.3/110. Изменения начаты после успешного deploy и обновления подключённого смартфона. Рабочая ветка `codex/android-304-ui-refinements`. Основной OneDrive checkout с незакоммиченными изменениями Фюзиса не изменялся.

## Аудит и принятый порядок

Снимки выявили несогласованность кнопок, слабое разделение текстов, лишние переключатели, недостаточный контраст и подмену стандартной сакральной практики привычкой из расклада. Сначала изменён один экран — сакральное описание года и его CTA; затем остальные указанные экраны последовательно, с существующими компонентами Universal UI.

Для истории привычек принят порядок: выбор привычки/периода → итоги → календарь выполнения → личные рекорды → сравнение → история отметок. Цели и объёмы, открытые периоды и неизвестная доступность сохраняют прежние расчёты и подписи.
