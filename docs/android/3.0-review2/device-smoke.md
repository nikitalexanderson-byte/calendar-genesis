## Ограничения

Это короткая проверка совместимого обновления и навигации. Сохранённая сессия доступна в интерфейсе; новый Google OAuth, обновление токена и реальный межустройственный cloud roundtrip этим не доказаны. Полнота пользовательской БД не исследовалась; private DB, токены и конфигурация аккаунта не читались.

На телефоне не создавались, не редактировались и не удалялись задачи, привычки, записи или сообщения. Тема, масштаб текста, календари и другие настройки вручную не менялись. Автоматическое поведение приложения при запуске и синхронизации сохраняется. Обе темы, IME, увеличение текста и остальные функции в этом физическом проходе повторно не проверялись; их отдельные эмуляторные результаты и ограничения приведены в [приёмке](acceptance.md).

Дообновленческий UI dump содержал launcher, поэтому не используется как сравнительный baseline профиля или содержимого. UI XML и диагностические файлы с телефона хранятся только в частном локальном временном каталоге вне Git; публичных снимков телефона нет. Исторический [протокол beta.1](../3.0-device-smoke.md) не переименовывался в beta.2.

Сайт, backend, production-БД, стабильный APK и update pointer не менялись. `GENESIS_DEPLOY_ANDROID=false` сохраняется; merge и production deploy не выполнялись. SSH не использовался.
