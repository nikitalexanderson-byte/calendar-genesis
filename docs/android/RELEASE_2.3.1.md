# GENESIS Android 2.3.1

Нативное Android-приложение, versionCode 34. Исправлена загрузка задач аккаунта в календарь и раздел «Задачи». Изменение сайта ограничено ссылкой на APK; действующий deploy workflow сохраняется, обновлены только версия, имя файла и проверяемый versionCode.

## Причина и исправление

В проверенном аккаунте сервер отдавал 39 задач, включая 7 невыполненных. Три идентификатора внешних событий имели длину 119 символов: сервер добавляет к исходному ID префикс Google-аккаунта. Android допускал только 100 символов, поэтому одна такая запись прерывала импорт всего списка. Успешный вход и синхронизация остальных данных скрывали отдельную ошибку загрузки задач.

- Импорт сохраняет полные идентификаторы длиной до 256 безопасных символов. Для изменения и удаления снимается только проверенный внешний префикс соответствующего Google-аккаунта; подтверждённый ответ сопоставляется с полным локальным ID. Существующий серверный контракт не меняется.
- Некорректная отдельная запись больше не отменяет загрузку остальных. Пустые заголовки получают отображаемое имя «Без названия». Неполный ответ не удаляет сохранённые задачи; локальные изменения и ожидающие отправки удаления защищены.
- Загрузка задач имеет отдельный статус и счётчики полученных и доступных на устройстве записей. Успешная отправка изменений больше не скрывает ошибку загрузки. Кнопки обновления запускают как отправку, так и получение данных.

## Проверка

- Samsung Galaxy A56, Android 16, реальное USB-устройство: 17 инструментальных тестов, PASS. Использован отдельный debug-пакет и изолированные тестовые аккаунты.
- Обезличенная структура всех 39 записей проверенного аккаунта импортируется полностью. Отдельный синтетический набор проверяет 39 задач, 7 невыполненных и три ID длиной 119 символов.
- Проверены отображение импортированных задач в списке и календарном окне дня, независимое сообщение об ошибке загрузки, сохранение локальных изменений и кеша при неполных/некорректных ответах.
- 144 native unit tests, PASS. Debug APK, androidTest APK, Android Lint и аудит переводов собраны/проверены успешно. Существующие предупреждения Lint остаются.
- `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` (67 тестов), `pnpm build:beget`, PASS. Локальный lint исключает временные каталоги и остатки других checkout; конфигурация CI не меняется.
- `git diff --check`, PASS. Изменений тем оформления, изображений и серверного кода нет.

Локальные протоколы и снимки находятся в `outputs/android/2.3.1/`: `device-tests-final.txt`, `after/2.3.1-imported-task-list.png`, `after/2.3.1-imported-calendar-tasks.png`, `after/2.3.1-task-download-error.png`. Тестовый снимок структуры данных и диагностические материалы не включаются в Git.

## Границы проверки

На момент подготовки релиза не проверены обновление на телефоне затронутого пользователя и реальное редактирование/удаление его задач. Исходные пользовательские задачи при диагностике не изменялись. Другие устройства, планшеты, альбомная ориентация, увеличенный шрифт и TalkBack для этого исправления повторно не проверялись.

SSH использовался для адресной диагностики только внутри разрешённого корня GENESIS: чтение SQLite в режиме read-only и получение задач через Google API. Секреты и содержимое задач не выводились; серверный код, задачи и БД не изменялись. Публикация подписанного APK выполняется существующим `.github/workflows/deploy.yml` после merge в master.
