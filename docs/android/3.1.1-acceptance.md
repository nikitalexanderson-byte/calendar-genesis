# GENESIS 3.1.1 — доработка и приёмка

Рабочая ветка: `codex/android-3-1-1-design`, база `origin/master` 7eb468e2.
Требования перенесены из последних сообщений пользователя в чате «Продолжить редизайн GENESIS» и дополнены в текущем чате 29 октября 2026. Этот документ фиксирует объём; незавершённые проверки не считаются успешными.

## Согласованный объём

- Проверка обновлений без действующей Google-сессии, ручной запуск, повтор после возвращения в приложение, корректные ошибки.
- Перетаскивание задач и списков вниз через прокрутку без обрыва; мгновенный визуальный перенос до завершения синхронизации во всех списках и досках личных и общих дел. Ошибки не скрываются.
- Обводка всех модальных окон в обеих схемах строго по внешней границе, без прозрачного зазора.
- Сохранённые советы дневника: звезда, закрепление, архив, удаление.
- Сообщения: подменю «Переписки / Контакты» общим компонентом календаря. Только в «Переписках» под ним четыре одинаковые кнопки с иконками: новый чат, обновить, устройства секретных чатов, прежняя переписка. В шапке эти действия убираются. Создание чата: профиль, группа профилей, PRO, глаз; доступные имена и подсказки сохраняются.
- Апрель: «От латинского — aperire — открывать, раскрывать», равномерно максимум в две строки. Июль: «Назван в честь Юлия Цезаря».
- Поделиться советом: изображение с существующей иллюстрацией, полным текстом и ссылкой на страницу приложения сайта, системная отправка; ссылка также передаётся текстом.
- В шапке привычек убрать переключатель схемы.
- Лунная информационная плашка в светлой схеме должна быть светлой.
- Иллюстрированные блоки всех трёх календарей: светлая полупрозрачная подложка в дневной схеме, читаемый тёмный текст, изображение остаётся видно.
- Из меню создания личных дел убрать переключение видимости хаос-бокса; сохранить управление на экране.
- Майндмепы по умолчанию открываются картой. Поиск узлов — общий раскрываемый нижний поиск; «Экспорт» открывает два формата, JSON и PDF. Меню «+»: мысль, затем добавление из дел. Кнопка главной мысли закреплена снизу слева, вне области прокрутки.
- Отмена соединения в майндмепе должна работать кнопкой, нажатием на исходный узел и Back. Связь создаётся выбором двух узлов. Долгое нажатие на пустое место показывает полноценное контекстное меню; не мешает перемещению узлов и масштабированию.
- Переход из года в месяц открывает начало месяца, не прокручивает к первому дню.
- Уменьшить пустоту над текстом блока дня во всех месячных календарях, сохранив иллюстрации и читаемость.
- Ошибка фоновой загрузки задач при отсутствии сети показывается внизу боковой панели, не над основными экранами.

## Выпуск и ограничения

Пользователь в исходном чате явно поручил после исправлений провести общий аудит, опубликовать 3.1.1 на сайте и в прежнем Google Play Alpha. В текущем чате поручено продолжить именно этот объём и учитывать последние замечания. Основные проверки выполняются на эмуляторе. В текущем чате пользователь отдельно поручил финальное обновление подключённого телефона поверх установленного приложения с сохранением данных. Позднее в этом чате пользователь заменил Realme на Samsung; обновлять Samsung. Повторная рассылка не входит в объём.

Перед публикацией обязательны frozen install, lint, web tests, build:beget, Android unit/lint/UI-проверки и проверка подписанных вариантов штатным путём. Подпись и package сохраняются, версия должна возрасти. Production Google Play и состав тестировщиков не меняются. После выпуска вернуть `GENESIS_DEPLOY_ANDROID=false`.

- Первичный итоговый Android UI-прогон 390/light: 15/15. Включены реальное исчезновение drag-source при lazy scroll, отложенный transport при переносе на доску, перенос в список, обновления без сессии, PNG/URI grants, календари и майндмепы.

Финальная Android-матрица 360/390/768/1440 × light/dark: **120/120**, затем font scale 1.3 при 390/light: **3/3**. Выполнены assembleDebug/assembleDebugAndroidTest/testDebugUnitTest/lintDebug. Подтверждены апрельская подпись в две строки, светлые и тёмные карточки трёх календарей, общие диалоги, поиск/палитра/масштаб майндмепа, действия переписок и переносы.

Штатный подписанный кандидат: [Actions 40910961174](https://github.com/nikitalexanderson-byte/calendar-genesis/actions/runs/40910961174), source 612e2859, success. Проверены checksum APK, package ru.genesis.calendar, 3.1.1/118 и прежний SHA256 сертификата 1e161d36f574b0560d808c7ee95e1abe98165b3385336d0276fb381dfd901cb8.

Два прерванных прогона исключены из успешных результатов: Windows зарегистрировала access violation в qemu-system-x86_64-headless.exe. После смены графического режима эмулятора оставшаяся матрица завершилась. Данные эмулятора не сбрасывались. Ручной SSH не использовался. Production-БД вручную не менялась.
