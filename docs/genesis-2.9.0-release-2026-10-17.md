# GENESIS 2.9.0 / 95 — выпуск 17 октября 2026

Пользователь уточнил порядок: оставшиеся функции основного промпта выполнять прежде всего в desktop/mobile web, нативное приложение — затем. Следующее явное поручение изменило ближайший приоритет: сегодня выпустить 2.9.0 на сайте, сохранить вверху символ и GENESIS, переместить только служебную строку вниз, проверять на эмуляторах вместо отключённых телефонов. Дополнительно мобильная веб-панель майндмепа должна показывать иконки без переносящихся подписей.

## Состав

- Нативные общие дела: пространство → проект → задача; общий компактный заголовок, поиск, применяемые/сбрасываемые фильтры, меню и раскрываемые дополнительные поля, отдельная полоса сохранения. Оригинальные данные, изображения и обработчики доступа сохранены.
- Личные дела: общий компактный заголовок и поиск по задаче/описанию/тегам/проекту/исходному Google-списку, меню создания проекта/списка. Майндмепы и сортировка находятся в одной прокручиваемой строке, без переноса слова при крупном шрифте.
- Карточки найденных/списковых личных задач используют AffairsTaskRow общих дел; TaskTitle сохраняет зачёркивание, непрочитанные комментарии и просрочку.
- Шапка независимо сохраняет оригинальный PNG-символ и GENESIS. Небольшой 192px PNG декодируется один раз без пустого асинхронного слота. Служебный статус и версия — под рабочей областью, не в строке меню. Название остаётся в одну строку.
- Mobile web до 760px: пять основных действий майндмепа сохраняют SVG, доступные названия/подсказки и область касания; подписи добавления/настроек скрыты. Desktop/tablet от 768px сохраняет текст.
- Новые переводы общих компонентов сохранены в существующем словаре affairs. Web использует их только как дополнение отсутствующих UI-ключей, сохраняя прежние переводы. Отдельный affairs-copy chunk удерживает лимит JS 350000 байт без его повышения.
- Версия 2.9.0, versionCode 95; существующий deploy workflow формирует подписанные native APK и Play AAB. Серверные схемы, секреты и протокол workspace этим выпуском не меняются.

## Проверки до публикации

- `pnpm install --frozen-lockfile`, lint (две исходные img warnings), 304 web tests, i18n 14 языков и build:beget прошли. Precache: 77 обязательных entry assets, 203 изображения; крупнейший JS 349901 байт.
- 284 JVM tests, debug APK и instrumentation APK успешны.
- API35: шапка/футер, landscape, unified personal, shared workspace и Android affairs прошли. Три старых проверки ProjectsFlow ожидали уже отсутствующее раскрытие Хаос-бокса и null вместо сохранённого explicit-inbox ID; обновлены под действующий контракт. После этого 6/6 сценариев переноса/шифрованного сохранения/редактора прошли. Дополнительная проверка Responsive оборвалась при завершении процесса эмулятора Windows; успешным результатом она не считается.
- API28: 11/11 шапка + unified personal + shared workspace; 6/6 ProjectsFlow. Дополнительный финальный shell-проход — 4/4: шапка в двух схемах и с иконками/текстом меню, повороты/все разделы/клавиатура, завершение/отмена выполнения, закрытие несохранённого редактора.
- API28 с geometry 800dp и fontScale 1.3: 2/2 полная оболочка и Responsive, обе ориентации. Геометрия и масштаб после проверки возвращены.
- Первые снимки эмуляторов перекрывались системными ANR окнами Launcher/System UI. Они не являются визуальной приёмкой. После закрытия системного окна ожидания сделан повтор и сохранены чистые снимки. Ошибка приложения этим не подтверждена.
- Chromium и Firefox mobile/desktop web: обе схемы ×360/390/430/768/1440; без горизонтального переполнения, все пять действий имеют имена и размер не менее44px, на телефоне одна строка и скрытые подписи, на больших ширинах подписи сохранены. Открываются настройки карты и выбор дела.

Артефакты (ignored): `output/ui290-release-*`, `ui290-api28-*`, `ui290-api35-*`, `output/playwright/ui290-mindmap-icons-*`, `ui290-emulator28-brand-*`, `ui290-emulator28-tablet-large-*`. До изменения шапки имеется ранний кадр с системным ANR; он отмечен как непригодный для чистого сравнения. До/после общих/личных экранов сохранены предыдущими проходами Samsung в mobile audit.

## Границы и дальнейшая работа

Физические Samsung/Realme в этом выпуске не использовались. Реальный Google OAuth и полная account offline/reconnect-синхронизация с отдельным живым аккаунтом, TalkBack, Safari/iOS и весь перечень ролей не проверены этим срезом. Fake-provider UI tests не выдаются за внешние интеграционные проверки. Подпись, minified ART и startup официального APK подтверждены успешным штатным CI; обновление на API28 описано ниже.

Выпуск не закрывает оставшиеся E4/E5/F/C/G. Незавершённая web-интеграция E4 сохранена отдельно в `codex/web-habit-lifecycle`, checkpoint `c3d084a` (включая пока неопубликованный protocol7), и в 2.9.0 не включена. После выпуска продолжаются оставшиеся функции основного промпта для веб-версии. Полная переделка всех личных редакторов/контекстных меню также не объявляется законченной.
