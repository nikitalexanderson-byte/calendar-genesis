## Аудит тесных групп действий в диалогах

Поиск охватил 382 Kotlin-файла приложения, включая 210 файлов Android UI и диалоги аккаунта. Восемь групп переведены на общий `DialogActionRow`: одинаковые места в одном ряду, без обводок, с локализованными доступными именами и подсказками. Подтверждения с двумя действиями сохраняют короткие текстовые подписи.

1. Сохранение черновика дневника: продолжить, отменить изменения, сохранить черновик.
2. Копирование/перенос личной задачи в общие дела.
3. Повтор/удаление сохранённого черновика команды.
4. Сохранение копии шаблона при выходе.
5. Удаление повторения/серии из календаря.
6. Удаление повторения/серии из списка задач дня.
7. Удаление повторения/серии из редактора задачи.
8. Выбор версии телефона/сайта при конфликте синхронизации; необходимость просмотреть все конфликты перед подтверждением сохранена.

Сохранение черновика имеет собственную иконку сохранения; удаление отличается цветом. Верхнее закрытие диалога остаётся крестиком без обводки.

## Исправление загрузки восполнения

Исходный регулярный разбор длинного авторского каталога воспроизводит `StackOverflowError` в JVM со стеком 256 KiB. Разбор с неперебираемыми блоками возвращает те же 384 двуязычные записи при том же ограничении. Дополнительно на Android API 35 подтверждён `PatternSyntaxException`: ICU требует экранировать завершающую фигурную скобку, которую JVM допускает без экранирования. Скобка экранирована. Добавлен регрессионный тест длинных абзацев с кавычками и переносами; существующая проверка сопоставления всех 14 языков сохранена. Путь каталога менять не потребовалось.
