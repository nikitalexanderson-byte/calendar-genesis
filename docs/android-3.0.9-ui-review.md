Рабочая ветка: `codex/android-3-0-9-calendar`, от `origin/master` `1bc4e038`.

## Аудит тесных групп действий в диалогах

Поиск охватил 382 Kotlin-файла приложения, включая 210 файлов Android UI и диалоги аккаунта. Восемь групп переведены на общий `DialogActionRow`: одинаковые места в одном ряду, без обводок, с локализованными доступными именами и подсказками. Подтверждения с двумя действиями сохраняют короткие текстовые подписи.

1. Сохранение черновика дневника: продолжить, отменить изменения, сохранить черновик.
2. Копирование/перенос личной задачи в общие дела.
3. Повтор/удаление сохранённого черновика команды.
4. Сохранение копии шаблона при выходе.
5. Удаление повторения/серии из календаря.
6. Удаление повторения/серии из списка задач дня.
7. Удаление повторения/серии из редактора задачи.
8. Выбор версии телефона/сайта при конфликте синхронизации; необходимость просмотреть все конфликты перед подтверждением сохранена.

Сохранение черновика имеет собственную иконку сохранения; удаление отличается цветом. Верхнее закрытие диалога остаётся крестиком без обводки.

## Исправление загрузки восполнения

Исходный регулярный разбор длинного авторского каталога воспроизводит `StackOverflowError` в JVM со стеком 256 KiB. Разбор с неперебираемыми блоками возвращает те же 384 двуязычные записи при том же ограничении. Добавлен регрессионный тест длинных абзацев с кавычками и переносами; существующая проверка сопоставления всех 14 языков сохранена. Путь каталога менять не потребовалось. Причина конкретного сбоя на телефоне ещё требует проверки на устройстве; скрытие входа при ошибке устранено независимо от причины.

## Проверки и ограничения

- `pnpm i18n:audit` — успешно: русский, английский и 12 дополнительных языков.
- `pnpm lint` — ошибок нет; два прежних предупреждения `no-img-element` в веб-компонентах майндмепов, которые эта задача не меняет.
- `node android/tools/export-theokyklos.mjs --check` — 14 секторов, 28 практик; содержимое каталога не изменилось.
- Исходный и исправленный разбор сопоставлены на авторском каталоге со стеком 256 KiB.
- Проверка исходников диалогов: все восемь найденных тесных групп используют общий ряд.
- `:app:testDebugUnitTest` — 857 проверок: 849 успешно, 8 дополнительных opt-in проверок пропущены, ошибок нет.
- `:app:compileDebugAndroidTestKotlin` — успешно. Это компиляция сценариев, не запуск интерфейса на устройстве.

Предоставленные пользователем снимки «до» сохранены в ignored `output/android-309/before/`. Новые снимки «после» не получены: APK 3.0.9 не собирался и не устанавливался. Визуально ещё не проверены светлая/тёмная схемы при 360, 390, 768 и 1440dp, увеличенный системный шрифт, клавиатура, оба состояния меню и жесты на Realme. До выпуска необходима нативная визуальная приёмка; браузерный рендер не подтверждает Compose-интерфейс.

Web-layout и production в этой задаче не изменялись. SSH не использовался. Перед будущим деплоем остаются обязательные frozen install, lint, web tests, build:beget и проверки подписанных Android-пакетов по действующему процессу выпуска.
