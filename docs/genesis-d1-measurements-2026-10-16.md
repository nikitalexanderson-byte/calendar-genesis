# D1: измеряемые привычки и согласованные изменения интерфейса

Дата: 16 октября 2026. Ветка `codex/habit-measurements`, база `1f21e1b5864fdf009a46685803d267872cc814a0`. Код подготовлен к публикации через существующий Deploy GENESIS. Android — 2.8.5 (85). Сам выпуск не закрывает D2, полный D3, E, F, C и G.

## Изменения

- Сохранён бинарный тип привычки; добавлены количество и длительность, единица, дневная цель, быстрое добавление и ручной ввод. Значения хранятся целыми тысячными, длительность — в минутах. Несколько записей суммируются; частичное выполнение, превышение цели и качество показываются раздельно.
- Новые записи и исправления имеют устойчивые ID. Удаление/восстановление записи сохраняет исходные события. Независимые записи объединяются, конкурентные исправления требуют выбора. История цели/расписания сохраняет прежний смысл результатов; изменения существующей привычки вступают в силу со следующего дня.
- Запись и подтверждение качества завершаются после долговечного сохранения зашифрованной offline-очереди. Ошибка хранилища сохраняет ввод для повторения. Повреждённое пространство не заменяется пустым: показаны восстановление и скачивание исходного JSON.
- Web и Android понимают одни и те же значения, события и версии правил. Новые измерения не удваивают дневной XP; исторические и импортированные корни не становятся источником XP через последующую маленькую ручную запись. Полная проверка Лавров/квестов и всех новых источников остаётся в D3/F3.
- В верхней панели порядок: личный аккаунт (человечек), установка приложения при доступности, микрофон. Экспорт `.ics` перенесён в «Настройки → Аккаунт GENESIS», рядом с данными аккаунта.
- Видимый раздел/пункт меню «Сакральное» переименован в «Оракул» на 14 языках. Название календаря «Сакральный» сохранено, внутренние ключи совместимости не переименованы.
- В майндмепе видна группа «Правки»: отмена и повтор, Ctrl/Cmd+Z, Ctrl+Y, Ctrl/Cmd+Shift+Z. История ограничена 50 действиями; текстовый ввод объединяется в пределах 900 мс. Ссылочные задачи не откатываются; обычное редактирование текста и другие диалоги сохраняют свои сочетания клавиш.
- Уведомления по умолчанию справа снизу. Перетаскивание на верхнюю панель закрепляет иконку размером 44 px; окно открывается под ней и сворачивается к ней. Перетаскивание обратно и кнопка открепления возвращают свободное положение. Аккаунт хранит закрепление и позицию. Контрастная рамка, изменение размера, прокрутка и краткое превью сохранены; мобильное превью скрыто. Заголовок занимает отдельную строку, действия — следующую.
- Исправлены подписи минут в английском, греческом и японском каталогах и возврат русского исходного текста в native translation helper.

## Совместимость и миграция

`065_workspace_writer_protocol.sql` добавляет минимальную версию writer-протокола для зашифрованного пространства. До появления новых данных старые writers продолжают работать. После появления измерений/истории правил требуется protocol 2; старый клиент не может стереть эти поля. Пол повышается монотонно, перенос аккаунта учитывает его. Android 85 поддерживает protocol 2; пользователям прежнего клиента требуется обновление для записи в такое пространство.

Миграция не расшифровывает и не переписывает содержимое. Проверены согласованная SQLite-копия до миграции, неизменность opaque-документа, совместимый старый SQL до активации, отказ старому writer после активации и защита при откате кода. Code rollback — `git revert` через workflow. Автоматический rollback БД запрещён; восстановление runtime-копии требует отдельного согласования. Production-БД вручную не изменялась. SSH на этом этапе не использовался.
