# Согласованный выпуск GENESIS: сайт, затем приложение

Источник требований — сообщения пользователя 7–8 октября 2026. Порядок: рабочий переезд на genesiscalendar.com → публикация всего веб-обновления → обновление Android. Объявление на genesiscalendar.ru включается только после проверок Google-входа, синхронизации приложения и сохранения тестового трека. Все новые замечания дополняют этот выпуск.

## Сайт

- Единственная базовая тема Standart, светлый и тёмный варианты. Перенести согласованные функциональные преимущества Experimental, затем убрать экспериментальный выбор. Сохранить все изображения, смысловые места ассетов, данные, календарные режимы и независимость отображения/ввода дат. Общая типографика, размеры заголовков/подзаголовков/текста/кнопок/отступов; качественные шрифты с кириллицей. Убрать дублирующие вступления настроек.
- Сегодня: кнопка перехода к делам по общему дизайн-коду; переключатель Григорианский / Сакральный / Лунный, показывающий только фактический сегодняшний день. Настроение выбирать через модальное окно, полный набор эмодзи раскрывать дополнительно, помнить раскрытие на устройстве или последний собственный вариант.
- Дела общие: пустой экран содержит только «Создать пространство» и «Присоединиться к пространству». Создание в модальном окне; присоединение открывает список приглашений с понятным пустым состоянием. При наличии пространств — вход в выбранное пространство.
- Создатель пространства приглашает участников по Gmail, пока без отправки email. Проекты по умолчанию свёрнуты, состояние раскрытия сохраняется на сервере для пользователя.
- Проект можно создать деревом произвольной вложенности или с досками: три по умолчанию, максимум 30. В доски помещаются проекты, задачи и списки задач; их можно перемещать, в том числе из личного пространства. Хаос-бокс с неназначенными задачами присутствует у обоих представлений.
- Настройки проекта и команды пересобрать. Настройки каждой доски открываются её модальным окном: имя, статус, цвет, изображение и связанные параметры. Упростить перенос личного проекта в общий, сохраняя данные и связи.
- Создание задачи: основные поля — название, проект, срок; остальные раскрываются по запросу. Сохранение доступно в пределах окна, включая масштаб 200% и небольшую высоту.
- Задачи внутри проектов: читаемые единые размеры текста и метаданных, без гигантских прописных дат/email. В мобильных категориях название не перекрывается действиями; редактирование и удаление доступны.
- Кнопка аккаунта сразу открывает личный кабинет с настройками.
- Завершение проекта: понятная кнопка, динамическая галочка на месте круга и сообщение «Проект завершён». Завершённая карточка занимает всю доступную ширину, справа нет пустой колонки.
- Стойхейон: вращающийся круг из 24 греческих букв виден на фоне при любом разрешении.
- Админка: отдельные разделы «Реклама» и «Аналитика». Две пользовательские таблицы объединить со всеми основными показателями; количество действий — под раскрывающимся спойлером.
- Проверить удаление задач и синхронизацию, исключить возвращение удалённых задач из старых локальных копий/Google.
- Публичные тексты: политика конфиденциальности, соглашение, поддержка, удаление аккаунта и пояснения о входе описывают genesiscalendar.com, Hostinger и Google; без Яндекса и прежнего домена.
- Проверки светлой и тёмной темы на 360, 390, 768, 1440 px, читаемость, переполнение, действия, модальные окна, масштаб 200%; сохранить до/после и перечислить непроверенные состояния. Frozen install, lint, tests, build, Git/Actions/production SHA и health.

## Android — после сайта

- Вместо отдельных «Задачи» и «Проекты» — единый раздел «Дела», вкладки «Личные» и «Общие». Задачи, проекты и списки образуют одну систему. Настройки видимости меню управляют новой структурой. Перенести новый UX общих пространств/проектов/досок с сайта.
- При свайпе активный пункт меню подсвечивается и включается сразу, без задержек и лагов.
- Для первого запуска/чистой установки: отображение меню — иконки; подменю настроек — подменю, иконки; переход между вкладками — общий свайп; связь меню и подменю — общая обводка; календари отображения и ввода по умолчанию — григорианские. Существующие явно выбранные пользователем настройки сохраняются.
- Сегодня: «Подробнее о дне» отсутствует в григорианском и лунном режимах. В сакральном режиме раскрытие содержит только сакральный календарь и смысл дня до пифагорейского смысла включительно, без лунного и григорианского блоков.
- Лунный режим Сегодня: главный блок содержит уникальные сведения из прежнего лунного блока, включая изображение фазы; исключить повторяющиеся тексты и карточки.
- Сохранять отдельные блоки нативных месячного/годового календарей и обычное поведение прокрутки. Сохранить package, подпись, аккаунты, данные, текущий Play testing track и тестеров. Новый origin — genesiscalendar.com; язык перед входом определяется регионом устройства, ручной выбор имеет приоритет.
