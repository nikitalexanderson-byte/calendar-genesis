# G3: настройки правил из архива и корзины

Основание — master `588d894` после G4 PR #203. [Аудит до реализации](genesis-workflow-restore-audit-2026-10-19.md) обнаружил серверный repair API без доступного веб-входа: обычный snapshot скрывает удалённый проект. Срез добавляет вход к существующим настройкам и сохраняет серверные ограничения восстановления.

## Изменения

В завершённых проектах, архивной задаче и строке корзины появились иконки «Процесс и лимиты» с общей подсказкой. Они отображаются при текущем manageProjects. Открывается существующий редактор workflow, после закрытия сохраняются исходный архив/корзина и фокус кнопки. Изменение правил не восстанавливает объект автоматически: пользователь сохраняет настройки и отдельно повторяет восстановление.

GET workflow теперь отдаёт согласованную минимальную projection: текущие права и идентичность проекта, его статусы и определения полей только этого проекта/пространства. Скрытые задачи, участники и обычный project snapshot для корзины не загружаются. Новые поля в read payload аддитивны; PUT, CAS, receipt/replay и история сохраняются. Список завершённых проектов возвращает текущие permissions; строки корзины содержат разрешение на управление правилами и имя соответствующего проекта.

Отказы восстановления по WIP/обязательным полям получают существующие локализованные объяснения workflowError. Права проверяет сервер; наличие ранее загруженной кнопки их не выдаёт. При потере доступа редактор очищается и закрывается. Новых миграций, writer protocol или Android release нет.

Повторное открытие редактора проверено после обновления родительского экрана: обработчик потери доступа хранится через ref, поэтому изменение callback не перезапускает и не отменяет загрузку. На ширинах до 420 px поля представлены одной колонкой, чтобы длинные подписи не распадались по буквам.

## Проверки

Frozen install, lint (0 ошибок, 2 прежних img warnings), 328/328 tests с i18n audit и production build:beget прошли. Precache сохраняет 90 обязательных entries и 203 visual assets; largest JS — 349901 bytes. Общий tsc сохраняет 9 прежних диагностик вне изменённых файлов.

Shared-workflows проверил 14 групп, включая минимальный live/archive/trash context, scoped definitions, текущие права, revoke, read-only viewer, guarded restore, конкурирующий WIP, CAS/replay, bulk/C1/C2/C5. Дополнительно прошли shared-task-lifecycle, shared-project-access, shared-projects, shared-sprint-reports и shared-planning. Серверные проверки используют отдельную synthetic CI DB; browser configuration восстановлена.

Перед изменением UI сохранены 16 before PNG: архив/корзина, две схемы ×360/390/768/1440. Все 14 языков проверены в реальном браузере: заголовок и черновик WIP сохраняются, overflow отсутствует. Сценарий темы исправлен на переключение в проверяемом окне: тема другого окна не является изменением DOM текущего окна. Никакой правки приложения ради этого assertion не делалось.

Browser → HTTP → PHP → SQLite подтвердил 13 сценариев: read-only viewer видит реальные строки корзины без входа к управлению и получает 403 на PUT; обе темы ×4 ширины; четыре настоящих восстановления. Для архива и корзины задач получен отказ WIP1, затем через UI сохранён WIP2 и восстановлен прежний task ID. Для завершённого и удалённого проекта получен отказ обязательного описания, правило явно исправлено, восстановлены прежние project/task IDs. Закрытие редактора возвращает архив и фокус. Для настроек удалённого проекта выполнено 0 запросов обычного project snapshot. После исправления загрузки повторно прошли 328/328 tests; последняя сборка содержит мобильную колонку.

Финальное подтверждение прошло ещё 8 случаев в обеих схемах ×4 ширины: нет overflow, мобильные подписи выровнены одной колонкой, кнопка закрытия не меньше 44 px, Escape сохраняет исходный архив. Проверены фактические позиции label; computed gridTemplateColumns у fieldset может содержать пробелы внутри minmax и не используется как счётчик колонок. Final PNG сохранены отдельно; дальнейшая косметическая полировка этого экрана не выполняется.

Доказательства: `output/workflow-restore-{install,lint,tests,build,php,types,loader-lint,loader-build,final-tests,final-build}.log`, `output/playwright/workflow-restore-before-result.log`, `output/playwright/workflow-restore-locales-result.json`, `output/playwright/workflow-restore-after-result.log`, последующие confirm result/final PNG.

## Остаток и совместимость

G3 остаётся частичным: durable draft после cold offline/reload, native и общая приёмка ещё открыты. В этом срезе не проверяются Safari/Firefox, физический Android, screen reader, 200% zoom и внешний Google roundtrip. Ранее подтверждённые CAS/lost-response сценарии общего редактора не заменяют будущую приёмку durable drafts.

Сохранены protocol6 и установленный Android 2.9.0/95. Runtime secrets и production DB вручную не менялись, SSH не использовался. Rollback — git revert через существующий deploy workflow; database rollback не нужен.
