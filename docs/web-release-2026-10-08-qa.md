# Веб-выпуск GENESIS: проверки и границы

Согласованный объём: [release-web-android-2026-10-08.md](release-web-android-2026-10-08.md). Production после переезда: https://genesiscalendar.com, Hostinger. Старый веб-сайт пока продолжает работать; его API обращается к новой базе. Android UX выпускается после веб-сайта.

## Реализовано

Единая Standart в светлом и тёмном вариантах, переход со старого Experimental с сохранением цветовой схемы; Source Sans 3 и Literata с локальными файлами и OFL. Общая типографика, кнопки, мобильные категории, карточки задач и завершённые проекты на всю ширину. Кнопка аккаунта открывает настройки. Сегодня переключает три календаря, настроение выбирается в модальном окне. В привычках доступны вкладки режимов. Создание личной и общей задачи начинается с основных полей; подробности раскрываются отдельно.

Общие дела начинаются с пространств: создание и приглашения в отдельных окнах, Gmail-приглашения внутри GENESIS без email-отправки. Дерево произвольной вложенности и проекты с тремя досками по умолчанию, максимум 30. В досках размещаются проекты и контейнеры списков задач. Настройки проекта, команды и каждой доски открываются отдельно; доска имеет имя, состояние завершения, цвет и изображение. Вид раскрытия хранится на сервере для каждого пользователя. Упрощён выбор пространства/проекта/доски при передаче личного проекта. Для личных записей с полями, которые пока не представлены в общей модели, доступна копия основных полей с сохранением оригинала; полный перенос таких записей блокируется для предотвращения потери данных.

Админка разделена на рекламу и аналитику, метрики пользователей и Android объединены, таблица использования функций свёрнута. В Стойхейоне виден вращающийся круг из 24 букв. Вход и настройки аккаунта используют Google; политика, соглашение, поддержка и удаление аккаунта описывают новый домен и Hostinger.

## Проверки

- Frozen install, ESLint, 110 тестов, `build:beget` и проверка обязательных офлайн-файлов.
- Изолированные PHP/SQLite проверки существующих общих проектов, приглашений, разграничения доступа, состояния раскрытия, будущих участников, настроек досок, ограничения 30 и удаления аккаунта. Приглашение от потерявшего права отправителя не принимается.
- Playwright с синтетическим аккаунтом и перехватом API: светлая и тёмная схемы, 360/390/768/1440 px; личные/общие дела, Сегодня, привычки, Стойхейон. Горизонтального переполнения нет, все 24 буквы находятся внутри фонового блока.
- Проверены выбор календаря Сегодня, настроение, компактная форма и доступность сохранения при масштабе 200% и высоте 500 px, приглашения без записей, настройки проекта/доски, разделы админки, завершение и ширина завершённых проектов.
- Четыре публичные страницы проверены по отображаемому тексту: Яндекс, Beget и старый домен отсутствуют.
- Снимки до/после: `output/playwright/web-standart/`. Это локальные артефакты проверки, а не production-данные.

## Миграция и откат

034 — добавочная миграция: существующие проекты/задачи не удаляются, старые Android-клиенты могут не передавать новые поля. Перед применением workflow сохраняет config и согласованную SQLite-копию через существующий backup helper. Код откатывается `git revert` и штатным workflow; добавочные таблицы/поля остаются совместимыми. Восстановление БД не выполняется автоматически.

## Ещё не подтверждено

Новый Android UX, реальный вход и синхронизация на Android-устройстве и публикация новой сборки в существующий Play testing track. Поэтому объявление на .ru не включено. Браузерные проверки изменения командных данных выполнены на синтетическом аккаунте; production-данные пользователей не использовались для тестовых изменений. Полный перенос личных задач с повторениями/Google-связями и связанных личных списков остаётся ограничен сохранением исходных данных.

Для этого веб-выпуска SSH не использовался. При самом переезде SSH использовался для переноса согласованной базы, закрытой конфигурации и проверки runtime; дальнейшая публикация выполняется через GitHub Actions.
