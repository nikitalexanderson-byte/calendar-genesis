## Аудит до изменений

`SharedTemplatesScreen` использует DialogProperties с platform default decorFitsSystemWindows, статический заголовок/ошибку, прокручиваемую форму и нижний блок preview/submit/discard. Существующий opt-in keyboard test проверяет появление клавиатуры, но получает размеры Submit из Compose и нажимает через Compose touch. Он не доказывает, что отдельное системное IME-окно не перекрывает полную кнопку. Пройденные C2 regression tests этого пробела C1 не закрывают.

Сначала усиливается только тест и снимается исходное состояние. Проверяются native accessibility window IME, фактический clickable ancestor Submit, полные48dp и полное активное поле над клавиатурой. Нажатие выполняет UiDevice; результат подтверждается реальным HTTPS/PHP/Keystore journal. Сценарии — сохранение копии шаблона и создание задачи из шаблона. При необходимости исправляется только это окно, с сохранением независимых календарей и явного preview.

## Direction contract

THESIS: редактирование шаблона и его применение доступны с открытой клавиатурой без потери ввода и скрытой основной кнопки.

OWN-WORLD: действующие native STANDART light/dark, Material typography, Affairs controls/disclosures/tooltips, минимум48dp. Существующие ассеты и canonical DESIGN/sidecar сохраняются.

STORY: открыть копию или применение → ввести название → при применении явно обновить preview → нажать доступную нижнюю основную кнопку → увидеть подтверждение одной операции.

FIRST VIEWPORT: нормальная форма сохраняет свою композицию. Низкий landscape с IME отдаёт доступную высоту активному полю и основной кнопке; вторичные действия остаются достижимыми.

FORM: code-led исправление одного существующего окна, без нового визуального мира, UI-библиотеки, ассетов или comp.

FINISH: системные proof/оригиналы на API28/API35, phone/tablet и обеих ориентациях/схемах, увеличенный шрифт; функциональные регрессии, ограниченный finish review с явным указанием его независимости и непроверенных состояний. Реализация UI начинается только после исходного доказательства и чтения craft-floor.
