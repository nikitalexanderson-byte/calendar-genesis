# Переводы привычек и панель общих дел — 18 октября 2026

Пользователь обнаружил русские названия/описания активированных встроенных практик в английской версии и попросил внимательно проверить переводы, сохраняя пользовательские тексты на исходном языке. Дополнительно согласован порядок панели: «Майндмепы» слева внутри «Проектов», затем «Пространства», затем поиск.

## Отображение встроенных текстов

Причина воспроизведена в браузере на исходной сборке: активированные Артемида/Аполлон показывали сохранённый русский текст, тогда как каталог уже содержал английский перевод. Единый `habitDisplayText` проверяет устойчивый sourceTemplateId/sacredPracticeId и каждое поле отдельно. Только точное совпадение со встроенным текстом на одном из 14 языков отображается в текущем переводе. Пользовательская привычка без происхождения из шаблона, изменённое название/описание и заметки остаются как введены. Stored workspace, ID, цели, история, награды и синхронизация не переписываются при смене языка.

Подключены карточки и библиотека, сакральный выбор, Теокиклос, статистика/мозаика, история, напоминания, количественные/периодические элементы управления, таймеры и completion feedback. Редактор показывает перевод неизменённого встроенного поля, сохраняя исходное значение в draft до фактического ввода пользователя. Историческое название таймера переводится только при совпадении с исходным текстом шаблона.

Три новых модельных сценария используют реальные словари: все сакральные практики × 14 исходных языков × 14 выбранных языков; обычные шаблоны с русским/английским сохранённым текстом; пользовательские поля, включая совпадение с известной строкой интерфейса. Проверяется отсутствие изменения входных данных.

## Панель проектов

Порядок DOM и клавиатуры совпадает с визуальным: блок проектов начинается кнопкой майндмепов, затем выбор/создание проекта, корзина/архив; дальше пространство и его действия, затем запрос задач. Из SharedTaskViewControls убрана отдельная перестановка майндмепов через viewport subscription. Обработчик открытия карт сохранён.

На desktop панель находится в одной строке; на tablet проекты и пространство образуют два блока; на mobile майндмепы занимают строку внутри проектов, далее выбор/действия проекта и пространство. Все существующие значки, действия и права сохранены. Узкий вариант проверен с длинными пользовательскими названиями.
