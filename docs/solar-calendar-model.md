Источник: предоставленный пользователем genesis-sacred-calendar-v8.svg, 24 октября 2026. Геометрия, все подписи и изображения вектора сохранены. В public/calendar-art/genesis-sacred-calendar-v8.svg добавлены группы месяцев, data-kind и CSS-переменные палитры STANDART. Внешних ресурсов, скриптов и сторонних библиотек нет.

## Direction contract

THESIS: существующий круг — главный объект. Пользователь исследует месяц, пяту и день непосредственно в предоставленной геометрии.

OWN-WORLD: палитра, шрифты и общая кнопка закрытия GENESIS; зелёный, золото и текущая поверхность светлой/тёмной схемы. Цвета месяцев остаются в исходных секторах.

STORY: общий круг → выбранный сектор → его название, смысл и дата → существующий месяц календаря с выбранным днём.

FIRST VIEWPORT: крупный вектор слева, компактные контролы масштаба сверху; справа выбор месяца, пяты и дня. На телефоне вектор сверху, те же доступные контролы ниже.

FORM: развитие существующего оформления по точному пользовательскому SVG; новая визуальная система не выбирается. Модальное окно открывается второй кнопкой в блоке «Солнечный календарь».

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Поведение

Каждый месяц, пята и день — SVG button. Click/Enter/Space приближают к его геометрии через Web Animations API и CSS transform внешнего слоя; viewBox SVG остаётся постоянным; стрелки выбирают следующий элемент того же уровня. Используется один tab stop в самом SVG и отдельные select для удобного управления на телефоне. Масштаб, перетаскивание, колёсико и pinch не изменяют данные пользователя. «Весь круг» возвращает обзор. prefers-reduced-motion отключает анимацию камеры. Апейрон имеет 5/6 фактических дней выбранного года; неявный шестой день в невисокосном году остаётся видимым в исходном рисунке с объяснением и без перехода на несуществующую дату.

Модальное окно использует общий useDialogAccessibility: Escape, focus trap, возврат фокуса и закрытие снаружи. Прежний диалог «Подробнее» сохранён и вынесен в отдельный загружаемый модуль, чтобы уложиться в текущий бюджет JS. Фюзис, API и Android не затрагиваются этим компонентом.

## Уточнение: кнопки в ряд и нагрузка — 24 октября 2026

«Подробнее» и «Круг GENESIS» объединены в year-description-actions. Они стоят рядом на всех проверенных ширинах, равны по высоте, между ними общий gap. На телефоне подписи переносятся внутри кнопок, иконки и стрелки остаются сверху. Отдельный боковой margin второй кнопки убран.

Причины нагрузки подтверждены замером Chromium Performance: непрерывные декоративные пульсации под backdrop blur заставляли страницу перерисовываться даже в покое; JS-изменение viewBox на каждом кадре пересчитывало большой вектор. Теперь размытие фона выключено только у этой модели, пульсации solar-glyph и voice-microphone-icon временно приостанавливаются и возобновляются при закрытии. Подсветка сохраняется без SVG drop-shadow и увеличения геометрии на каждом наведении.

Сам SVG не упрощён и не заменён изображением: все 4757 узлов, 451 цель и исходные ассеты сохранены. Камера перемещает HTML-слой с помощью transform. Приближение выполняется встроенным Web Animations API, без покадрового JS-цикла; остаётся RAF fallback. События drag/wheel/pinch объединяются до одного обновления на кадр. React-индикатор масштаба обновляется после завершения жеста. Временный will-change снимается в покое; анимации, RAF и таймеры отменяются при закрытии/скрытии. Размеры берутся из ResizeObserver, цели индексируются один раз; parsed SVG переносится через adoptNode без второго клонирования дерева.
