# C4: нативный командный отчёт

Срез после native import PR #223 реализован и прошёл локальную приёмку исходников. Общий остаток — 21 частичный функциональный ID и 14 K/U/L. Server/web реализация находится в `SharedTeamReports`, `shared-reports.php` и `shared-reports-history.php`; G2 добавляет оценки по отдельным проектам. Новый публичный Android APK этим этапом не выпускается.

До реализации у нативного проекта были текущий фильтр задач (поиск, статус, выполнение, участник, приоритет и календарный диапазон), общий menu/REPORT icon, Material3/STANDART, раскрываемые разделы и элементы 48dp. C4 gateway и отдельного экрана не было. G4 sprint report — самостоятельная модель с другими метриками; она сохранена отдельно.

Добавлен один экран отчёта выбранного проекта: условия и независимый календарный период, отдельные разделы текущего состояния, участников, возраста, времени этапов/цикла, динамики и G2 оценок. Фильтр источника переносится целиком, включая сохранённые представления и пользовательские критерии; расширение на пространство выполняется явно. Текущие счётчики отделены от истории за период. Points/часы остаются раздельно по проектам, нулевые оценки отличаются от отсутствующих. На телефоне разделы переключаются одним полем, на широком экране — боковым списком. Длинное название проекта ограничено двумя строками; системные панели читаются в обеих схемах.

Используются три существующих read-only POST API: `/shared/reports`, `/shared/reports/check`, `/shared/reports/tasks`. Token связан с actor, полным набором условий и asOf. Счётчики ведут к точной серверной выборке, страницы по 100; открытие задачи повторно проверяет token и актуальный доступ. Изменения условий/прав/данных и offline очищают старые переходы. Поздние ответы после смены controller/account/scope/формы отвергаются. Запросы выбора метрик принадлежат экрану: исчезновение строки метрики при переходе больше не отменяет её запрос. В sharedOnlineCall повторно проверяются ready/sign-in/shared-enabled/UID/scope; ACCESS_NETWORK_STATE позволяет снять результаты при отключении сети.

Добавлены bounded nested protocol, состояние и transport. Server payload проверяется на Dispatchers.Default до рендера: точные целые счётчики, конечные seconds/оценки, 0/null, полный последовательный календарный период, отдельные project scales и соответствие источников metric/asOf/cursor. Пустой PHP filter-map `[]` нормализуется в `{}`; непустой массив отвергается. Отчёт и token живут только в памяти; SavedState хранит условия. Смена языка не перезагружает отчёт и не сбрасывает условия. Нативные данные отображаются текстом без HTML/WebView.

Проверено:

- 446 JVM tests без пропусков/ошибок, включая новый C4 protocol/state и реальный C5 HTTP/PHP integration. C4 fixtures получены из изолированного PHP API: 131 synthetic task, выбранный корень 121, страницы 100 + 21; tracked tokens/cursors заменены инертными маркерами. Проверены 0/null, независимые шкалы проектов, malformed payloads, stale/cancel/offline/revoke и сохранение условий. Это не live native C4 HTTP/Google-проход.
- Финальный API28: runner OK (8 tests), из них 7 выполненных — 4 C4 UI и 3 controller; 1 capture-only assumption skip. API35: runner OK (20 tests), 18 выполненных — те же 7 и 11 G4 regression; 2 capture-only skip. C4 UI проверяет 121 источник, повторную проверку задачи, системный Back, offline/changed report, условия/timezone и сохранение civil bounds при трёх календарях.
- 98 initial + 98 confirm native captures: обе схемы × 360/390/768/1440 × 7 состояний, короткое landscape 592 × 2 × 7 и summary для 14 языков при 390/font1.3. Проверены репрезентативные размеры, обе схемы, немецкий/font1.3 и landscape. Сохранены отдельные исходные PNG в `output/playwright/team-initial-*` и `team-confirm-*`. Короткое окно прокручивается; все счётчики не обязаны помещаться в первый экран.
- `pnpm install --frozen-lockfile`, lint (0 ошибок, 2 прежних img warnings), 360 web tests, `pnpm build:beget`, native i18n audit и обе QA APK сборки прошли. Web UI этим срезом не менялся; новая browser visual-матрица не проводилась. Полный tsc с прежними 9 ошибками не объявляется чистым.

Логи: `output/native-team-report-{release-checks,install,lint,web-tests,web-build,last-build}.log`, `output/native-team-report-device-api{28,35}-final.log`. Финальные instrumentation выполнены на изолированном `ru.genesis.calendar.c5qa.debug`; официальная установленная GENESIS не изменялась.

Не проверены: физический Samsung, TalkBack, IME/foldables, все переведённые интерактивные состояния, реальный native C4 Google/HTTPS, подписанный/R8 C4 APK, большие многолетние C4 истории и общий project/release flow. Публичный APK остаётся 2.9.0/95. Эти ограничения сохраняют C4 частичным; отдельная приёмка исходников не закрывает общий ID.

Миграций и ручных production-БД изменений не требуется. SSH не использовался.
