# Компактный верхний блок Фюзиса — 25 октября 2026

Запрос: уменьшить верхний блок примерно вдвое, сохранив фон на всю ширину и видимость Аполлона и Артемиды.

## Реализация

- Для широкого экрана пропорция изменена с 4:1 на 8:1. При ширине окна 2510 px блок стал 277,75 px вместо 555,5 px.
- Минимальная высота на планшете и обычном десктопе — 180 px. На телефоне — 280 px: заголовок и описание располагаются над фигурами, настройки остаются слева внизу.
- Пейзаж заполняет блок через `cover`, а прозрачный слой со статуями масштабируется по высоте независимо от пейзажа. Новых анимаций или JavaScript для баннера нет.
- Новые WebP: `landscape-v2.webp` (1920×640, 240412 байт) и `apollo-artemis-cutout-v2.webp` (960×640, 173358 байт, alpha). Оба включены в существующий offline precache. Исходные v1 сохранены.
- Исходники сгенерированы в этой задаче: `exec-9fb1b06a-40c2-4a19-b9dd-58ca50eb7351.png` и `exec-ee5896f3-9906-4dce-8258-d575a20ef07a.png` в каталоге generated_images текущего чата. Сжатие меняет формат, но не композицию.

Проверена готовая production-сборка с локальной изолированной PHP-фикстурой: изображения загружаются; горизонтального переполнения нет; заголовок и настройки помещаются; настройки открываются в модальном окне и закрываются Escape с возвратом фокуса. Размер кнопки настроек — не менее 44×44 px. На всех размерах нет анимаций внутри баннера.

Снимки сохранены в основном рабочем каталоге проекта: до — `output/playwright/physis-hero-after-{light,dark}-{width}.png`, после — `output/playwright/compact-hero-after-{light,dark}-{width}.png`. Лог проверки — `output/compact-hero-browser.log`.

Обязательные проверки: `pnpm install --frozen-lockfile`, `pnpm lint` (0 ошибок, 2 прежних предупреждения в компонентах mindmap), `pnpm test` (697/697), `pnpm build:beget` (208 visual assets в offline precache). Для локального запуска проверки переводов сгенерированному JSON восстановлены LF; содержимое Git не изменено.

Непроверенные состояния: физические iOS/Android-устройства, Safari, системные forced colors и масштаб браузера 200%. Проверена адаптивная версия сайта в Chromium; Android-сборка и публикация не выполняются.

Публикация — существующий `deploy.yml`, Android отключён переменной `GENESIS_DEPLOY_ANDROID=false`. Изменений схемы или данных БД нет; rollback кода выполняется обычным `git revert`. Прямой SSH не использовался.
