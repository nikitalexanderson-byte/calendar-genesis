## Android: граница подтверждения

Компиляция исходников и JVM завершились успешно: 737 cases, 729 выполнены, 8 прежних opt-in skips. APK не упаковывалась и не устанавливалась; новый UI этими результатами не подтверждён.

Существующий QA APK2.9.4/99 запускался на API28/API35. Начальный смешанный запуск: по11 cases, соответственно3/4 failures. UI test требует отсутствующий selector shared-filter-completion-completed; notification fixture запускала verify до arm, API35 имела выключенное разрешение, distinct notifications не нашёл активную запись. Первоначальные ошибки сохранены; общий запуск зелёным не объявляется. Штатный arm → kill → verify затем подтвердил диагностическое уведомление на обеих API. Временное разрешение только QA-пакету API35 возвращено в исходный ignore.

Открыты: native UI-матрица нового CRUD/relations/watch, TalkBack/IME/Back/крупный шрифт нового экрана и подписанный выпуск после отдельного разрешения. Здесь не проверены Safari/iOS/WebKit, физический телефон и доставка реального внешнего сообщения. Web не заменяет native acceptance.
