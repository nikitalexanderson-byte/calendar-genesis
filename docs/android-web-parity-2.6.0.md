# Сверка функций Android и сайта для 2.6.0

Проверено 04.10.2026 по коду ветки выпуска и на Android-эмуляторе API 35. Сравнение относится к функциям, добавленным в приложение к этому выпуску; отдельная переработка оформления сайта не проводилась.

| Функция приложения | Состояние сайта после сверки |
| --- | --- |
| Вернуться к фактическому сегодняшнему дню, оставаясь в календаре «Месяц» | Добавлена кнопка внутри календаря. Переход не открывает раздел «Сегодня». |
| Лунные повторы привычек: декады, дни декады, новолуние, полнолуние, ежегодный выбор месяца, включая 13-й | Добавлены те же варианты в форме привычки и общем вычислителе повторов. Канонические даты остаются григорианскими, поэтому просмотр в других календарях согласован. |
| Собственное настроение с названием и смайликом | Добавлены ввод, повторное использование уже созданного настроения, отображение в сводке и сохранение в общем документе трекеров. |
| Скрыть технические списки Google Tasks при создании задачи | В выборе списка скрыты списки по умолчанию и служебные «Мои задачи», «My Tasks», «Привычки GENESIS» для аккаунта Google. |
| Фоновое управление приложением голосом | Добавлен второй режим поверх существующего голосового ввода. Поддерживаются переходы по разделам, создание задачи, проекта, списка и привычки, открытие редакторов, отметки выполнения и перенос задачи в проект. Неоднозначные названия отклоняются; неподдерживаемая команда получает явный ответ. |
| Уменьшенные эмблемы достижений; рамки формы привычки | Это оформление Android. Дизайн сайта в этом выпуске не менялся. |

## Функции сайта, которых пока нет в форме Android

- Пользовательский цвет и эмодзи обычной привычки.
- Роль и ритуал привычки, выбираемые вручную.
- Явная настройка синхронизации напоминания привычки с Google Tasks и показа привычки в Google Calendar. Нативная форма содержит локальные напоминания.

Эти возможности Android в 2.6.0 не добавлялись; требуется отдельное решение об их переносе.

## Проверка и ограничения

- Android: сборка debug и androidTest, модульные тесты, четыре UI-сценария на эмуляторе API 35.
- Сайт: `pnpm lint`, `pnpm test`, `pnpm build:beget`; браузерная проверка публичного экрана в темах Standart и Experimental на ширинах 360, 390, 768 и 1440 px без горизонтального переполнения.
- Не проверены в браузере экраны после авторизации, реальная синхронизация с Google Tasks и Яндекс.Календарём, разрешение микрофона и качество распознавания речи в разных браузерах. Для них нужна авторизованная тестовая учётная запись и доступный API.
- Физический Samsung в этом выпуске не использовался: по просьбе владельца проверка проводилась в эмуляторе.
