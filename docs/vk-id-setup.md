# Настройка входа через VK ID

> Актуально для GENESIS 2.5.6. До заполнения `vk_client_id` интерфейс VK ID скрыт. Сначала выпустите код сайта и APK, затем включайте поставщика.

GENESIS использует один веб-поток VK ID для сайта и Android. Приложение Android открывает официальный экран VK ID в браузере; после успешного входа получает одноразовый билет для своей отдельной серверной сессии. Пароль VK и токены VK ID не хранятся в GENESIS. Личного календаря VK для задач этот способ не подключает.

До настройки числового ID приложения в закрытом серверном конфиге VK ID остаётся выключенным: кнопки входа и подключения не показываются на сайте и в Android. Google остаётся отдельной группой и никогда не объединяется с Яндекс ID или VK ID.

## Что подготовить

1. Создайте приложение типа **веб-сайт** в [кабинете подключения VK ID](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application). Название и описание должны соответствовать GENESIS; адрес сайта — `https://genesiscalendar.ru`.
2. Укажите разрешённый адрес возврата **точно** `https://genesiscalendar.ru/api/auth/vk/callback`. Если кабинет просит домен, укажите `genesiscalendar.ru`. Не добавляйте произвольные или локальные адреса.
3. Включите получение адреса электронной почты, если кабинет предлагает такое разрешение. Пользователь может не предоставить email; GENESIS тогда создаст внутренний технический адрес и всё равно привяжет аккаунт по постоянному идентификатору VK ID.
4. Сохраните числовой **ID приложения**. Для текущего веб-потока нужен именно ID. Не отправляйте секрет VK в чат, GitHub, браузер или Android APK.
5. В закрытом файле `/home/h/haiirodw/genesis-calendar/server/config.php` на Beget добавьте в возвращаемый массив строку `'vk_client_id' => 'ВАШ_ЧИСЛОВОЙ_ID',`. Проверьте синтаксис, не выводя содержимое файла и не меняя `crypto_key`. Пустая строка отключает кнопку входа VK ID на сайте и в Android.

## Порядок действий в кабинете VK ID

1. Войдите в [кабинет VK ID для разработчиков](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application) под аккаунтом, который будет администрировать интеграцию. Создайте приложение для сайта GENESIS. Если кабинет предлагает отдельные платформы, для этого потока используйте **сайт**: Android открывает тот же веб-вход во внешнем браузере.
2. Укажите название GENESIS, публичный домен `genesiscalendar.ru`, HTTPS-адрес сайта `https://genesiscalendar.ru` и адрес возврата `https://genesiscalendar.ru/api/auth/vk/callback`. Сохраните настройки и проверьте, что кабинет показывает адрес возврата без добавленного `/` в конце или параметров запроса.
3. Проверьте разрешение на получение профиля и, если доступно, email. Для входа достаточно постоянного VK ID: отсутствие email не блокирует аккаунт GENESIS. Доступ к сообществам, сообщениям, друзьям и рекламным данным не нужен.
4. Скопируйте **ID приложения** из карточки приложения. Это числовое значение. Секрет, сервисный ключ и токен доступа сюда не вводятся; текущий поток использует PKCE и одноразовый `state`.
5. В настройках приложения VK ID проверьте статус публикации/доступности для нужных пользователей. Если приложение доступно только тестировщикам, сначала проверьте вход тестовым VK-аккаунтом, затем измените статус в кабинете VK ID.

## Включение на сервере GENESIS

1. Дождитесь успешного деплоя GENESIS 2.5.6. Убедитесь, что `https://genesiscalendar.ru/api/health` отвечает успешно и `https://genesiscalendar.ru/deploy-meta.json` указывает на развёрнутый коммит.
2. В закрытом файле `/home/h/haiirodw/genesis-calendar/server/config.php` измените только значение `vk_client_id` в возвращаемом PHP-массиве. Пример значения: `'vk_client_id' => '123456789',`. Число здесь условное; подставьте фактический ID. Если ключ уже есть с пустой строкой, замените её, не создавая второй ключ.
3. Проверьте синтаксис PHP и права чтения файла веб-процессом. Содержимое `config.php`, его копии и секреты не выводите в журнал, чат или Git. Не меняйте `crypto_key`: от него зависит чтение существующих зашифрованных данных.
4. Откройте `https://genesiscalendar.ru/api/auth/providers`. Значение `vk: true` означает, что кнопка может появиться. Если оно осталось `false`, проверьте числовой ID, синтаксис массива и кеш страницы, затем повторите запрос.

Секрет приложения и дополнительные API-ключи для нынешнего потока не требуются. Не добавляйте их в публичный код. Обновление `vk_client_id` включает способ входа; заранее заполненный пустой `vk_client_id` безопасно оставляет заготовку скрытой.

Серверный `config.php` не хранится в Git и сохраняется процедурой деплоя. Включать VK ID следует **после** публикации кода и регистрации адреса возврата. За пределами корня GENESIS файлы не требуются.

## Проверка после настройки

1. Откройте `https://genesiscalendar.ru/api/auth/providers`. Поле `vk` должно стать `true`. Если `false`, проверьте, что ID записан как строка из цифр в `server/config.php`.
2. В приватном окне сайта проверьте кнопку «Войти через VK ID». Официальная страница входа должна вести на `id.vk.ru`, затем возвращать на GENESIS. Отказ в доступе должен вернуть на форму входа без создания аккаунта.
3. Создайте тестовую задачу, дождитесь состояния «Синхронизировано с GENESIS», откройте тот же VK ID на другом устройстве и проверьте задачу и список. Проверьте изменение и удаление с обеих сторон.
4. Установите APK версии не ниже **2.5.6** и повторите вход. После браузера должно открыться приложение; одноразовый билет действует пять минут и привязан к начатому на этом устройстве входу. Если возврат не сработал, обновите приложение, повторите вход с начала и проверьте, что Android разрешил открыть ссылку в GENESIS.
5. Проверьте страницу `/privacy`, предупреждение на входе, выход и повторный вход. Не используйте для теста аккаунт с важными несинхронизированными данными.
6. После входа через VK ID откройте кабинет сайта и подключите Яндекс ID. Проверьте и обратный порядок, а также второй аккаунт Яндекса. Если у второго аккаунта уже есть своё пространство, GENESIS покажет отдельное подтверждение объединения. При несовместимых записях объединение остановится с сохранением обеих копий.
7. В настройках распределите направления задач по умолчанию, при создании или по категории. Для каждого Яндекс ID подключите собственный Яндекс.Календарь отдельно. У VK ID копия задачи хранится только в GENESIS. Повторите вход через оба связанных поставщика и убедитесь, что открывается один кабинет. Вход через Google должен по-прежнему вести в отдельное пространство.

Если после настройки VK ID отклоняет адрес возврата, убедитесь, что в кабинете и в GENESIS указан один и тот же HTTPS-адрес с `/api/auth/vk/callback`. При необходимости временно отключите VK ID, очистив только `vk_client_id`; данные пользователей от этого не удаляются.

Если кнопка есть, но после входа появляется ошибка сессии, проверьте время устройства, доступность cookie в браузере, завершение входа в пределах пяти минут и соответствие домена `genesiscalendar.ru`. После неудачного входа начните новый поток: одноразовые коды и билеты повторно не используются. Проверяйте только события GENESIS, без печати токенов или содержимого cookie.

## Связанные аккаунты и уведомления

- После входа через VK ID в настройках GENESIS подключите Яндекс ID; после входа через Яндекс доступно подключение VK ID. Подключение существующего аккаунта открывает явное подтверждение объединения. До подтверждения пространства раздельны.
- Несколько Яндекс-аккаунтов можно связать с одной группой Яндекс/VK. Для каждого подключение Яндекс.Календаря выполняется отдельно паролем приложения «Календарь» в кабинете GENESIS. Пароль не передавайте через чат.
- В настройках распределите, в какие связанные аккаунты отправляются новые задачи: по умолчанию, выбор при создании или по категории. Уведомления устройства остаются локальными; календарные уведомления идут от того календаря, который вы отдельно подключили.
- Google-аккаунт и его Calendar/Tasks находятся в отдельном пространстве. Объединения Google с Яндекс/VK нет, и настройки маршрутизации между этими группами не смешиваются.

## Хранение и риски

Задачи VK ID шифруются сервером перед записью в базу, а проекты и привычки шифруются приложением до отправки. Сервер видит текст задачи во время синхронизации. VK не получает задачи и не создаёт календарную резервную копию. В отличие от подключённого Google Calendar/Tasks или Яндекс.Календаря, восстановление зависит от сервера GENESIS, его резервных копий и локального устройства. Подробности и способы удаления описаны в [политике конфиденциальности](https://genesiscalendar.ru/privacy).
