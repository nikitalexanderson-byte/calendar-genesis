# Настройка входа через VK ID

GENESIS использует один веб-поток VK ID для сайта и Android. Приложение Android открывает официальный экран VK ID в браузере; после успешного входа получает одноразовый билет для своей отдельной серверной сессии. Пароль VK и токены VK ID не хранятся в GENESIS. Личного календаря VK для задач этот способ не подключает.

## Что подготовить

1. Создайте приложение типа **веб-сайт** в [кабинете подключения VK ID](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application). Название и описание должны соответствовать GENESIS; адрес сайта — `https://genesiscalendar.ru`.
2. Укажите разрешённый адрес возврата **точно** `https://genesiscalendar.ru/api/auth/vk/callback`. Если кабинет просит домен, укажите `genesiscalendar.ru`. Не добавляйте произвольные или локальные адреса.
3. Включите получение адреса электронной почты, если кабинет предлагает такое разрешение. Пользователь может не предоставить email; GENESIS тогда создаст внутренний технический адрес и всё равно привяжет аккаунт по постоянному идентификатору VK ID.
4. Сохраните числовой **ID приложения**. Для текущего веб-потока нужен именно ID. Не отправляйте секрет VK в чат, GitHub, браузер или Android APK.
5. В закрытом файле `/home/h/haiirodw/genesis-calendar/server/config.php` на Beget добавьте в возвращаемый массив строку `'vk_client_id' => 'ВАШ_ЧИСЛОВОЙ_ID',`. Проверьте синтаксис, не выводя содержимое файла и не меняя `crypto_key`. Пустая строка отключает кнопку входа VK ID на сайте и в Android.

Серверный `config.php` не хранится в Git и сохраняется процедурой деплоя. Включать VK ID следует **после** публикации кода и регистрации адреса возврата. За пределами корня GENESIS файлы не требуются.

## Проверка после настройки

1. Откройте `https://genesiscalendar.ru/api/auth/providers`. Поле `vk` должно стать `true`. Если `false`, проверьте, что ID записан как строка из цифр в `server/config.php`.
2. В приватном окне сайта проверьте кнопку «Войти через VK ID». Официальная страница входа должна вести на `id.vk.ru`, затем возвращать на GENESIS. Отказ в доступе должен вернуть на форму входа без создания аккаунта.
3. Создайте тестовую задачу, дождитесь состояния «Синхронизировано с GENESIS», откройте тот же VK ID на другом устройстве и проверьте задачу и список. Проверьте изменение и удаление с обеих сторон.
4. Установите APK версии не ниже **2.5.2** и повторите вход. После браузера должно открыться приложение; одноразовый билет действует пять минут и привязан к начатому на этом устройстве входу.
5. Проверьте страницу `/privacy`, предупреждение на входе, выход и повторный вход. Не используйте для теста аккаунт с важными несинхронизированными данными.

Если после настройки VK ID отклоняет адрес возврата, убедитесь, что в кабинете и в GENESIS указан один и тот же HTTPS-адрес с `/api/auth/vk/callback`. При необходимости временно отключите VK ID, очистив только `vk_client_id`; данные пользователей от этого не удаляются.

## Хранение и риски

Задачи VK ID шифруются сервером перед записью в базу, а проекты и привычки шифруются приложением до отправки. Сервер видит текст задачи во время синхронизации. VK не получает задачи и не создаёт календарную резервную копию. В отличие от подключённого Google Calendar/Tasks или Яндекс.Календаря, восстановление зависит от сервера GENESIS, его резервных копий и локального устройства. Подробности и способы удаления описаны в [политике конфиденциальности](https://genesiscalendar.ru/privacy).
