# Публичные документы .com и Google OAuth

Политика, соглашение, поддержка и удаление аккаунта обновлены под genesiscalendar.com и Hostinger. Общий источник app/legal-content.ts используется интерактивным интерфейсом и четырьмя HTML-документами сборки. Правила Apache отдают полный текст по /privacy, /terms, /support, /delete-account без входа и выполнения JavaScript; обычный клиент и существующие изображения сохраняются. Canonical ведёт на .com. Build gate проверяет полноту политики, редакцию, ссылки и отсутствие прежнего домена, Яндекса и Beget.

Удалены все подключения Yandex Metrika: React-компонент, обе точки входа, noscript-пиксель. Первая сторона GENESIS продолжает собирать описанные в политике показатели использования. Исторические приватные данные и совместимость старого приложения не удаляются.

Google Branding auto-verification потребовала подтвердить владение новым доменом в Search Console и ждать 24 часа до повторной проверки. Подтверждение постоянных прав владельца запрошено у пользователя отдельно. Текущие OAuth scopes и production audience сохранены; изменённые ссылки брендинга пока не считаются опубликованными. До проверки реального Google-входа/синхронизации нового Android .ru остаётся совместимым.

Frozen install, lint, веб-тесты и build:beget обязательны перед merge. Публикация только действующим GitHub Actions; политика в ответе production проверяется повторно после deploy.

Проверено локально: frozen install, lint, все 111 веб-тестов, build:beget; CUA с отключённым JavaScript прочитал 29 разделов политики, 7 соглашения и по 3 поддержки/удаления. Интерактивный /privacy.html тоже открывает правильный документ. Снимок privacy-static-no-javascript.png сохранён в output/playwright/web-standart (не коммитится).
