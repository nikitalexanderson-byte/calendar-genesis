# Компактная шапка окна задач календаря — 28 октября 2026

Изменение касается только десктопного и мобильного сайта. Android, данные и API не изменены.

Причина: у окна не было собственного заголовка h2. Общая шапка диалогов использовала aria-label, где название и длинная дата объединены. В узком окне крупный заголовок занимал пять строк, а прежнее название со счётчиком повторялось ниже.

Окно теперь передаёт общей шапке заголовок «Общие задачи · 1» (или «Личные задачи · 1») и отдельный data-dialog-subtitle с полной датой. Только для этих окон заголовок использует Inter 16px/1.4, дата — 12px/1.5. Дата занимает всю ширину под названием и кнопкой закрытия. Прежние ширина окна, токены тем и действия сохранены; закрытие имеет цель 44×44px.
