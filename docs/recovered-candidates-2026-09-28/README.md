## Очистка и восстановление

Снимок всех исходных refs и SHA: `branch-inventory.json`. Для веток, уже входящих в master, удаление имени ветки не удаляет код или историю. Пример восстановления нужной ветки:

```powershell
git switch -c codex/restored-topic <SHA-из-branch-inventory.json>
```

Для уникального старого QA-коммита сохраняются выбранные тесты, а его устаревший отчёт не переносится в текущую документацию. Все действительно выбранные незакоммиченные материалы находятся в этой preservation branch.

Production/master не изменяются. Samsung, adb, Google Cloud, Figma, пользовательские аккаунты и production-БД не затрагиваются. SSH не использовался. Этот аудит проверяет происхождение и актуальность Git-материалов, а не повторяет функциональное испытание релиза на телефоне.
