# Android: отмена загрузки общих дел — 18 октября 2026

Пользователь сообщил о `The coroutine scope left the composition` на экране общих пространств Android 2.9.0 и поручил исправить без публикации приложения.

Причина воспроизведена на API28: смена активности страницы отменяет `LaunchedEffect`; общий `catch (Exception)` принимал `CancellationException` за сетевую ошибку и сохранял её текст в Compose state. Состояние экрана переживает уход со страницы, поэтому служебная ошибка становилась видна при возврате. Два регрессионных сценария в обеих темах на исходной сборке показали точно тот же текст и упали на проверке отсутствия `shared-feedback`.

В `SharedProjectsScreen` отмена теперь пробрасывается до обычной обработки ошибок во всех асинхронных загрузках и действиях: пространства, проекты, задачи, комментарии, сохранение раскрытия, приглашения, Google settings/sync и изображение доски. Чтение комментариев больше не подавляет отмену через `runCatching`. Аналогично исправлен экран приглашений. Настоящие сетевые ошибки по-прежнему отображаются; `finally` освобождает флаги занятости.

Проверки:

- `:app:testDebugUnitTest`, `:app:assembleDebug`, `:app:assembleDebugAndroidTest`: success; 284 JVM tests, 0 failures/errors.
- Android API28 emulator-5556: весь `SharedWorkspaceUiTest`, 10 tests, success. Включает отмену в светлой/тёмной темах, возврат и повторную загрузку, показ настоящей ошибки, создание/редактирование/повтор сохранения, поиск/фильтры, роли и доски.
- Стандартный connected Gradle runner не смог прочитать package name APK в Windows checkout с кириллицей. Скопированы только два тестовых APK во временный ASCII-путь и установлены на эмулятор через adb; проверка запущена обычным AndroidJUnitRunner. Полная копия кода не создавалась.
- До/после: ignored `output/playwright/android-shared-cancellation-{before,after}-{light,dark}.png`. Логи `output/android-cancellation-*`.

Версия и versionCode не менялись, release APK/AAB не собирались и не публиковались. Production Android остаётся 2.9.0/95. Физические телефоны, другие API и подписанная release-сборка в этом исправлении не проверены. Ручной SSH и production DB edits не использовались.
