# GENESIS: язык сообщений импорта и экспорта

23 октября 2026. Локальный C5/L4/U в ветке `codex/shared-editor-errors-2026-10-23`, после исправления отмены экспорта `c5b45f0`. Деплой, push и новая Android-сборка не разрешены. Строгий остаток **11/32 принятых, 21 частичный функциональный ID и 14 сквозных K/U/L** сохраняется.

## Воспроизведение и изменение

Настоящий `SharedDataExchange` с синтетическим loopback API подтвердил четыре дефекта: после переключения RU→EN прежний язык сохраняли ошибка HTTP 413, сообщение готового экспорта и результат начатого ранее запроса. Дополнительно смена языка перезапрашивала независимую от него историю и могла сбросить загруженные страницы. Все четыре признака — в `output/playwright/exchange-language/before.log`; 16 исходных кадров охватывают два состояния, обе схемы и 360/390/768/1440px.

Теперь компонент хранит исходную причину ошибки и описание результата, переводя их при текущем render. Источники статических сообщений ограничены типом; экспортные счётчики форматируются текущим `Intl.NumberFormat`, включая ноль. Отмена экспорта использует тот же механизм. HTTP 403/404 сохраняют обработчик потери доступа.

Первичная загрузка истории зависит от пространства. Смена языка не прерывает запрос и не сбрасывает страницы. Import/undo сохраняют lock; operationId, fingerprint, исходный файл, точный JSON команды, календарь и локализованные статусы зафиксированного предпросмотра не меняются ради перевода интерфейса. Изменён только `app/SharedDataExchange.tsx`; CSS, кнопки 44px/10px, STANDART, изображения, календари, сервер и зависимости сохранены.

Проверка исправлена на сохранение фактического endpoint с тем же import ID и точного тела. Неудачный `functional-harness-path-failure.log` сохранён; зелёным считается последующий полный прогон.
