## Поведение

- В обычном режиме без сакральных функций десктопный месяц показывает до трёх плашек незавершённых задач в ячейке. Личные задачи учитывают существующие правила календарных повторов, общие — доступные пользователю задачи со сроком на эту дату. Завершённые задачи, как и в существующих календарных счётчиках, сюда не входят.
- Плашка открывает настоящую карточку с описанием: личную через существующий preview, общую через существующий маршрут задачи. Обычное нажатие свободной области дня сохраняет прежнее поведение.
- При переполнении «…» открывает список именно даты этой ячейки. На десктопе личные задачи расположены слева, общие — справа; списки прокручиваются независимо. Заголовок с датой остаётся над ними. В узком окне части располагаются последовательно.
- Полный общий список использует существующую пагинацию, повторную проверку доступа, обновление версии запроса и кнопку «Показать ещё». Ограничения в 100 задач на весь день нет.
- Соседние месяцы остаются только для просмотра. Сакральный и лунный режимы, реальные данные и экран «Сегодня» сохраняют существующее поведение. Повторная надпись «Григорианский календарь · год» в заголовке обычного месяца скрыта.
- На десктопе от 1280 px выбор пространства и проекта, их действия, «Майндмепы», применимая сортировка и поиск располагаются в одну строку. Длинные значения выбираются в прежних списках. Для точного указателя на 1280–1599 px вторичные действия имеют ширину 36 px и высоту 44 px; сенсорные размеры остаются прежними.
- В мобильных личных и общих делах золотистая кнопка «Майндмепы» выровнена по списку сортировки. Подпись сортировки находится над ним, поиск — ниже. Оформление и анимация кнопки сохранены.

## API и данные

Добавлен только GET `/shared/calendar/previews?from=YYYY-MM-DD&to=YYYY-MM-DD`. Диапазон ограничен 42 днями включительно. Оконная функция SQLite выбирает до трёх лёгких проекций на каждую дату, поэтому заполненный первый день не вытесняет остальные дни. Точные счётчики и плашки читаются в одной транзакции через действующие ACL и encrypted-content read view. Описания, вложения и проверки согласования для плашек не загружаются.

Запрос выполняется только в открытом обычном месяце на ширине от 1100 px; изменения месяца/аккаунта отменяют устаревшие запросы. Существующий API календарных задач и нативные клиенты сохраняют совместимость. Новых миграций, ручных изменений production-БД и новых зависимостей нет. Rollback — revert коммита выпуска и штатный deploy.yml.
