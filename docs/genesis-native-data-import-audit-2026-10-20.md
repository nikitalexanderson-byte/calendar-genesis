# C5: нативный импорт и восстановление команды

Состояние: нативный импорт реализован и прошёл локальную приёмку исходников после native export PR #219. Публичный APK и полный C5 этим срезом не закрываются. Общий остаток — 21 частичный функциональный ID и отдельно 14 K/U/L.

## Действующий контракт

- Web: `app/SharedDataExchange.tsx`, `app/shared-data-exchange.ts`.
- PHP: `server/src/shared-data-plan.php`, `shared-data-apply.php`, `shared-data-format.php`, `shared-data-csv.php`, `shared-data-trello.php`.
- API: POST `/shared/data/preview`, POST `/shared/data/apply`, GET `/shared/spaces/{space}/data-imports`, POST `/shared/data-imports/{id}/undo`, GET `/shared/projects/{project}/data-history`.
- GENESIS JSON v1, CSV и Trello JSON; исходный UTF-8 файл до20 MiB. Preview учитывает полный источник и текущие права назначения. Apply использует `operationId` и fingerprint; повтор неизменной команды возвращает сохранённый результат. Undo проверяет последующие изменения и связи. Импортированная история не запускает уведомления, автоматизации и награды.
- `PlanningJournal` уже даёт CAS, отдельные версии, durable attempt marker, неизменную pending-команду и консервативную обработку потерянного ответа. Лимит журнала8 000 000 байт не вмещает максимальный файл; повышать его для всех функций не требуется.

## Предлагаемый срез

Продолжить существующее меню действий выбранного проекта одним нативным экраном импорта и его истории. Сохранить STANDART Material3, `AffairsDisclosure`, 48dp действия, фиксированную область статуса и основного действия. Базовый путь: выбрать файл → проверить назначение и настройки → предпросмотр → сопоставить данные → явно применить. CSV-колонки, календарный контекст и сложные сопоставления раскрываются по необходимости. Ошибки, offline, потеря доступа и неоднозначный результат остаются видимыми рядом с действием.

Исходный файл хранить отдельно от SavedState/SharedPreferences и очереди задач, зашифрованным в приватном хранилище без backup. Ссылка включает случайный ID, размер и SHA-256; AAD привязан к аккаунту, пространству, проекту и ID. Ограничить чтение до20 MiB, строго проверить UTF-8 и повторно проверить размер/хэш при восстановлении. Незавершённый файл не заменяет действующий источник. Ошибка хранилища не превращается в пустой черновик.

Расширить существующий контракт команд отдельным purpose для импорта. Журнал хранит ссылку на источник, параметры разбора/назначения/сопоставления, принятый fingerprint и operation identity, но не содержимое файла. После попытки с неизвестным результатом запрещено менять pending-команду; разрешён повтор того же запроса. Новое содержимое и изменённые настройки требуют нового предпросмотра. При смене UID/controller/scope поздний ответ не меняет UI и не отправляет следующий запрос.

Реализовано явное представление `view=native-v1` для preview/apply/history: тот же полный серверный plan и fingerprint, все каталоги/сопоставления и проблемы, точные полные счётчики и первые100 задач. Тела задач и истории и большие per-row receipt maps не передаются телефону; замечания receipt ограничены100 с отдельным полным счётчиком. Каталоги и blockers не обрезаются: сверх30MB возвращается явная ресурсная ошибка. Неизвестный view отклоняется до записи; прежний web-контракт сохраняется.

## Текущее состояние исходников

Реализованы отдельный зашифрованный chunk-store без backup с квотой512MiB, SHA/строгим UTF-8/AAD/footer, ссылки вместо20MiB содержимого в command journal, потоковый HTTP body с точным Content-Length, отдельный import purpose и durable undo intent/outcomes. В controller сохранены UID/generation/access/scope/cancellation guards и запрет записи при незавершённой очереди задач проекта. Неоднозначная отправка повторяет исходную команду; первая подтверждённая ошибка и сохранённые копии обрабатываются отдельно.

Нативная форма одного проекта содержит JSON/CSV/Trello, назначение, независимые календарные настройки, CSV-колонки, сопоставления/typed defaults, предпросмотр, историю и undo, версии и recovery. Группы раскрываются по5, большие селекторы имеют поиск/пагинацию. Автосохранение не блокирует поле и сохраняет более новый ввод. Picker SavedState хранит scoped parameters, не URI или содержимое. Добавлены38 строк во все14 языков. Подготовлен отдельный срез исходников и совместимое серверное представление; публичная подписанная сборка с импортом требует дальнейшей приёмки.
