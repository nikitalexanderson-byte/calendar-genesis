# GENESIS 2.6.2 — состояние ветки

Рабочая ветка: `codex/complete-2.6.2`. Production и сайт загрузки всё ещё обслуживают 2.6.1. Этот документ фиксирует проверяемые изменения и оставшийся объём; он не обозначает готовый выпуск.

## Реализовано в ветке

- Исправлена передача Android-переключателя «Общие проекты» в локальную очередь настроек. Ожидающее выключение сразу скрывает раздел и подменю, а серверный флаг сохраняет данные для повторного включения. Добавлены проверки локального цикла включения/выключения и серверного запрета доступа при выключении.
- Заголовки «Проекты - личные» и «Проекты - общие» и общая иконка-папка с двумя сходящимися деревьями. Общий хаос-бокс вынесен в отдельную карточку под заголовком. Счётчик берётся из доступного пользователю проекта и обновляется при открытом экране.
- Веб-раздел общих проектов сгруппирован в ограниченные блоки. Подменю личных/общих проектов на Android использует общий компонент меню. Навигация свайпом переведена на `HorizontalPager` с предварительной композицией соседней страницы и скрытием невидимых страниц из дерева доступности.
- Создание пространства, проекта, общей задачи, списка/колонки, категории и приглашения открывает модальную форму в вебе и Android. Форма задачи принимает название, описание, срок, список/статус, категорию и исполнителя. Участник с правом записи может создать список/колонку; сервер проверяет это право.
- На сайте есть перенос дерева личного проекта в общее пространство с идемпотентной квитанцией сервера (`024_shared_project_imports.sql`). Android пока умеет переносить отдельную личную задачу, но не дерево проекта.
- Расширены голосовые команды сна, напоминания перед сном и Стойхейона; обновлены русские и английские словари. Добавлен полный каталог эмодзи для выбора в привычке и собственного настроения на обеих платформах. Доработаны логотипы и подписи входа, а также загрузка блока рекламы в Android.
- Номер приложения и проверки существующего GitHub workflow подготовлены к `versionCode 68`, `versionName 2.6.2`. Ветка не слита в `master`.
- Для каждого участника и проекта добавлено отдельное согласие на копии в его Google Tasks и Google Calendar (`025_shared_google_projection.sql`). Командная задача остаётся на сервере GENESIS; связи с Google запоминаются по участнику и задаче. Собственные проектные списки/события отфильтровываются из импорта личных задач. Переключатели доступны в вебе и Android, обновление выполняется пакетами при работе участника с проектом. Отключение прекращает новые обновления, но оставляет существующие копии в его Google-аккаунте; это описано в политике.

## Проверки

- После последних изменений прошли `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` (105/105) и `pnpm build:beget`.
- После изменения номера версии и хаос-бокса прошли Android `:app:assembleDebug`, `:app:assembleDebugAndroidTest`, `:app:testDebugUnitTest`.
- На эмулятор установлены последние debug APK 2.6.2 и тестовый APK; после добавления Google-переключателей повторно прошли четыре instrumented-теста: локальная очередь настройки, меню/свайпы и выбор эмодзи своего настроения (4/4). Ранее также проходили создание задачи и смена языка. Реальное отключение флага с авторизованным сервером на эмуляторе пока не проверено.
- Миграции SQLite 001–025 последовательно применились к пустой изолированной базе в Python; SQL выборки Google-синхронизации также проверен на SQLite. Синтаксис изменённых PHP-файлов разобран PHP-парсером JavaScript. Это не заменяет PHP smoke и проверку обновления существующей production-базы.
- В статическом веб-превью окно создания задачи проверено в темах Standart и Experimental на ширинах 360, 390, 768 и 1440 px. Скриншоты `output/playwright/shared-modal-final-*.png` локальные и исключены из Git. Проверка не подтверждает авторизованный React/API-сценарий.
- Новый блок «Мои копии в Google» проверен в статическом браузерном макете для Standart и Experimental на 360, 390, 768 и 1440 px: горизонтального переполнения нет, переключатели сохраняют нормальный размер. Скриншоты `output/playwright/shared-google-*.png` локальные и исключены из Git; авторизованный интерфейс/API этим не проверены.
- PHP smoke новой миграции и серверного сценария выключения недоступен в этом окружении: здесь отсутствуют PHP CLI и локальный `server/config.php`. Нельзя считать эти тесты пройденными. Production и реальный Google/OAuth не проверены. SSH не применялся.

## Не реализовано или не проверено

- Индивидуальная Google-проекция реализована в коде, но не проверена с действующим OAuth и реальными тестовыми аккаунтами. Проверить согласие каждого участника, создание/обновление/отключение копий, повторные попытки и отсутствие повторного импорта копий в личные задачи. PHP smoke новой миграции пока не запущен.
- Командные уведомления и их настройки; офлайн-кеш и очередь разрешённых операций; перенос дерева личного проекта из Android.
- Полное адресное голосовое управление тонкими настройками напоминаний, всеми настройками приложения, раскладом девяти карт и остальными действиями из пользовательского запроса. Реальное распознавание речи микрофоном на русском и английском не измерено.
- Остальные этапы C–E подробного задания по общим проектам: поиск и сохранённые представления, файлы, документы, зависимости, повторения, шаблоны, аналитика, автоматизации, расширенные роли и нагрузочный профиль. Интерфейс этих функций не следует показывать как готовый.
- Обновление 2.6.2 на сайте, подписанный release APK, CI-деплой, `/deploy-meta.json`, `/api/health` и скачивание новой версии не выполнялись.

## Следующий шаг

Сначала проверить серверную модель добровольной Google-проекции и завершить командные уведомления с проверкой прав, затем офлайн-очередь и Android-перенос проекта. После этого повторить все проверки, PHP-интеграцию на изолированной копии БД, аудит тем/ширин и сборку подписанного 2.6.2 через существующий GitHub Actions workflow. Production-БД вручную не менять; при проблеме кода использовать `git revert`, восстановление БД согласовывать отдельно.
