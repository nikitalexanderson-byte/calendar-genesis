# Общие дела и вложения — 11 октября 2026

Пользовательские изменения охватывают один экран общих дел и связанные календарные счётчики. Стек, существующие изображения и серверные права сохранены.

## Результат

- Шапка пространства компактнее: Inter 16px, роль и участники. Убраны дублирующее название в хаос-боксе и описание «Совместная проверка»; фраза о совместном планировании и личных данных сохранена.
- Выбор пространства уже на desktop. Выбор проекта и назначения задачи показывает дерево с количеством задач. В пустом пространстве есть большая кнопка первого проекта. Настройки проекта справа; в хаос-боксе нет кнопки создания задачи.
- Названия пространств обновляются по таймеру, при возвращении фокуса и восстановлении сети. Команда и роли относятся к пространству.
- В календаре проекта можно переносить задачу на дату. Задачи без срока раскрываются отдельно. Выполненные задачи Ганта находятся в отдельном разделе.
- Уведомление комментария открывает исходную задачу. Удаление задачи выделено красным и расположено отдельно от её полей.
- В веб-формах создания и редактирования общей задачи можно выбирать и перетаскивать файлы. До 5 файлов, суммарно до 10 МБ. Форматы: JPG/JPEG, PNG, WebP, GIF, BMP, TIFF, PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT/ODS/ODP, RTF, TXT, CSV. Сохранённые файлы скачиваются из карточки задачи.
- В доске строго сохранены прежние поля изображения и прежние форматы. Офисные документы туда не добавлены.
- Общие счётчики календаря круглые, фиолетовые, внизу справа. Android 2.7.2 (78) получает те же счётчики.

## Хранение и совместимость

Миграция 039 добавляет отдельную таблицу; существующие задачи и фотографии не преобразуются. Содержимое файлов и имена шифруются существующим серверным ключом. В публичном каталоге файлы не создаются. JSON содержит только метаданные и закрытую ссылку. Download проверяет текущие права проекта и пространства, включая перенос задачи и исключение участника; используется attachment disposition, no-store и nosniff.

Создание/изменение задачи и файлов выполняется одной транзакцией. Повтор запроса использует существующий requestId. Клиенты без полей вложений не удаляют файлы. Существующий SQLite runtime-backup включает новую таблицу. Проверены integrity_check и повторное применение миграции. Code rollback — git revert через штатный workflow; новую таблицу и пользовательские файлы при откате кода автоматически не удалять. Production-БД вручную не изменялась.

## Непроверенные состояния

Непосредственное перетаскивание файла с рабочего стола не подтверждено браузерным инструментом: эта операция недоступна через его CDP. Обработчики drop реализованы; выбор файлов кнопкой и серверное сохранение проверены. Живые Google OAuth/sync, два реальных аккаунта, нагрузка, нативное Android-устройство и загрузка файлов в нативной форме не проверены. Полная матрица месячных/годовых счётчиков всех трёх календарей не завершена из-за сбоя браузерного стенда; проверка лунного месяца/года и григорианского года остаётся отдельной runtime-проверкой.

Дополнительный tsc --noEmit не прошёл из-за существующих ошибок типов и включения архивных папок work; обязательные lint/test/build зелёные. SSH не использовался.
