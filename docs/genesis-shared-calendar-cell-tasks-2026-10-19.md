# Задачи в ячейках общего календаря и поиск

По уточнению пользователя общий календарь показывает первые три активные задачи каждого дня. Задача открывает актуальную полную карточку; многоточие и дата открывают существующее окно дня. В окне сохраняются все страницы, завершённые задачи и создание/назначение задач. Превью больше не зависит от первых100 задач проекта. [Предварительный аудит](genesis-shared-calendar-cell-tasks-audit-2026-10-19.md).

Использованы существующие CalendarCellTasks, bounded preview endpoint и hook. Необязательный фильтр проекта/приоритета/пользовательских полей применяется сервером до ограничения трёх задач на дату. Сохраняются42-дневная граница, current ACL, шифрованное read view, open-only и исключение архивов. Прежний вызов без фильтра совместим. Перед открытием загружаются свежие задача и контекст; ответ прежнего проекта/периода/фильтра не открывает карточку. Медленные preview-запросы не отменяются каждым polling tick. Изменение scope отменяет прежний запрос и исключает его данные из текущего экрана.

В ячейке больше нет вложенных кнопок. Дата, до трёх задач и многоточие доступны отдельно с клавиатуры и имеют подписи. Длинные названия занимают до двух строк. Обычная неделя сохраняет семь колонок; сакральные/лунные циклы и независимый календарь ввода сохранены. Узкая сетка прокручивается внутри блока; страница не расширяется. Основной календарь сохраняет прежнее правило desktop-only для превью. Существующие SVG и ассеты сохранены.

Правка поиска удаляет отдельное левое позиционирование значка общих дел: оба поля используют общее правое положение personal-affairs-search. Текст получает отступ справа; личная кнопка очистки, native clear общего search-input и фокус по области значка сохранены. Майндмепы уже размещают существующие значки справа. Новые значки для полей без значка не добавлялись; native Android search в этом срезе не изменялся.
