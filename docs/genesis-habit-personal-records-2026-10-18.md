# F2: достоверный процент личных рекордов — 18 октября 2026

Источник ошибки: `buildHabitPersonalRecord` делил все завершённые записи на число запланированных дат и скрывал результат выше100% через cap. Дубликаты записей умножали total/mastery и лучший месяц; выполнения вне текущего плана могли давать100% при реально пропущенных запланированных днях.

Теперь numerator — уникальные выполненные запланированные даты, denominator — уникальные возможности по переданному правилу расписания/settlement. Общая история считается отдельно по уникальным допустимым прошлым датам; выполнения вне плана не теряются. Future, невозможные civil dates и даты до создания не учитываются. Изменённый endDate ограничивает план, сохраняя уже существующую историю. Процент не ограничивается искусственно: согласованные множества дают корректный диапазон. При пустом знаменателе показывается «—», при существующем плане без выполнений —0%.

В личных рекордах видны оба числа, отдельно количество вне расписания. Для текущей паузы показывается статус паузы, без ложного вывода о том, что старые реальные результаты выполнены вне расписания. Полная реконструкция исторических пауз остаётся в E4. В итогах периода добавлен устойчивый bestHabitId, чтобы лидер переводился тем же helper по происхождению текста, включая совпадающие пользовательские названия.

Новые подписи переведены на13 остальных языков. Изменение касается только read-only проекций; записи workspace, XP/Лавры, порог49/50 и механизм начисления не вызываются и не изменяются. Схема/миграции/протокол синхронизации прежние; Android не пересобирается.

Проверки: frozen install, lint (0 ошибок, прежние2 img warnings), все326tests/i18n и build:beget прошли. Семь новых сценариев: несогласованный numerator/denominator, дубли, future/до создания/невозможные даты, нулевая база, изменённый endDate, периодические settlement slots, мозаика384дней без обрезки370. Годовая мозаика уже использовала реальные границы выбранного календаря; это проверено регрессией, а не объявлено новым изменением.

Chromium, обе темы ×360/390/768/1440: проверены проценты, явные знаменатели, отсутствие переполнения и снимки до/после. Артефакты `output/playwright/habit-records-{before,after}-*`; протокол итоговой проверки `habit-records-confirm.log`. Detector для изменённого экрана вернул пустой список. Firefox/WebKit, screen reader, physical phones, live Google reconnect и полная приёмка F2/F3 не проверены в этом срезе. Ручной SSH и production DB edits не использовались.
