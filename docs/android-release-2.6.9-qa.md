# Android GENESIS 2.6.9 (75): проверка release

Содержит согласованные изменения сайта/приложения из [отчёта 2.6.8](android-release-2.6.8-qa.md). Пакет, сертификат, страны и участники существующего Alpha сохраняются. Код 74 уже загружен в Play как черновик и не отправляется на проверку; исправленный AAB использует 75.

Публичный APK 74 успешно устанавливался, но падал при первом запуске на API 35: VerifyError в оптимизированной инициализации WorkManager. Эта ошибка не проявлялась в debug-сборке и модульных тестах. Оптимизация R8 отключена правилом `-dontoptimize`, сокращение неиспользуемого кода и обфускация сохраняются. Похожая ошибка генератора описана в [официальном tracker R8](https://issuetracker.google.com/issues/551348855); тождественность причин не предполагается, исправление проверяется запуском нашего APK.

До исправления скачивание проблемного APK закрыто через права файла в согласованных корнях Hostinger и Beget; сайт и активный Play-выпуск 2.6.5 продолжают работать. Новая сборка публикуется только штатным workflow. Права публичного каталога/файлов явно заданы, ключи подписи остаются закрытыми.

Перед деплоем CI устанавливает и запускает именно подписанные Native и Play APK на отдельном эмуляторе API 35. Проверяет выживание процесса, отсутствие FATAL EXCEPTION/VerifyError и открытую MainActivity; сохраняет снимки. Скрипт отказывается работать с физическим устройством. Настройка CI использует документированный [Android Emulator Runner](https://github.com/ReactiveCircus/android-emulator-runner).

Локально оба release APK (Native и Play) прошли тот же скрипт на изолированном emulator-5584 с тестовой подписью: процесс жив спустя 15 секунд, MainActivity открыта, ошибок verifier/AndroidRuntime нет. Начальный экран выбрал английский для устройства и показал только Google-вход. 214 модульных Android-тестов, frozen install, lint, 111 веб-тестов и build:beget прошли. Production-подпись и запуск обеих финальных сборок проверяются CI до деплоя.

Реальный вход через Google и двусторонняя синхронизация с пользовательским аккаунтом требуют отдельного подтверждения на Android; до него .ru сохраняет совместимость. Ограничения передачи богатых личных полей/списков из отчёта 2.6.8 остаются: исходные записи не удаляются при неполной передаче.

Первый CI-запуск 37718721737 собрал обе подписанные release-сборки, но эмулятор не стартовал: на runner оставалось 3,4 GB при стандартном разделе userdata более 7 GB. До загрузки AAB и деплоя проверка остановила workflow. Для одноразового smoke-эмулятора задан документированный disk-size 2048M; условия проверки самого приложения не ослабляются.

Второй запуск 37722645101 подтвердил, что image API 35 требует 7372,8 MB даже при disk-size 2048M, поэтому одно уменьшение раздела проблему не решает. После завершения подписи, stripping и всех Android unit tests CI теперь удаляет через sdkmanager только установленные NDK-инструменты из одноразового runner (далее они не используются), проверяет запас свободного диска не менее 10 GiB и задаёт AVD 8192M. Production-сервер и данные не затрагиваются; APK/AAB по-прежнему проходят запуск до загрузки и деплоя.
