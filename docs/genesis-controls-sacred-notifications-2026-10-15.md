# GENESIS: полотно, сакральные действия и уведомления

Выпуск от `63b13cc0eb8f6ef23b8f824c45b749828c7113e1`, ветка `codex/mindmap-floating-zoom`, опубликован через существующий GitHub Actions → Hostinger: [PR #172](https://github.com/nikitalexanderson-byte/calendar-genesis/pull/172), master/production `435798848cfbaa7e0dcadf27cadc54ab543abd0c`.

## Поведение

- Полотно майндмапы начинается непосредственно у верхней границы. Масштаб расположен отдельным элементом справа сверху; действия выбранной пунктирной связи не сдвигают полотно.
- «Участники пространства» — следующий самостоятельный блок после рабочей области общей карты. Состояние участников сохраняется при переключении карты и структуры; присутствие и личная переписка используют прежние API.
- В меню мысли есть «Удалить мысль» с подтверждением. Дочерние узлы переходят к родителю, остальные связи и ссылки сохраняются. «Убрать ветку» остаётся отдельным действием. Изменение можно отменить; реальные задачи и проекты не удаляются.
- На десктопе «Создать проект» находится слева в строке действий доски; остальные иконки справа. На 360/390 px прежний порядок сохранён.
- `DialogCloseButton` объединяет закрытие диалогов: 44×44, стандартная SVG-иконка, общие цвета, фокус и положение справа. Удаление сущностей и очистка поиска сохраняют собственные обработчики.
- Нижние кнопки сакрального окна используют обычный secondary-button и стандартные иконки.
- Новые сакральные практики в web и Android создаются однократно на одну выбранную дату с `recurrence=false`. Прежние записи, расписания и награды не мигрируются.
- Практики сектора кликабельны в полной информации карты. У перевёрнутой карты отдельные рекомендации расположены непосредственно перед «Полная информация о карте». Клик открывает создание или редактирование соответствующей практики.
- Уведомления, комментарии, приглашения и личные сообщения доступны через единый компактный блок. На десктопе краткое уведомление исчезает через 5 секунд; непрочитанное остаётся в списке. Блок можно перетаскивать внутри рабочей области; закрытие возвращает иконку в нижний левый угол рабочей области. На ширинах до 1040 px включительно новое сообщение показывает только иконку выше мобильной навигации; список открывается по нажатию. Пустой блок скрыт.
- Список поддерживает серверную пагинацию и прочтение конкретного сообщения. Истечение таймера, открытие и сворачивание списка не отмечают сообщения прочитанными. Закрытый список сохраняет получение новых сообщений; личные сообщения по-прежнему открываются в существующем защищённом диалоге.
- Сохранение определения привычки подтверждается после записи шифрованной операции в существующую очередь. Редактор остаётся открыт при ошибке записи. Это устраняет потерю действия при перезагрузке в прежнем окне ожидания 650 мс, сохраняя существующие API и механизм повторной синхронизации.
