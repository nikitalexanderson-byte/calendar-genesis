# Видимое и устойчивое перетаскивание видов проекта

Удержание «Список / Доски / Календарь / Гант» воспроизвело потерю pointer capture: React переставлял захватившую указатель кнопку в DOM, браузер отправлял lostpointercapture, а компонент отменял перенос. Захват перенесён на неподвижный контейнер ряда.

Во время переноса поверх страницы движется отдельная плашка с названием вида, а полупрозрачное место вставки остаётся в ряду. На сенсорном экране плашка поднята над пальцем. За пределами ряда она приглушается; отпускание снаружи отменяет изменение. Используются существующие STANDART-токены обеих схем. Новых библиотек или изображений нет.

Escape, pointercancel, потеря захвата, уход из окна, прокрутка и изменение размера отменяют перенос. Отпускание вне ряда до срабатывания удержания очищает таймер. Отмена не запускает обычный клик, даже если указатель отпущен позже. Обычные клики, касания и Alt+стрелки/Home/End сохраняют прежнее назначение. Изменившийся за время переноса сохранённый порядок защищён от перезаписи.

Сохранение порядка остаётся в существующем account preferences API: первый вид становится видом по умолчанию, текущий вид не переключается при переносе. Проверена запись на локальный PHP API синтетического аккаунта, повторное открытие и отображение ошибки при отказе записи. Production-данные не изменялись вручную.

Проверены обе схемы на 360/390/768/1440 px и ширине пользовательского скриншота 1917 px: 40 кадров обычного состояния, удержания, перемещения и выхода из ряда. Дополнительно четыре кадра реального Chromium touch input на 360/390 px, отмена touch и обычная вертикальная прокрутка. Сохранены четыре полностраничных кадра и снимки до изменения. Evidence: `output/project-drag-{inspection,functional,touch,full}.json`, `output/project-drag-image-manifest.json`, `output/playwright/project-drag-*.png`. Начальная нестабильность touch-harness происходила до завершения загрузки верхних панелей; итоговый прогон дожидается network idle и шрифтов.

Frozen install, lint (0 ошибок, два прежних img warning), 362 теста и build:beget прошли. Один scoped detector: 0 primary, одно advisory о цвете тени #0004; это существующий тип нейтральной тени, а не новая палитра. Независимый finish review завершён с disposition `ship` без material fixes; сверка документации завершена без расхождений, вызванных этой правкой. Оба результата относятся только к этому web-контролу и сохранённой матрице проверок: `output/project-drag-finish-review.md`, `output/project-drag-documentation-check.md`.
