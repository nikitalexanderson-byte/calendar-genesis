# B6 — массовые действия, 15 октября 2026

Статус: локальная реализация, до браузерной приёмки и публикации. Production остаётся на B5 / `134200a893ba331d3a13602b18cfe10af8a24463`, Android 2.8.4 / 84.

## Область

Массовые действия встроены в выдачу существующих сохранённых представлений. Отдельные флажки сохраняют открытие карточки задачи. Есть явный выбор среди показанных задач (до 1000), всех результатов фильтра (серверный снимок), предварительный просмотр, подтверждение, отмена остатка, восстановление после фонового сбоя и ограниченный постраничный отчёт. История операций доступна независимо от текущей выдачи, включая пустую.

Действия: исполнитель, статус отдельно для каждого проекта, приоритет, установка/сдвиг/очистка срока, добавление/снятие меток, перенос, архив и корзина с существующей политикой 1–30 дней. Календарь ввода даты локален для формы и не меняет календарь отображения или фильтра. Права, ревизии, утверждение, отношения и квоты проверяют существующие операции задач.

## Надёжность и приватность

- Неизменяемый снимок SQL с TTL предварительного просмотра 10 минут; браузер не загружает все задачи для режима all.
- Зашифрованные определения операций, устойчивые receipts операции/элементов, savepoints и атомарные результат/ack. Сдвиг даты не применяется повторно после потери ответа.
- Архив/корзина фиксируют всех потомков и возвращают точный результат также для изначально невыбранных детей. Изменившееся дерево не расширяет область после подтверждения.
- Существующая фоновая очередь сохраняет lease, backoff и пять попыток. Terminal failure видим; resume обрабатывает только остаток. Старый callback не отменяет возобновлённую операцию.
- Названия и ссылки отчёта проверяют текущий доступ. После переноса ссылка ведёт в целевой проект; корзина показывает доступное название без активной ссылки. При отзыве доступа названия/ID проектов и задач не выдаются. Открытие ссылки дополнительно делает свежий API-запрос.
- Устройство сохраняет только ID операции и ещё не подтверждённый запрос для безопасного повтора. Отчёты и названия не сохраняются; logout удаляет весь префикс `genesis.shared-bulk.`. Серверная история доступна после повторного входа.

## Миграции и откат

`062_shared_bulk.sql` добавляет операции/элементы; `063_shared_task_branch_index.sql` добавляет индекс `(project_id,parent_task_id,id)`. Они не переписывают пользовательские задачи. Миграционный тест сохраняет согласованный SQLite backup до изменений, проверяет исторические записи, шифрование, совместимые старые записи и каскадное удаление аккаунта.

Существующий CI перед deploy сохраняет только server-only config и runtime SQLite. Code rollback — git revert с повторным workflow; добавленные таблицы и индекс остаются, данные не удаляются. Автоматического восстановления production-БД нет. В этом этапе SSH не использовался, production-БД вручную не менялась.

## Доказательства на checkpoint

- `output/b6-final-shared-bulk.log`: 121 результат all, все действия, ACL/revision, потомки, completion/reopen, retry/cancel, атомарность, stale/concurrent/expired leases, terminal failure/resume, текущие имена в отчёте, revoked reports, шифрование.
- `output/b6-migration-test.log`: миграции 062/063, backup и совместимость.
- Первоначальный large-прогон подтвердил 10001 selected, 10000 изменений, один конфликт и точную пагинацию, но был остановлен на медленной ветке 6000. Он не считается полным успешным прогоном.
- `output/b6-recover-large.log`: после исправления плана recursive join и индекса прерванная операция завершила ровно 6000 задач за 3,45 с, peak 12 MiB. Удалены только её синтетический actor и точное пространство fixture. Полный повтор large ожидается.
- Frozen install, i18n:audit, начальный build:beget прошли; max JS 349895 байт. Новые 65 строк переведены на все 13 нерусских локалей; русская использует исходные строки. Unit tests проверяют повтор receipt, восстановление, очистку logout и параметры всех локалей.
- Scoped ESLint прошёл. Полный tsc всё ещё выдаёт девять прежних ошибок в других модулях; он не объявляется зелёным.

Ещё не проверены: HTTP/browser жизненный цикл, lost response/logout race в браузере, полный новый large-прогон, новая визуальная матрица обеих схем × 360/390/768/1440, 14 языков в UI, финальный reviewer/documenter, авторизованные production-сценарии. Нативный интерфейс B6, Safari/Firefox и screen reader в эту веб-фазу не входят.
