# E4/E5: аудит продолжения после G/C/B выпуска

Обнаруженный остаток текущего Android: HabitsRepository.delete физически убирает привычку, completions и measurements; карточки переключают active без истории. Отдельных native archive/trash/restore и backup conflict/apply экранов нет. Подготовленные547d73c/57a6bc8/8276f8d сохраняются в codex/genesis-complete-acceptance; их нельзя переносить поверх более новых C/G/B файлов целиком.

Первый экран реализации — существующие «Мои привычки»: общие48dp icon actions, понятные блоки активных/паузы/архива/корзины, отдельное короткое подтверждение удаления с прежним экономическим правилом. Архив не меняет награды. Restore возвращает тот же ID на паузе; Resume остаётся явным действием. Существующие изображения карточек, STANDART, записи, настройки и награды сохраняются.

Переиспользуется подготовленный причинный lifecycle journal/merge и Room-transaction outbox. Все новые actions получают устойчивый ID; повтор не создаёт событие/штраф. Таймер ставится на паузу в той же транзакции. Конфликт двух ветвей не разрешается молчаливым last-write-wins. Порог удаления50 считается по уникальным подлинным completed датам экономической истории, а не измерениям/единицам/историческому импорту.

Следом E5: полная CSV история и проверяемый versioned JSON, read-only preview, явные keep/copy конфликты и атомарное применение без наградного replay. Native reader/export должны совпадать с веб-форматом и поддерживать перенос в чистое изолированное пространство, повтор и повреждённый ввод. Старые protocol6 offline outbox и schema16 documents требуют upgrade/merge проверки до включения marker7; server guard не ослабляется.

Проверка: domain/web/native parity, настоящие encrypted storage/outbox tests и HTTPS old/new writer, pause/archive/delete/restore с таймером/уведомлениями/экономикой, обе схемы ×360/390/768/1440,14 локалей/font130, системный Back/IME и доступные controls. Сначала before, затем один общий visual pass/один corrective batch. Realme отключён; только API28/API35. После E4/E5 продолжаются F1–F3 и A4. Этот аудит не означает принятую реализацию.
