# L2/B5/C3: нативные названия досок — аудит

Продолжение web-среза `3c5fcc0`, без деплоя и нового публичного APK. Android API28 эмулятор доступен; Samsung/Realme не используются. Строгий остаток21 partial ID/14 K/U/L сохраняется.

Обнаружены подстановки сохранённых «К выполнению», «В работе», «Готово»: `sharedStatusLabel` в `SharedProjectsScreen`, дополнительный перевод metadata карточки и отдельная ветвь `SharedTaskFieldQuery`. В соседних C1/C3 controls пользовательские choice labels уже рендерятся через Material Text напрямую. Это конфликт с сохранением пользовательских названий и принятым web-поведением.

Первый узкий срез — существующие карточка/статусный фильтр. Новая instrumentation-пара проверяет исходное название в карточке и раскрытом/выбранном фильтре; число0 и системная локализация сохраняются. До изменения продукта ожидается настоящий failure на текущем коде, отдельно от ошибок harness. Скриншоты снимаются с физического Surface эмулятора; перед/после сохраняются раздельно.

После baseline убрать только переводы сохранённых titles и использовать прямой Material Text там, где местный Text локализует содержимое. Системные подписи, поля, календари, история, ассеты, оформление/размеры48dp не меняются. Проверить обе схемы, реальные360/390/768/1440dp, font1.3 и14 языков; восстановить исходные wm/density/font settings. Изолированный QA application ID, без очистки основного приложения. Полный MainActivity/OAuth/физические жесты/TalkBack и API35 в этот срез автоматически не включаются.

Baseline подтверждён: обе новые проверки API28 завершились assertion failures, filter показывает To do, карточка — To do и Description. Тестовый APK сначала был отклонён guard как stale DEX; чистая пересборка только merge/package AndroidTest восстановила соответствие перед устройством. Ошибки выбора JDK/SDK и аргумента PowerShell также относились к запуску сборки, не к продукту. Before PNG сохранены и просмотрены.

На этом же исходном кадре выявлен Material default radius28dp окна фильтров. Узкая UI-правка использует существующий `AffairsLayout.controlShape`10dp; кнопки уже используют этот токен и48dp. Это единственное изменение геометрии. Категория карточки также переводится местным Text и включена в новую проверку исходных названий. Остальные system labels сохраняют перевод.

Контраст исходного текста категории измерен по native PNG: foreground RGB178/138/74 на RGB248/245/237 даёт2.91:1. Для категории выбран существующий onSurfaceVariant, без новой палитры. Instrumentation дополнительно получает фактический цвет TextLayoutResult и проверяет минимум4.5:1 в обеих схемах; показатели сохраняются отдельно для confirming кадров.
