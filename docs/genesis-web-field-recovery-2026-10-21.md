# C3: восстановление настройки полей в браузере

Аудит обнаружил, что `SharedCustomFieldManager` держит frozen PUT только в ref. Перезагрузка теряет command/operationId, редактирование и любой409 сбрасывают его. После неизвестного ответа это допускает новую операцию вместо точного replay. Защита beforeunload не восстанавливает ввод после закрытия вкладки.

Выбран один существующий экран настроек полей. Сохраняются его блоки, STANDART light/dark и общий IconActionButton. Добавляется компактный блок локальных черновиков с существующими переводами14 языков. Продолжение и удаление используют подписанные для доступности иконки44px; применение, повтор и явный возврат к редактированию имеют короткий текст.

Используется существующий AES-GCM `SharedWorkDraftJournal` с purpose `custom-fields`, отдельным writer каждой вкладки, CAS удаления и очисткой при выходе. Сохраняются собственный ввод и точное JSON-тело команды. Durable attempt записывается до PUT; любой неизвестный ответ, повреждённый receipt или повторный отказ после неизвестного ответа оставляют прежнюю команду. Редактирование/отмена и удаление попытанного неизвестного запроса заблокированы. Документированный первый отказ можно явно вернуть в редактор. Смена типа требует согласия на successor; ответ проверяется по всей нормализованной конфигурации, IDs/области/revision/previousFieldId. Полученный receipt сохраняется до очистки журналов; сбой очистки не требует повторного применения.

Перед первым запросом перепроверяется preview/fingerprint, для replay используются исходные bytes/operationId. Ошибка чтения очищает загруженный каталог/историю. Поздняя crypto/HTTP-работа не меняет другой account/проект; API сохраняет проверку текущих прав. Повреждённый журнал сохраняет исходные зашифрованные bytes для выгрузки.

До: матрица существующего экрана `output/playwright/field-editor-before-*.png` и опубликованный исходник. Приёмка нового восстановления, финальные состояния обеих тем/четырёх ширин и ограничения дополняются после проверок. Этот срез сам по себе не закрывает C3 или основной промпт. SSH и ручных изменений production-БД нет.

## Фактическая проверка

Frozen install, lint (0 ошибок/2 прежних img warnings),372 web tests/i18n и build:beget прошли. Семь новых unit-проверок покрывают потерянный ответ/reload/exact replay, полное подтверждение настроек и successor, первый окончательный отказ и поздний отказ после неизвестного результата, ошибку хранения до/после отправки, изоляцию encrypted namespace. Полный tsc остаётся неуспешным из-за прежних ошибок вне новых файлов; типовых ошибок нового writer/экрана в нём нет.

Настоящий browser/PHP flow: ввод восстановлен после reload; первый PUT применён сервером, ответ потерян; после второго reload409 оставляет команду заблокированной; третий PUT подтверждает исходную операцию. Все3 тела побайтно совпали, одно поле/revision1, исходный title сохранён, plaintext title/operationId в журнале отсутствуют. Продолжение сначала сохраняет новую encrypted копию и лишь затем CAS-удаляет прежнюю; незавершённая попытанная операция не удаляется через интерфейс. Основной журнал — `output/field-durable-functional-2.log`; предшествующий отдельный replay — `output/field-durable-resume.log`.

Сохранены16 ready-state PNG: восстановление и неизвестный результат × обе схемы ×360/390/768/1440 (`output/playwright/field-durable-{recovery,pending}-*.png`). Проверены отсутствие горизонтального переполнения, локализованные accessible names и44px icon targets. Прочитаны desktop/light и phone/dark originals; визуальные изменения ограничены существующими блоками. Новая подпись возврата в редактор добавлена на14 языках в существующий каталог. Inline finish review является self-review.

Browser harness принял первый beforeunload, затем подавлял только этот guard при программных reload, чтобы проверить восстановление после принудительного закрытия. Это не новая проверка защиты от закрытия окна. Не проверены в браузере: выгрузка повреждённого ciphertext, новая quota-ошибка и гонка двух окон во время переноса записи; storage/CAS/account guards имеют unit-покрытие существующего журнала. Общие G/C/B-интеграции, B5 durable writer, native signed/Google и общий выпуск ещё открыты. Публикации, SSH и изменений production-БД этим commit не выполнялось.
