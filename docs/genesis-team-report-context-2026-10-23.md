# GENESIS: условия и удобство командного отчёта

23 октября 2026. Локальный C4/G2/K/U/L после `296066f` в ветке `codex/shared-editor-errors-2026-10-23`. Деплой и новая Android-сборка запрещены. Общий строгий остаток **11/32 принятых, 21 частичный функциональный ID и 14 сквозных K/U/L** не изменён этим срезом.

## Аудит одного экрана

В настоящем `SharedTeamReports` с синтетическим loopback API воспроизведён неверный признак актуальности. При `Not/A_Zone` поле уже имело `aria-invalid`, обновление было запрещено, но старые показатели, страницы точной выборки и вызов обработчика открытия задачи оставались доступны. Последний валидный календарный контекст сохранялся, поэтому JSON key совпадал с прежним snapshot. Это несоответствие видимых условий и доступных действий; серверные ACL/token этой проверкой не обходились.

На 360/390px три горизонтальные таблицы не имели клавиатурной точки входа. Показатели использовали радиус 8px, а локальные pressed/checkbox стили ссылались на отсутствующий в STANDART `--accent`. Длинные непрерывные названия уже переносились без переполнения; их не сокращали и не заменяли.

Исходный `before.log` и `output/team-report-context/before-receipt.json` фиксируют четыре признака неверно доступного перехода и недоступную клавиатурную прокрутку; overflow-признак честно false. Сохранены 16 before PNG: два состояния × обе схемы × четыре ширины.

## Изменение

Актуальность отчёта теперь требует валидного периода и часового пояса. При ошибке блокируются счётчики, старые задачи и продолжение выборки; ввод и прежний результат остаются для просмотра. Возврат точно прежнего валидного значения восстанавливает тот же snapshot без запроса. Другой валидный контекст требует явного обновления.

Существующая фраза о корректном IANA-поясе показана непосредственно под полем и связана через `aria-describedby`, с `role=alert`. Использован готовый перевод на 14 языков. Контекстная сетка выравнивает поля по верху, поэтому пояснение не сдвигает поле начала года на десктопе и предшествует ему на телефоне. Условия сохраняются в памяти открытого окна; долговечное сохранение после закрытия/перезагрузки этим текстом и срезом не заявляется.

Обновление отчёта, сброс фильтров и очистка стартовых статусов используют общий `IconActionButton`: SVG, доступное имя/подсказка, 44×44px и 10px. Кнопки показателей также получили 10px. Таблицы стали именованными регионами с Tab-фокусом, нативной прокруткой стрелками и видимой рамкой. Цвета focus/pressed/checkbox используют существующий `--ui-accent`.

Изменены только `app/SharedTeamReports.tsx` и `app/shared-reports.css`. STANDART, изображения, сервер, зависимости, вычисления календарей и модели отдельных points/часов сохранены.

## Непроверенные состояния

WebKit/Firefox, touch/системная клавиатура физического телефона, экранные дикторы, live production/Google/ACL и большие многолетние серверные наборы здесь не проверены. Все API и задачи синтетические; суммы не пересчитывались настоящим PHP в этой UI-приёмке. Native `TeamReportState.change()` сверён только по исходникам: он очищает результат при изменении условий. Android runtime/сборка не запускались. Новый код локальный, без push, деплоя, SSH и обращения к production-БД; Private-статус репозитория не менялся.
