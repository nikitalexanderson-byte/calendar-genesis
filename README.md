# GENESIS

Production: [https://genesiscalendar.ru](https://genesiscalendar.ru)

GENESIS — устанавливаемый календарь и менеджер жизни: сакральный 360-дневный круг, Артемида и Геката, план дня, проекты и подпроекты, категории, теги, зависимости, повторяющиеся задачи и напоминания Google Calendar.

## Что уже работает

- браузерный интерфейс для десктопа и телефона;
- PWA-установка и стационарный ярлык Windows;
- бесплатный GENESIS Voice: голосовое создание задач без внешнего AI API, с локальным разбором русских и английских команд и предварительным подтверждением;
- проекты, подпроекты, категории, теги и связи между задачами;
- гибкие повторения по профанскому, сакральному и лунному календарям: диапазоны дат, дни недели, конкретные месяцы, дни и чётные/нечётные пяты;
- завершение с фиксацией времени и визуальным вычёркиванием;
- локальная офлайн-копия и очередь изменений до восстановления сети;
- закрытая приветственная страница: календарь доступен только после входа;
- безопасный вход только через официальный Google OAuth; приложение не запрашивает пароль Google;
- PHP 8.3 API, SQLite и строгая изоляция аккаунтов;
- Google OAuth 2.0 с `state` и PKCE: вход запрашивает только профиль, а Calendar и Tasks подключаются отдельным согласием;
- отдельный календарь `GENESIS` и двусторонняя синхронизация Google Tasks;
- задачи и заметки не сохраняются в SQLite: они живут локально, в Google Calendar или Google Tasks;
- структура проектов шифруется AES-GCM в клиенте до загрузки на сервер;
- двусторонняя синхронизация названия, даты, времени, статуса, связей и напоминаний;
- административная статистика без содержимого задач и проектов;
- четыре астрономические точки года с золотыми солнечными днями и отдельной символикой месяцев;
- создание, переименование, перекрашивание и удаление категорий без удаления связанных проектов и задач;
- Android-модуль Trusted Web Activity с application ID `ru.genesis.calendar`.

## Локальная разработка

Требуется Node.js 22.13 или новее.

```powershell
pnpm install
pnpm dev
pnpm lint
pnpm build
pnpm build:beget
```

Локальная версия хранит данные в браузере. Серверная синхронизация включается через `NEXT_PUBLIC_GENESIS_API_URL` или при Beget-сборке через `GENESIS_API_URL`.

## Сервер

Публичная статика собирается в `dist-beget/public_html`. Сервер находится в `server/`; файл `server/config.php`, SQLite-база, сессии и Google-токены не попадают в Git и должны находиться вне публичной директории.

Основные маршруты API:

- `GET /api/health` — состояние сервиса;
- `GET /api/session` — текущий пользователь и CSRF;
- `GET /api/bootstrap` — Google-события и зашифрованный контейнер структуры;
- `GET /api/auth/google/start?purpose=login|services` — вход Google или отдельное подключение Calendar и Tasks;
- `POST /api/account/google-services/disconnect` — отзыв Google-разрешения и удаление токенов без удаления профиля;
- прежние маршруты парольного входа отключены и отвечают HTTP 410;
- `GET /api/sync/tasks` — чтение задач напрямую из Google Calendar;
- `PUT|DELETE /api/tasks/{id}` — запись или удаление Google-события без сохранения задачи в БД;
- `PUT /api/workspace` — зашифрованная структура проектов и подпроектов;
- `GET /api/admin/stats` — агрегаты для администратора;
- `DELETE /api/account` — отзыв OAuth-разрешения и удаление серверного аккаунта и данных.

Публичные страницы: `/privacy`, `/terms`, `/support`, `/delete-account`.
