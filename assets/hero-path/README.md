# Hero Path artwork

- `MANIFEST.md` is the supplied source-of-truth mapping.
- `source/` contains the original 1254×1254 transparent PNG files without modification.
- `public/hero-path/256/` and `public/hero-path/512/` contain the production WebP variants.

The WebP files are resized with Lanczos resampling and encoded at quality 95 with lossless alpha.
