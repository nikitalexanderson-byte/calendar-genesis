## Важное замечание

- Для **«Укротитель Мощи»** использовать именно файл `11_tamer_of_might.png`.
- Старую версию с рукой **не использовать**.
- Все файлы являются исходными PNG-иконками. Для сайта их желательно оптимизировать в WebP/AVIF и оставить PNG как исходники.
- Предполагаемые чекпоинты амфор по последовательности: после ранга 4, после ранга 8, после ранга 12, после ранга 16.
