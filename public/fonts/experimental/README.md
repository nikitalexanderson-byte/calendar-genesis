# Experimental fonts

Inter and Source Serif 4, variable normal, copied from the user's published reference https://tempo-roan-delta.vercel.app/ on 2026-10-09. All original Cyrillic, Greek, Latin and Vietnamese subsets are retained. The CSS unicode ranges come from that reference. SIL Open Font License texts accompany the files.

Source Sans 3 and Literata remain fallbacks for scripts absent from these fonts. No third-party font request is made at runtime.
