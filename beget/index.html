Как GENESIS использует Google Calendar и Google Tasks

Для входа используются только основные данные профиля Google. Синхронизация подключается отдельно: GENESIS создаёт собственный календарь, а доступ к Google Tasks использует для показа и двустороннего изменения списков и задач по вашему выбору.

Нейросетевой помощник GENESIS разбирает команды и готовит план задач. GENESIS не создаёт интимные изображения без согласия (AI NCII) и не использует Google API для этой цели.
